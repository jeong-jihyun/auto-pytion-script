# 파이썬 업무 자동화 스크립트

사무·업무에서 바로 쓸 수 있는 작은 파이썬 스크립트 모음입니다. 매일 10개씩 늘어납니다.

## 사용법
1. 파이썬 3.8 이상을 준비합니다.
2. `scripts/번호_이름/` 폴더로 들어가 README.md를 읽습니다.
3. `sample/` 데이터로 먼저 실행해 보고, 내 파일로 바꿔 씁니다.
4. 파일을 바꾸거나 옮기는 스크립트는 기본이 **미리보기(dry-run)** 입니다. `--apply`를 붙여야 실제로 동작합니다.
5. 비밀번호·API 키는 코드에 넣지 말고 환경변수로 쓰세요.
