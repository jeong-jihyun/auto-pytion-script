# CSV 병합

## 무엇을 하나요?
폴더 안의 CSV 여러 개를 한 파일로 합칩니다. 어느 파일에서 왔는지 '원본파일' 열을 붙여요.

## 어떤 업무에 쓰나요?
지점별 매출표, 월별 보고 파일 합치기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample -o output/merged.csv
```

## 입력 / 출력 예시
- 입력: sample/ 안 CSV 2개(4행)
- 출력: output/merged.csv (헤더 + 4행 + 원본파일 열)

## 주의사항
헤더가 다른 파일은 건너뛰고 알려줍니다. 인코딩이 다르면 --encoding cp949 처럼 지정하세요.
