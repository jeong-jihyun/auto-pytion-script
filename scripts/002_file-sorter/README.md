# 폴더 파일 자동 분류

## 무엇을 하나요?
확장자를 보고 문서/이미지/표/압축/기타 폴더로 정리합니다.

## 어떤 업무에 쓰나요?
다운로드 폴더 정리

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample          # 미리보기
python3 main.py sample --apply  # 실제 이동
```

## 입력 / 출력 예시
- 입력: sample/ 안 파일 6개
- 출력: 문서/ 이미지/ 표/ 압축/ 기타/ 폴더로 이동

## 주의사항
기본은 미리보기입니다. 같은 이름이 있으면 덮어쓰지 않고 _1, _2를 붙입니다. 테스트할 때는 sample을 복사해서 쓰세요.
