# 파일 이름 일괄 변경

## 무엇을 하나요?
접두어 붙이기, 글자 바꾸기, 일련번호 붙이기를 한 번에 합니다.

## 어떤 업무에 쓰나요?
견적서/회의록 파일명 규칙 맞추기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample --find 초안 --replace 최종 --number
(실제 변경은 --apply 추가)
```

## 입력 / 출력 예시
- 입력: 견적서_초안.txt 등 3개
- 출력: 001_견적서_최종.txt 처럼 변경

## 주의사항
기본은 미리보기. 바뀐 이름이 서로 겹치면 중단합니다. 테스트는 sample 복사본으로 하세요.

## 테스트 상태
2026-10-20, 파이썬 3 로 sample 데이터를 실제 실행해 동작을 확인했습니다. 실제 업무 데이터에서는 먼저 복사본으로 시험해 보세요.
