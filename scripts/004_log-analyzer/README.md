# 로그 분석·요약

## 무엇을 하나요?
배치/서버 로그에서 레벨별 개수, 시간대별 ERROR, 자주 나온 ERROR를 요약합니다.

## 어떤 업무에 쓰나요?
야간 배치 점검, 장애 원인 1차 파악

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample/batch.log --top 3 -o output/summary.txt
```

## 입력 / 출력 예시
- 입력: '날짜 시각 [LEVEL] 메시지' 형식 로그
- 출력: ERROR 3건, 시간대별 건수, 상위 ERROR(숫자는 N으로 묶음)

## 주의사항
형식이 다른 줄은 '읽지 못한 줄'로 세기만 합니다. 로그 형식이 다르면 main.py의 패턴(정규식)을 고치세요.
