# 정산 대사(두 CSV 비교)

## 무엇을 하나요?
키 열로 두 CSV를 맞춰 한쪽만 있는 건, 금액이 다른 건을 찾습니다.

## 어떤 업무에 쓰나요?
내부 원장 vs 상대 기관 내역 대사

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample/ours.csv sample/theirs.csv --key 거래번호 --amount 금액 -o output
```

## 입력 / 출력 예시
- 입력: ours.csv, theirs.csv
- 출력: only_left.csv, only_right.csv, amount_diff.csv

## 주의사항
금액은 Decimal로 비교해 소수점 오차가 없습니다. 1,000 같은 쉼표는 자동으로 처리합니다. 키가 중복이면 마지막 값이 쓰이니 먼저 중복을 확인하세요.
