# CSV 중복 제거

## 무엇을 하나요?
지정한 열이 같으면 첫 행만 남기고, 제거된 행은 따로 저장합니다.

## 어떤 업무에 쓰나요?
회원/거래 명단 중복 정리

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample/members.csv --keys 이메일 -o output
```

## 입력 / 출력 예시
- 입력: members.csv 4행
- 출력: deduped.csv(3행), removed.csv(1행)

## 주의사항
공백·대소문자 차이는 같은 값으로 봅니다. 원본은 수정하지 않습니다.
