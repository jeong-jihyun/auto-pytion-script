# 텍스트 일괄 치환

## 무엇을 하나요?
규칙 CSV(바꿀말,새말)대로 폴더 안 텍스트 파일을 한꺼번에 바꿉니다.

## 어떤 업무에 쓰나요?
문서 속 연도·담당자명 일괄 변경

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample --rules sample/rules.csv        # 미리보기
python3 main.py sample --rules sample/rules.csv --apply
```

## 입력 / 출력 예시
- 입력: mail1.txt, report.txt, rules.csv
- 출력: 4군데 변경 (원본은 .bak으로 보관)

## 주의사항
기본은 미리보기. 먼저 폴더를 복사해 테스트하세요. 규칙은 위에서 아래 순서로 적용됩니다.

## 테스트 상태
2026-10-20, 파이썬 3 로 sample 데이터를 실제 실행해 동작을 확인했습니다. 실제 업무 데이터에서는 먼저 복사본으로 시험해 보세요.
