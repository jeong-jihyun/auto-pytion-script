# 영업일 계산

## 무엇을 하나요?
N 영업일 뒤 날짜, 두 날짜 사이 영업일 수를 계산합니다(주말 제외, 공휴일은 파일로).

## 어떤 업무에 쓰나요?
납기일·결제일·정산일 계산

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py add 2026-10-02 3 --holidays sample/holidays.txt
python3 main.py count 2026-10-01 2026-10-12 --holidays sample/holidays.txt
```

## 입력 / 출력 예시
- 입력: holidays.txt (한 줄에 YYYY-MM-DD)
- 출력: 2026-10-08 (목) / 6일

## 주의사항
공휴일 파일의 날짜는 예시입니다. 해마다 실제 공휴일로 직접 갱신하세요.

## 테스트 상태
2026-10-20, 파이썬 3 로 sample 데이터를 실제 실행해 동작을 확인했습니다. 실제 업무 데이터에서는 먼저 복사본으로 시험해 보세요.
