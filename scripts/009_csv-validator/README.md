# CSV 데이터 검증

## 무엇을 하나요?
JSON 규칙(필수·형식·범위·허용값·정규식)으로 CSV를 검사해 틀린 곳을 알려줍니다.

## 어떤 업무에 쓰나요?
업로드 전 데이터 점검, 이관 데이터 검증

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample/orders.csv --rules sample/rules.json
```

## 입력 / 출력 예시
- 입력: orders.csv(4행), rules.json
- 출력: 문제 4건을 줄 번호·열·이유와 함께 출력, 문제가 있으면 종료코드 1

## 주의사항
줄 번호는 헤더를 1줄로 센 값입니다. 규칙에 쓴 열이 CSV에 없으면 바로 중단합니다.
