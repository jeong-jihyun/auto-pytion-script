# 폴더 zip 백업

## 무엇을 하나요?
폴더를 날짜시간이 붙은 zip으로 백업하고 오래된 백업을 개수 기준으로 정리합니다.

## 어떤 업무에 쓰나요?
업무 폴더 정기 백업

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더에서 아래처럼 실행합니다.

```bash
python3 main.py sample -o backup_out --keep 5          # 미리보기
python3 main.py sample -o backup_out --keep 5 --apply
```

## 입력 / 출력 예시
- 입력: sample/ (파일 2개)
- 출력: backup_out/sample_YYYYMMDD_HHMMSS.zip

## 주의사항
삭제는 --keep과 --apply를 모두 줬을 때만, 이 스크립트가 만든 이름 형식의 zip만 대상입니다. 백업 폴더를 원본 폴더 안에 두지 마세요.
