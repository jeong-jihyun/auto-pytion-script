# 엑셀 요약 보고서 자동 생성

## 무엇을 하나요?
CSV 한 개를 읽어서 엑셀(.xlsx) 보고서를 만듭니다.
- `원본` 시트: CSV 내용 그대로. 숫자는 숫자로 저장하고(쉼표 `950,000` 도 숫자로), 머리글에 색을 입힙니다.
- `요약` 시트: 기준 열(예: 지점)별 건수·합계·평균. **엑셀 수식**으로 넣어서 원본을 고치면 요약도 같이 바뀝니다.

## 어떤 업무에 쓰나요?
지점별·부서별 매출 보고, 월말 비용 집계처럼 "CSV를 받아서 엑셀로 요약해 올리는" 반복 업무.

## 설치
파이썬 3.8 이상 + 패키지 1개.

```bash
pip install -r requirements.txt
```

## 실행 예시
```bash
python3 main.py sample/sales.csv -o output/report.xlsx --group-col 지점 --value-col 매출
```
엑셀에서 저장한 CSV가 한글이 깨지면 `--encoding cp949` 를 붙이세요.

## 입력 / 출력 예시
- 입력: `sample/sales.csv` (지점, 월, 담당자, 매출 / 6행)
- 화면 출력:
```
완료: 원본 6행, 그룹 3개 -> output/report.xlsx
  서울: 합계 2,550,000
  부산: 합계 1,750,000
  대전: 합계 1,120,000
```
- 출력 파일: `output/report.xlsx` (시트 2개, 전체 합계 5,420,000)

## 주의사항
- 요약 시트의 값은 엑셀이 열릴 때 계산됩니다. 파이썬이 계산한 값은 화면 출력으로만 보여 줍니다.
- 기준 열 이름이 CSV 머리글과 정확히 같아야 합니다.
- 숫자 열에 글자가 섞이면 그 칸은 합계에서 0으로 취급됩니다(엑셀 SUMIF 동작).
