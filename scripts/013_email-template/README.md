# 이메일 본문 일괄 생성 (발송 안 함)

## 무엇을 하나요?
받는 사람 목록(CSV)과 본문 틀(txt)을 합쳐서 사람마다 이메일 본문 파일을 만듭니다.
틀 안의 `{이름}`, `{회사}` 같은 부분이 CSV의 같은 이름 열 값으로 바뀝니다. 틀 첫 줄이 `제목: ...` 이면 제목으로 씁니다.

## 어떤 업무에 쓰나요?
결제 요청·일정 안내·자료 요청처럼 내용은 같고 이름·금액·날짜만 다른 안내 메일을 여러 명에게 보낼 때 본문 준비.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
python3 main.py sample/recipients.csv sample/template.txt -o output/emails
```

## 입력 / 출력 예시
- 입력: `sample/recipients.csv` 3명, `sample/template.txt` 틀
- 출력: `output/emails/001_김가상.txt` 등 3개. 내용 예:
```
제목: [예시상사] 2026-10-31까지 결제 요청드립니다

김가상 님, 안녕하세요.

예시상사에서 확인해야 할 금액은 1,200,000원 입니다.
2026-10-31까지 확인 부탁드립니다.

감사합니다.
```

## 주의사항
- **메일을 보내는 기능은 일부러 넣지 않았습니다.** 만든 파일을 눈으로 확인한 뒤 직접 복사해서 쓰세요.
- 틀에 쓴 `{이름표}` 가 CSV에 없으면 한 건도 만들지 않고 알려 줍니다(빈 값으로 나가는 실수 방지).
- 받는 사람 목록은 업무상 연락이 허용된 사람만 넣으세요. 광고성·무단 대량 발송 용도로 쓰면 안 됩니다.
- 틀 안에 중괄호 글자를 그대로 쓰고 싶으면 `{{` `}}` 처럼 두 번 씁니다.
