# 이미지 일괄 리사이즈

## 무엇을 하나요?
폴더 안 이미지(jpg, png, bmp, gif, webp)를 지정한 크기 안에 들어오도록 **비율을 유지한 채** 줄여서 다른 폴더에 저장합니다.
이미 작은 이미지는 키우지 않고 그대로 둡니다. 기본은 **미리보기**이고, `--apply` 를 붙여야 저장합니다.

## 어떤 업무에 쓰나요?
메일 첨부 용량 줄이기, 게시판·쇼핑몰 올릴 사진 크기 맞추기, 스캔 이미지 용량 정리.

## 설치
```bash
pip install -r requirements.txt
```

## 실행 예시
```bash
# 1) 먼저 미리보기 (아무것도 저장 안 함)
python3 main.py sample --max-width 800 --max-height 800
# 2) 괜찮으면 실제 저장
python3 main.py sample -o output/resized --max-width 800 --max-height 800 --apply
```

## 입력 / 출력 예시
```
  big_photo.jpg: 2000x1200 -> 800x480 (줄임)
  small_icon.png: 120x80 -> 120x80 (그대로)
  tall_scan.png: 900x1600 -> 450x800 (줄임)
끝: 전체 3개 중 2개를 줄였습니다.
```

## 주의사항
- 원본은 건드리지 않습니다. 저장 폴더를 원본 폴더와 다르게 쓰세요.
- JPG 는 다시 저장되므로 화질이 조금 달라질 수 있습니다(`--quality` 로 조절, 기본 85).
- 열 수 없는 파일은 건너뛰고 알려 줍니다. 하위 폴더는 보지 않습니다.
