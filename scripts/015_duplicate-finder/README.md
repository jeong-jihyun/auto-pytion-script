# 중복 파일 찾기

## 무엇을 하나요?
폴더(하위 폴더 포함)에서 **내용이 똑같은 파일**을 찾아 보고서(CSV)로 만듭니다.
이름이 달라도 내용이 같으면 중복이고, 이름이 같아도 내용이 다르면 중복이 아닙니다.
빠르게 하려고 크기가 같은 파일만 골라 sha256 해시를 비교합니다.

## 어떤 업무에 쓰나요?
공유 폴더·백업 폴더에 쌓인 같은 파일 정리, 저장 공간 확보 전 점검.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
# 보고서만 만들기 (파일은 건드리지 않음)
python3 main.py sample -o output/duplicates.csv
# 중복을 다른 폴더로 옮길 계획만 보기
python3 main.py sample -o output/duplicates.csv --move-to output/moved
# 실제로 옮기기 (되돌릴 수 있게 삭제가 아니라 '옮기기')
python3 main.py sample -o output/duplicates.csv --move-to output/moved --apply
```

## 입력 / 출력 예시
`sample/` 에는 내용이 같은 txt 3개(`docs/report.txt`, `backup/report_copy.txt`, `backup/old_name.txt`)와, 비슷하지만 내용이 다른 `minutes.txt` 2개가 있습니다.
```
완료: 중복 그룹 1개, 중복 파일 2개, 낭비 82 바이트 -> output/duplicates.csv
```
보고서에는 그룹마다 `유지` 1개와 `중복` 나머지가 적힙니다. `minutes.txt` 2개는 내용이 달라 중복으로 보지 않습니다.

## 주의사항
- **삭제 기능은 없습니다.** 옮기기도 `--move-to` 와 `--apply` 를 둘 다 써야 실행됩니다.
- `유지` 로 표시되는 파일은 수정 시각이 가장 오래된 것(같은 초면 이름순)입니다. 어떤 파일을 남길지는 보고서를 보고 직접 판단하세요.
- 옮기기 시험은 꼭 복사본 폴더에서 먼저 해 보세요.
- 바로가기(심볼릭 링크)는 건너뜁니다.
