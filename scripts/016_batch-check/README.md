# 배치 실행 결과 점검

## 무엇을 하나요?
야간·일일 배치가 끝난 뒤 "실행 결과 CSV"를 읽어서, 아침에 확인해야 할 문제를 골라 줍니다.

| 점검 | 뜻 |
|---|---|
| 실패 | 상태가 SUCCESS 가 아님 |
| 누락 | 있어야 할 작업이 결과에 없음 (`--expected` 목록 필요) |
| 지연 | 종료 시각이 마감(`--deadline`, 기본 06:00)보다 늦음 |
| 장시간 | 걸린 시간이 `--max-minutes`(기본 60분) 보다 김 |
| 0건 | 처리 건수가 `--min-rows`(기본 1) 보다 적음 |

같은 작업이 여러 번 있으면 시작 시각이 가장 늦은 것(마지막 실행)만 봅니다.

## 어떤 업무에 쓰나요?
증권·금융 시스템, ERP 의 일배치 점검(정산, 시세 적재, 수수료 계산, 백업 등). 문제가 있으면 종료 코드 1 로 끝나서 다른 스크립트·스케줄러와 연결하기 좋습니다.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
python3 main.py sample/runs.csv --expected sample/expected.txt --deadline 06:00 --max-minutes 60
```

## 입력 / 출력 예시
- 입력 열: `작업명,시작,종료,상태,처리건수` (시각 형식 `2026-10-20 01:00:00`)
- 화면 출력:
```
점검 작업 6개 중 문제 5개 -> output/batch_check.csv
  [장시간] ARCHIVE_LOG: 130분 걸림 (허용 60분)
  [0건] CLOSING_PRICE: 처리건수 0
  [실패] FEE_CALC: 상태 FAIL
  [0건] FEE_CALC: 처리건수 0
  [지연] REPORT_GEN: 종료 06:25 > 마감 06:00
  [장시간] REPORT_GEN: 145분 걸림 (허용 60분)
  [누락] BACKUP_DB: 실행 결과에 없음
```
- 출력 파일: `output/batch_check.csv` (작업명, 판정, 사유)

## 주의사항
- 한 작업이 여러 문제에 걸리면 줄이 여러 개 나옵니다(위 FEE_CALC, REPORT_GEN).
- 마감은 종료 "시각(시:분)"만 비교합니다. 날짜는 보지 않아요. 그래서 낮이나 저녁에 끝나는 배치는 모두 "지연"으로 나옵니다. 낮에 도는 배치는 `--deadline 18:00` 처럼 늦게 잡거나, 새벽 배치와 파일을 나눠서 점검하세요.
- 작업 실행 로그 자체를 분석하려면 `004_log-analyzer` 를 함께 쓰세요.
