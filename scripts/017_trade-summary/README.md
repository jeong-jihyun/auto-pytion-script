# 체결내역 종목별 요약

## 무엇을 하나요?
하루치 체결내역 CSV를 읽어 **종목별**로 아래를 계산합니다.
매수/매도 수량, 매수/매도 평균단가(수량 가중), 매수/매도 금액, 순수량(매수-매도), 수수료 합계.
금액은 Decimal 로 계산해서 소수점 오차가 생기지 않습니다.

## 어떤 업무에 쓰나요?
증권사·자산운용 후선(백오피스)의 일일 체결 집계, 정산 전 수량 대조 자료 만들기. 두 시스템의 결과를 맞춰 볼 때는 `005_reconcile-compare` 와 함께 쓰면 좋습니다.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
python3 main.py sample/trades.csv -o output/trade_summary.csv
```

## 입력 / 출력 예시
- 입력 열: `종목코드,종목명,구분,수량,단가,수수료` (구분은 `매수` 또는 `매도`)
- 화면 출력:
```
완료: 종목 3개, 수수료 합계 5,077 -> output/trade_summary.csv
[주의] 합계에서 뺀 줄 2개:
  8번째 줄: 구분이 '보류' 입니다(매수/매도만 가능)
  9번째 줄: 수량은 1 이상, 단가는 0 이상이어야 합니다
```
- 출력 한 줄 예: `A0001,가상전자,150,70333.33,10550000,80,72000.00,5760000,70,2447` (평균단가는 소수 둘째 자리까지)

## 주의사항
- 종목명·종목코드·금액은 모두 **가짜 예시 데이터**입니다.
- 이 스크립트는 수량·금액 집계만 합니다. 실현손익·평가손익은 취득원가 정보가 필요해서 계산하지 않습니다.
- 규칙에 어긋난 줄은 합계에서 빼고 몇 번째 줄인지 알려 줍니다. 조용히 틀린 합계가 나오지 않게 하려는 것입니다.
