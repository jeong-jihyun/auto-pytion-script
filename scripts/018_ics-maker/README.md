# 일정 CSV -> 캘린더 파일(.ics) 변환

## 무엇을 하나요?
CSV에 적은 일정을 `.ics` 파일로 만듭니다. 구글 캘린더·아웃룩·휴대폰 캘린더에서 "가져오기"로 한 번에 넣을 수 있습니다.

입력 열: `제목, 날짜(YYYY-MM-DD), 시작(HH:MM), 종료(HH:MM), 장소, 메모, 반복, 횟수`
- 시작·종료를 비우면 **하루 종일** 일정이 됩니다. 종료만 비우면 1시간짜리가 됩니다.
- 반복은 `매일` / `매주` / `매월` 중 하나, 횟수는 반복할 총 횟수입니다.

## 어떤 업무에 쓰나요?
월말 마감일·정기 회의·점검 일정을 엑셀에서 정리한 뒤 캘린더에 한꺼번에 등록.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
python3 main.py sample/schedule.csv -o output/schedule.ics --calendar-name "업무 일정"
```

## 입력 / 출력 예시
`sample/schedule.csv` 5줄 중 3개가 변환됩니다.
```
완료: 일정 3개 -> output/schedule.ics
  [건너뜀] 5번째 줄: 종료가 시작보다 빨라요
  [건너뜀] 6번째 줄: 반복을 쓰면 횟수(1 이상)도 적어야 합니다
```
(잘못 적은 줄은 일부러 넣은 예시입니다.)

## 주의사항
- 시간은 타임존 없이 "그 캘린더의 현지 시각"으로 저장됩니다. 해외 시간대 일정에는 맞지 않습니다.
- 같은 파일을 두 번 가져오면 일정이 중복될 수 있습니다. (제목+날짜+시작시각이 같으면 같은 일정 번호가 만들어지지만, 앱에 따라 처리가 다릅니다.)
- 새 캘린더를 따로 만들어서 가져오면, 잘못되었을 때 그 캘린더만 지우면 되어 안전합니다.
