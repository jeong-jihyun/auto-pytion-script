# JSON <-> CSV 변환

## 무엇을 하나요?
- `to-csv`  : JSON(객체 목록 `[{...}, {...}]`)을 CSV로. 안쪽 객체는 `고객.이름` 처럼 점으로 이은 열 이름으로 펼칩니다.
- `to-json` : CSV를 JSON 목록으로. 열 이름에 점(`.`)이 있으면 다시 안쪽 객체로 묶습니다.

## 어떤 업무에 쓰나요?
API 응답 JSON을 엑셀로 열어 보기, 엑셀로 정리한 표를 설정·테스트 데이터 JSON으로 만들기.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시
```bash
python3 main.py to-csv sample/orders.json -o output/orders.csv
python3 main.py to-json output/orders.csv -o output/back.json --infer
```

## 입력 / 출력 예시
`sample/orders.json`(3건)을 to-csv 하면:
```
id,고객.이름,고객.등급,금액,태그,메모
1,김가상,A,12000,"[""신규"", ""쿠폰""]",
2,이나가,B,8500.5,[],
3,박다예,,30000,,배송 전 연락
```
행마다 키가 달라도(3번은 `등급` 없음) 열은 처음 나온 순서대로 합쳐집니다.

## 주의사항
- 목록 값(`태그`)은 CSV 안에 JSON 글자로 저장되고, to-json 때 다시 목록으로 돌아옵니다.
- CSV의 **빈 칸은 "키 없음"** 이 됩니다(`--keep-empty` 로 빈 글자 `""` 유지).
- CSV 는 모든 값이 글자라서, 숫자로 되돌리려면 `--infer` 를 쓰세요. 단, `001` 처럼 앞에 0이 있는 코드도 숫자 1로 바뀌니 코드 열이 있으면 `--infer` 를 쓰지 마세요.
- 이름에 점이 들어 있는 원래 키(예: `"a.b"`)는 왕복 변환 때 안쪽 객체로 바뀝니다.
