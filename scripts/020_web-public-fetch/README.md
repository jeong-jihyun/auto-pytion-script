# 공개 웹페이지 제목·링크 수집 (robots.txt 준수)

## 무엇을 하나요?
주소 목록을 받아 각 페이지의 **제목, 설명(meta description), 링크 개수, 링크 목록**을 CSV로 저장합니다.
예의를 지키도록 만들었습니다.
1. 페이지마다 그 사이트의 `robots.txt` 를 먼저 확인하고, 막혀 있으면 가져오지 않습니다.
2. 요청 사이에 쉬는 시간을 둡니다(`--delay`, 기본 2초).
3. 누구인지 알 수 있는 User-Agent 를 보냅니다(`--user-agent`).
4. robots.txt 를 읽을 수 없으면(서버 오류·접속 실패) 안전하게 **수집하지 않습니다**. 이유는 화면과 CSV 에 적힙니다.

## 어떤 업무에 쓰나요?
우리 회사·협력사의 공개 공지 페이지 제목 모니터링, 링크 점검 전 목록 만들기, 공개 자료 목록 정리.

## 설치
파이썬 3.8 이상만 있으면 됩니다(표준 라이브러리만 사용).

## 실행 예시 (내 컴퓨터의 시험용 가짜 사이트로 연습)
터미널 두 개를 엽니다.

```bash
# 터미널 1: 샘플 사이트 켜기 (이 폴더에서)
cd sample/site && python3 -m http.server 8765 --bind 127.0.0.1

# 터미널 2: 수집 실행 (이 폴더에서)
python3 main.py sample/urls.txt --delay 0.3
```
회사 프록시를 쓰는 환경에서 127.0.0.1 접속이 막히면 `NO_PROXY=127.0.0.1` 을 앞에 붙이세요.

실제 사이트에 쓸 때는 `urls.txt` 에 주소를 적고, **본인 연락처를 영문으로** 넣으세요.
```bash
python3 main.py my_urls.txt --user-agent "my-script/1.0 (contact: me@example.com)"
```

## 입력 / 출력 예시
```
  [성공] http://127.0.0.1:8765/index.html -> '예시 홈페이지'
  [성공] http://127.0.0.1:8765/about.html -> '소개 페이지'
  [차단] http://127.0.0.1:8765/private/secret.html - robots.txt 가 이 주소의 수집을 막음
완료: 주소 4개 중 성공 2개 -> output/pages.csv
```
`/private/` 주소는 서버에 요청 자체를 보내지 않았습니다. (`ftp://` 주소는 http/https 가 아니라서 건너뜁니다.)

## 주의사항 (꼭 읽어 주세요)
- **사이트의 이용약관은 코드가 확인해 줄 수 없습니다.** 수집 전에 직접 읽고, 약관이 금지하면 하지 마세요.
- 로그인이 필요한 페이지, CAPTCHA 우회, 개인정보(이름·연락처 등) 수집에는 쓰지 않습니다. 공개 페이지만 대상으로 하세요.
- 쉬는 시간을 너무 줄이면 상대 서버에 부담을 줍니다. 기본값(2초) 이상을 권장합니다.
- 자바스크립트로 나중에 그려지는 내용은 가져오지 못합니다(HTML 원문만 읽음).
- `--user-agent` 에는 한글을 쓸 수 없습니다(HTTP 규칙).
