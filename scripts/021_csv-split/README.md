# CSV 나누기

## 무엇을 하나요?
큰 CSV를 두 방법으로 나눕니다. 1) --rows N: N행씩 잘라 part_001.csv ... 2) --by 열이름: 같은 값끼리 모아 값별 파일로 저장. 모든 파일에 머리글을 똑같이 붙입니다.

## 어떤 업무에 쓰나요?
엑셀이 느려지는 큰 파일 쪼개기, 지점·부서별로 나눠서 각자에게 배포하기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/021_csv-split`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/sales.csv --rows 2 -o output/rows
python3 main.py sample/sales.csv --by 지점 -o output/by_branch
```

## 입력 / 출력 예시
- 입력: sales.csv 5행(지점 3곳)
- 출력: `--rows 2` 이면 part_001~003.csv, `--by 지점` 이면 지점_서울.csv, 지점_부산.csv, 지점_대구.csv

## 주의사항
값에 파일 이름으로 못 쓰는 글자가 있으면 _ 로 바뀝니다. 원본은 수정하지 않습니다.
