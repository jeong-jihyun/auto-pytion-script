# 엑셀 시트별 CSV 변환

## 무엇을 하나요?
엑셀 파일의 시트마다 CSV 파일 하나씩을 만듭니다. 수식 칸은 마지막으로 저장된 계산 값을 씁니다.

## 어떤 업무에 쓰나요?
엑셀 자료를 다른 시스템에 올리기 전 CSV로 바꾸기, 시트가 여러 개인 파일 나누기

## 설치
파이썬 3.8 이상이 필요합니다. 이 스크립트는 외부 패키지가 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행 예시
이 폴더(`scripts/022_xlsx-to-csv`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/sales.xlsx -o output
python3 main.py sample/sales.xlsx --sheet 매출 -o output
```

## 입력 / 출력 예시
- 입력: sales.xlsx (시트 '매출', '메모')
- 출력: 매출.csv, 메모.csv (날짜는 2026-10-01 형태)

## 주의사항
엑셀에서 한 번도 저장하지 않은 수식은 값이 비어 나올 수 있습니다(엑셀에서 열어 저장하면 해결). xlsx 만 읽습니다(xls 불가).
