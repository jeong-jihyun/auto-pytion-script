# 워드 문서 글자 추출

## 무엇을 하나요?
docx 파일의 문단과 표 글자를 위에서 아래 순서로 txt 파일에 저장합니다. --find 로 지정한 낱말이 몇 번 나오는지도 셉니다. 표의 한 행은 ' | ' 로 이어 줍니다.

## 어떤 업무에 쓰나요?
보고서 내용 검색·검토, 문서 속 특정 용어 사용 횟수 확인

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/023_docx-text`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/report.docx --find 장애 -o output/report.txt
```

## 입력 / 출력 예시
- 입력: report.docx (문단 3개 + 표 1개)
- 출력: report.txt 5줄, '장애' 3번 출력

## 주의사항
머리글·바닥글·텍스트 상자·각주는 읽지 않습니다. 옛 .doc 형식은 읽을 수 없습니다.
