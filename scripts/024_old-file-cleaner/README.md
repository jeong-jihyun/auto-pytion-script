# 오래된 파일 보관 이동

## 무엇을 하나요?
폴더 안에서 마지막 수정일이 N일보다 오래된 파일을 찾아 보관 폴더(--trash)로 옮깁니다. 삭제하지 않으므로 되돌릴 수 있습니다. 기본은 미리보기이고 --apply 를 붙여야 옮깁니다.

## 어떤 업무에 쓰나요?
임시·로그 파일 정리, 공유 폴더 용량 줄이기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/024_old-file-cleaner`)에서 아래처럼 실행합니다.

```bash
# 1) 미리보기 (실제 변경 없음)
python3 main.py sample --days 0 --pattern "*_old.*"
# 2) 실제 이동
python3 main.py sample --days 0 --pattern "*_old.*" --apply
```

## 입력 / 출력 예시
- 입력: sample 폴더(파일 3개)
- 출력: 미리보기는 목록만 출력, --apply 는 old_files_out 폴더로 이동
- 샘플 파일은 수정일이 최근이라 `--days 0` 으로 시험합니다. 실제로는 `--days 90` 처럼 씁니다.

## 주의사항
처음에는 꼭 미리보기로 목록을 확인하세요. --apply 를 쓰면 원본 위치에서 파일이 사라집니다(보관 폴더에 있음). 같은 이름이 있으면 덮어쓰지 않고 번호를 붙입니다.
