# 폴더 파일 목록 만들기

## 무엇을 하나요?
폴더(하위 폴더 포함)의 파일마다 상대경로·이름·확장자·크기·수정일을 CSV 한 장으로 정리하고, 확장자별 개수·크기 합계를 화면에 보여 줍니다.

## 어떤 업무에 쓰나요?
공유 폴더 현황 파악, 이관·백업 전 파일 목록 확보

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/025_folder-inventory`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample -o output/inventory.csv
```

## 입력 / 출력 예시
- 입력: sample 폴더(하위 폴더 포함 파일 4개)
- 출력: inventory.csv 4줄 + 확장자별 요약

## 주의사항
파일은 읽기만 합니다. 파일이 아주 많으면 시간이 걸릴 수 있습니다.
