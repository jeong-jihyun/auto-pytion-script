# 날짜 형식 통일

## 무엇을 하나요?
날짜 열에 섞여 있는 여러 형식을 모두 YYYY-MM-DD 로 바꿉니다. 읽지 못하거나 없는 날짜(2026-02-30)는 원래 값을 두고 줄 번호와 함께 알려 줍니다.

## 어떤 업무에 쓰나요?
여러 부서에서 모은 자료의 날짜 맞추기, 시스템 업로드 전 형식 정리

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/026_date-normalizer`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/orders.csv --columns 주문일,배송일 -o output/orders_fixed.csv
```

## 입력 / 출력 예시
- 입력: orders.csv 5행
- 출력: orders_fixed.csv, 읽지 못한 칸 2개(없는 날짜, '어제')를 화면에 안내

## 주의사항
10/11/2026 처럼 월·일이 헷갈리는 값은 기본이 월/일/년이고, 일/월/년이면 --dayfirst 를 붙입니다. 두 자리 연도(26.10.21)는 읽지 않습니다.

## 테스트 상태
2026-10-21, 파이썬 3 로 sample 데이터를 실제 실행해 동작을 확인했습니다. 실제 업무 데이터에서는 먼저 복사본으로 시험해 보세요.
