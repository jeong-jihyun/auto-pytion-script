# 고정길이 전문 → CSV

## 무엇을 하나요?
고정길이 텍스트 파일을 항목 규칙(이름, 시작 위치, 길이)에 따라 잘라 CSV로 만듭니다. 위치·길이는 바이트 기준이라 한글(cp949)도 정확히 잘립니다.

## 어떤 업무에 쓰나요?
금융 기관·증권사와 주고받는 전문 파일 확인, 대사 전 데이터 변환

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/027_fixed-width`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/trades.txt --spec sample/spec.json --encoding cp949 -o output/trades.csv
```

## 입력 / 출력 예시
- 입력: trades.txt(cp949, 3줄), spec.json(항목 4개)
- 출력: trades.csv (종목코드, 종목명, 수량, 단가)

## 주의사항
시작 위치는 1부터 셉니다. 줄이 규칙보다 짧으면 경고를 냅니다. 파일 인코딩이 다르면 --encoding utf-8 처럼 지정하세요.
