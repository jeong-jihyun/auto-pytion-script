# 환경설정(.env) 점검

## 무엇을 하나요?
.env.example(필요한 키 목록)과 실제 .env 를 비교해 빠진 키, 값이 빈 키, 예시에 없는 키를 알려 줍니다. 비밀번호 보호를 위해 값은 절대 출력하지 않고 키 이름만 보여 줍니다. 문제가 있으면 종료 코드 1을 돌려줍니다.

## 어떤 업무에 쓰나요?
배포·배치 실행 전 설정 점검, 신규 담당자 환경 세팅 확인

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/028_env-check`)에서 아래처럼 실행합니다.

```bash
python3 main.py --example sample/.env.example --env sample/env_sample.txt
```

## 입력 / 출력 예시
- 입력: .env.example(키 5개), env_sample.txt(가짜 값)
- 출력: 빠진 키 API_KEY, 빈 키 DB_PASSWORD, 예시에 없는 키 DEBUG, 결과 '문제 있음'

## 주의사항
샘플의 값은 모두 가짜입니다. 실제 .env 는 저장소에 올리지 마세요(.gitignore 에 .env 가 들어 있습니다).
