# CSV 열 요약(프로파일링)

## 무엇을 하나요?
CSV를 받으면 열마다 채워진 칸·빈 칸·서로 다른 값 수를 세고, 숫자 열이면 최소·최대·합계·평균, 글자 열이면 가장 많이 나온 값 3개를 보여 줍니다. 결과는 화면과 CSV로 나옵니다.

## 어떤 업무에 쓰나요?
새로 받은 데이터 훑어보기, 빈칸·이상값이 있는 열 빨리 찾기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/029_csv-profile`)에서 아래처럼 실행합니다.

```bash
python3 main.py sample/accounts.csv -o output/profile.csv
```

## 입력 / 출력 예시
- 입력: accounts.csv 5행 4열
- 출력: profile.csv (열마다 한 줄) + 화면 요약

## 주의사항
'1,500,000' 처럼 쉼표가 든 숫자도 숫자로 읽습니다. 날짜는 글자로 취급합니다.
