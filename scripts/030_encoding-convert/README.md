# 텍스트 인코딩 변환(cp949↔utf-8)

## 무엇을 하나요?
폴더 안 파일의 원래 인코딩(utf-8 또는 cp949)을 알아내 --to 로 정한 인코딩으로 새 폴더에 저장합니다. 원본은 건드리지 않고, 기본은 미리보기이며 --apply 를 붙여야 파일을 만듭니다.

## 어떤 업무에 쓰나요?
엑셀·구형 시스템 파일 한글 깨짐 해결, 시스템 업로드용 인코딩 맞추기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 따로 설치할 패키지는 없습니다(표준 라이브러리만 사용).

## 실행 예시
이 폴더(`scripts/030_encoding-convert`)에서 아래처럼 실행합니다.

```bash
# 미리보기
python3 main.py sample
# 실제 변환 (새 폴더에 저장)
python3 main.py sample --apply -o converted_out
```

## 입력 / 출력 예시
- 입력: cp949_sample.csv, utf8_sample.csv
- 출력: cp949 파일만 utf-8(BOM 포함, 엑셀에서 바로 열림)로 converted_out 에 저장, utf-8 파일은 건너뜀

## 주의사항
자동 판별은 utf-8 → cp949 순서로 시도합니다. 둘 다 아니면(예: utf-16) 실패로 알려 줍니다. cp949 에 없는 글자는 변환 실패로 표시합니다.
