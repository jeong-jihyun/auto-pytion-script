# 031 CSV 열 고르기·이름 바꾸기

## 무엇을 하나요?
CSV에서 **필요한 열만 남기고**, **열 이름을 바꾸고**, **열 순서를 바꿉니다.**

## 어떤 업무에 쓰나요?
- 다른 시스템에 올리려면 "열 이름이 이래야 해요" 할 때
- 메모·내부용 열을 빼고 파일을 전달할 때

## 설치
파이썬 3.8 이상이면 끝입니다. 따로 설치할 것이 없습니다.

## 실행 예시
```
python3 main.py sample/orders.csv --keep 주문번호,상품,수량 --rename 상품:품목,수량:개수 -o output/result.csv
```

## 입력 / 출력 예시
입력 `주문번호,고객명,상품,수량,단가,메모` → 출력 `주문번호,품목,개수` (3열만)

## 주의사항
- 입력 파일은 바꾸지 않고 **새 파일**로 저장합니다.
- 없는 열 이름을 적으면 오류로 알려 줍니다(오타 확인용).
- 결과 폴더 `output/` 은 저장소에 올라가지 않습니다.
