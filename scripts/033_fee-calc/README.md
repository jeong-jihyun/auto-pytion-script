# 033 구간별 수수료 계산·정산서

## 무엇을 하나요?
거래 금액에 따라 **수수료율이 달라지는 규칙**(JSON)대로 거래마다 수수료를 계산하고, **고객별 정산서**를 만듭니다.

## 어떤 업무에 쓰나요?
증권·결제·대행 수수료 정산, 가맹점 정산, 월말 수수료 점검.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/trades.csv sample/rules.json -o output
```

## 입력 / 출력 예시
- 입력 거래 `500,000원` → 100만 원 이하 구간(0.15%) → 수수료 750원
- 입력 거래 `30,000원` → 0.15%는 45원이지만 **최소수수료 100원** 적용
- 출력: `fee_detail.csv`(거래별), `fee_summary.csv`(고객별 합계)

## 주의사항
- 금액을 읽을 수 없는 줄은 건너뛰고 화면에 알려 줍니다.
- 구간은 "금액 전체에 한 요율"을 적용하는 방식입니다(누진 방식이 아님). 실제 업무 규칙과 다르면 규칙 해석을 꼭 확인하세요.
- 예시 데이터와 요율은 연습용 가짜입니다.
