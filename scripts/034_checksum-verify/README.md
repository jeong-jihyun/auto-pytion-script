# 034 파일 무결성 점검 (체크섬)

## 무엇을 하나요?
폴더의 모든 파일을 **지문(SHA-256 해시)** 으로 기록해 두고, 나중에 다시 비교해서 **바뀐 파일 / 없어진 파일 / 새로 생긴 파일**을 알려 줍니다.

## 어떤 업무에 쓰나요?
파일 이관·백업 후 빠짐없이 옮겨졌는지 확인, 전달받은 자료가 변조·손상되지 않았는지 확인.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음.

## 실행 예시
```
# 1) 지문 목록 만들기
python3 main.py make sample/data -m output/manifest.sha256
# 2) 나중에 검사하기
python3 main.py verify sample/data -m output/manifest.sha256
```

## 입력 / 출력 예시
`data/b.csv` 의 내용을 한 글자라도 바꾸고 verify 하면 `[바뀜] b.csv` 가 나옵니다. 끝 코드는 문제가 있으면 1, 없으면 0 이라 배치 점검에도 쓸 수 있습니다.

## 주의사항
- 파일은 읽기만 합니다(삭제·수정 없음).
- 목록(manifest)은 `sha256sum` 과 같은 `해시  경로` 모양입니다.
- 새로 생긴 파일만 있으면 "이상 없음 아님"으로 표시되지만 끝 코드는 0 입니다.
