# 035 거래처별 청구서(docx) 만들기

## 무엇을 하나요?
품목 표(CSV)를 읽어 **거래처마다 워드 청구서 1장**을 만듭니다. 공급가액·부가세(10%)·합계를 자동 계산합니다.

## 어떤 업무에 쓰나요?
월말 청구서 작성, 견적서·거래명세서 양식 반복 작업.

## 설치
```
pip install -r requirements.txt
```

## 실행 예시
```
python3 main.py sample/items.csv -o output --date 2026-10-22
```

## 입력 / 출력 예시
입력 열: `거래처,품목,수량,단가` → 출력: `output/청구서_가나다상사.docx` 등 거래처 수만큼.
수량이 숫자가 아닌 줄(예: `x`)은 건너뛰고 화면에 알려 줍니다.

## 주의사항
- 부가세는 공급가액의 10%, 원 미만 버림으로 계산합니다. 회사 규칙이 다르면 코드의 `vat` 줄을 고치세요.
- 양식은 가장 단순한 형태입니다. 회사 로고·직인은 넣지 않았습니다.
- 예시 거래처·금액은 가짜입니다.
