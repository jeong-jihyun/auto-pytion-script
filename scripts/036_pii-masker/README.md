# 036 개인정보 마스킹

## 무엇을 하나요?
CSV의 **이름·전화번호·이메일·주민번호 형태·카드번호** 열을 `*` 로 가려서 새 파일로 저장합니다.

## 어떤 업무에 쓰나요?
외부 업체에 자료를 보내기 전, 개발·테스트용 데이터를 만들 때, 보고서에 고객 정보가 그대로 나가지 않게 할 때.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/customers.csv --mask 고객명:name,전화:phone,이메일:email,주민번호:id,카드번호:card -o output/masked.csv
```

## 입력 / 출력 예시
| 종류 | 입력 | 출력 |
|---|---|---|
| name | 홍길동 | 홍*동 |
| phone | 010-1234-5678 | 010-****-5678 |
| email | hong@example.com | h***@example.com |
| id | 900101-1234567 | 900101-******* |
| card | 1234-5678-9012-3456 | ****-****-****-3456 |

## 주의사항
- **내 회사·내 데이터를 보호**하는 용도입니다. 남의 개인정보를 수집하는 용도로 쓰지 마세요.
- 마스킹은 완전한 익명화가 아닙니다. 가리지 않은 다른 열(메모 등)에 개인정보가 있는지 꼭 확인하세요.
- 예시 데이터는 모두 가짜입니다.
