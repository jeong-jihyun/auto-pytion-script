# 037 일정·예약 겹침 찾기

## 무엇을 하나요?
예약표에서 **같은 회의실·차량·장비를 같은 시간에 잡은 예약 쌍**을 찾아 줍니다.

## 어떤 업무에 쓰나요?
회의실/차량 예약 점검, 교대 근무표 중복 확인, 점검 작업 일정 충돌 확인.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/reservations.csv -o output/conflicts.csv
```

## 입력 / 출력 예시
회의실A의 김하나(09:00~10:00)와 이두리(09:30~11:00)는 겹침 → 결과에 표시.
박세모(11:00~)는 이두리가 끝나는 11:00에 시작하므로 **겹침 아님**.
종료가 시작보다 빠른 잘못된 줄은 건너뛰고 알려 줍니다.

## 주의사항
- 시간은 `2026-10-22 09:00` 또는 `2026/10/22 09:00` 형식입니다.
- 같은 이름이라도 자원 이름이 다르면(회의실A/회의실B) 따로 검사합니다.
- 예약 파일은 읽기만 합니다.
