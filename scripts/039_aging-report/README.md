# 039 미수금 연령 분석 (에이징 리포트)

## 무엇을 하나요?
못 받은 돈(청구액 − 입금액)을 **청구일로부터 지난 날짜 구간**(30일 이하/31~60/61~90/90일 초과)으로 나눠 거래처별 표로 만듭니다.

## 어떤 업무에 쓰나요?
채권 관리, 월말 미수금 점검, 독촉 대상 선별.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/receivables.csv --base-date 2026-10-22 -o output/aging.csv
```

## 입력 / 출력 예시
기준일 2026-10-22 에 가나다상사의 `2026-10-10` 청구 100만 원(미입금)은 12일 지남 → "30일 이하". `2026-08-20` 청구 30만 원 미수는 63일 → "61~90일". 다 받은 건은 제외, 날짜를 못 읽은 줄은 건너뛰고 알려 줍니다.

## 주의사항
- 기준일을 꼭 정해서 실행하면 같은 결과를 다시 만들 수 있습니다.
- 청구일 기준 계산입니다. 납기일 기준이 필요하면 `billed` 를 납기일 열로 바꾸세요.
- 예시 금액과 거래처는 가짜입니다.
