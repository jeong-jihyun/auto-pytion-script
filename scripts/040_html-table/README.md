# 040 HTML 표 → CSV 변환

## 무엇을 하나요?
저장해 둔 **HTML 파일 속 표(`<table>`)를 찾아 CSV로 저장**합니다. 표가 여러 개면 표마다 파일이 하나씩 생깁니다.

## 어떤 업무에 쓰나요?
시스템이 HTML로 내보낸 보고서를 엑셀에서 열고 싶을 때, 저장해 둔 웹 화면의 표를 정리할 때.

## 설치
파이썬 3.8 이상. 따로 설치할 것 없음. (인터넷 접속 없이 내 컴퓨터의 파일만 읽습니다.)

## 실행 예시
```
python3 main.py sample/report.html -o output
```

## 입력 / 출력 예시
`report.html` 에 표가 2개 → `report_table1.csv`(지점,매출), `report_table2.csv`(배치,상태,비고).
칸 안의 줄바꿈(`<br>`)은 공백으로, `&amp;` 같은 특수문자는 원래 글자로 바뀝니다.

## 주의사항
- 표 안에 또 표가 있는 경우 바깥 표만 읽습니다.
- 칸 합치기(colspan/rowspan)는 처리하지 않아 해당 표는 칸이 어긋날 수 있습니다.
- 한글이 깨지면 `--encoding cp949` 를 써 보세요.
