# 041 zip 일괄 풀기

## 무엇을 하나요?
폴더 안에 있는 **zip 파일을 전부 한 번에 풉니다.** zip마다 이름이 같은 폴더를 만들어 그 안에 풀기 때문에 파일이 뒤섞이지 않습니다.

## 어떤 업무에 쓰나요?
- 월별로 받은 zip 첨부파일 12개를 한꺼번에 풀 때
- 거래처에서 받은 압축파일을 정리할 때

## 설치
파이썬 3.8 이상이면 됩니다. 따로 설치할 것이 없습니다.

## 실행 예시
```
# 1) 미리보기 (아무것도 풀지 않음)
python3 main.py sample
# 2) 실제로 풀기
python3 main.py sample -o output/unzipped --apply
```

## 입력 / 출력 예시
입력: `2026-09_sales.zip`, `2026-10_sales.zip` → 출력: `output/unzipped/2026-09_sales/sales_a.csv` …

## 주의사항
- 기본은 **미리보기**입니다. `--apply` 를 붙여야 풀립니다.
- 이미 같은 이름 폴더가 있으면 **덮어쓰지 않고 건너뜁니다.**
- zip 안에 `../evil.txt` 처럼 밖으로 나가는 경로가 있으면 그 파일만 무시합니다(샘플에 일부러 넣어 두었습니다).
- 비밀번호가 걸린 zip은 지원하지 않습니다.
