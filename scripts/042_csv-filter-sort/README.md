# 042 CSV 행 거르기·정렬

## 무엇을 하나요?
CSV에서 **조건에 맞는 행만 남기고**, 원하는 열 기준으로 **정렬**해 새 CSV로 저장합니다. (엑셀의 필터 + 정렬과 같습니다.)

## 어떤 업무에 쓰나요?
- "서울 지점이고 10만 원 이상인 주문만 뽑아 줘" 같은 요청
- 큰 파일에서 필요한 행만 추려 보낼 때

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/orders.csv --where "지점 == 서울" --where "금액 >= 50000" --sort 금액 --desc -o output/seoul.csv
```
조건 연산자: `==  !=  >  >=  <  <=  contains`(포함)

## 입력 / 출력 예시
입력 6행 → 서울 + 5만 원 이상 → 2행(노트북 120만, 키보드 8.9만)이 금액 큰 순으로 저장됩니다.

## 주의사항
- 조건 여러 개는 **모두 만족**해야 남습니다(AND).
- 숫자처럼 보이면(쉼표 포함) 숫자로 비교합니다.
- 원본 파일은 바꾸지 않습니다.
