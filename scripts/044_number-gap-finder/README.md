# 044 일련번호 누락·중복 찾기

## 무엇을 하나요?
전표번호·주문번호처럼 **1씩 이어져야 하는 번호**에서 **빠진 번호**와 **두 번 나온 번호**를 찾아 줍니다.

## 어떤 업무에 쓰나요?
- 월말 마감 때 전표 번호가 빠지지 않았는지 점검
- 세금계산서·주문서 번호 누락 확인 (ERP 감사 대응)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/vouchers.csv --column 전표번호 -o output/gaps.csv
```

## 입력 / 출력 예시
`INV-2026-0001, 0002, 0004, 0005, 0005, 0008` → 누락 0003·0006·0007, 중복 0005 로 알려 줍니다. `PO-` 번호는 따로 묶어서 검사합니다.

## 주의사항
- 번호 끝이 숫자여야 합니다. 숫자로 끝나지 않으면 "형식오류"로 따로 표시합니다.
- 접두어가 같은 것끼리 한 그룹으로 보고, 그 그룹의 최소~최대 사이에서만 누락을 찾습니다.
- 번호가 건너뛰는 게 정상인 체계(예: 5씩 증가)에는 맞지 않습니다.
