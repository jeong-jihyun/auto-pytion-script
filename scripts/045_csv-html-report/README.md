# 045 CSV를 HTML 보고서로

## 무엇을 하나요?
CSV를 **보기 좋은 표 한 장짜리 HTML 파일**로 바꿉니다. 숫자는 쉼표가 붙고 오른쪽 정렬, 원하는 열은 맨 아래에 합계가 붙습니다.

## 어떤 업무에 쓰나요?
- 메일에 붙여 보낼 간단한 보고서
- 브라우저에서 인쇄 → "PDF로 저장" 으로 보고용 PDF 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/sales.csv --title "10월 지점별 매출" --sum-cols 수량,매출 -o output/report.html
```
만들어진 `output/report.html` 을 더블클릭하면 브라우저에서 열립니다.

## 입력 / 출력 예시
입력 4행 → 표 4행 + 합계 행(수량 29, 매출 7,900,000).

## 주의사항
- 열의 값이 전부 숫자일 때만 숫자 열로 취급합니다(전화번호처럼 0으로 시작하는 값은 글자로 두는 게 안전).
- 내용은 HTML 이스케이프 처리되어 `<` 같은 글자가 있어도 깨지지 않습니다.
