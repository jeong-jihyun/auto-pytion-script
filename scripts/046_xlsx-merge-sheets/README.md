# 046 엑셀 파일을 시트로 모으기

## 무엇을 하나요?
폴더에 흩어진 **엑셀 파일 여러 개를 한 파일**로 모읍니다. 파일 하나가 시트 하나가 되고, 맨 앞에 **목차 시트**가 생깁니다.

## 어떤 업무에 쓰나요?
- 지점별로 따로 받은 엑셀을 한 통합 문서로 묶어 볼 때
- 월별 파일 12개를 한 파일 안에서 시트로 넘겨 보고 싶을 때

(참고: 001은 CSV 합치기, 022는 엑셀→CSV 변환이라 기능이 다릅니다.)

## 설치
```
pip install -r requirements.txt
```

## 실행 예시
```
python3 main.py sample -o output/merged.xlsx
```

## 입력 / 출력 예시
`seoul_sales.xlsx`, `busan_sales.xlsx`, `daegu_sales.xlsx` → `merged.xlsx` (시트: 목차, busan_sales, daegu_sales, seoul_sales)

## 주의사항
- 각 파일의 **첫 번째 시트만** 가져옵니다.
- 값만 복사합니다. 서식(색, 열 너비)과 수식은 가져오지 않습니다.
- 시트 이름은 파일 이름(31자까지)입니다. 같은 이름이면 `_2` 가 붙습니다.
- 원본은 바꾸지 않습니다.
