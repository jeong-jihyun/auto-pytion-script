# 047 키워드 줄 추출

## 무엇을 하나요?
폴더 안의 텍스트·로그 파일에서 **키워드가 들어 있는 줄만** 골라 `파일, 줄번호, 줄내용` CSV로 모읍니다.

## 어떤 업무에 쓰나요?
- 여러 로그에서 "ERROR", "timeout" 이 나온 줄만 한 번에 모아 볼 때
- 회의록 여러 개에서 특정 단어가 나온 곳 찾기

(참고: 004는 로그 통계 요약이고, 이 스크립트는 해당 줄을 그대로 뽑는 검색입니다.)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample -k ERROR -k timeout -i -o output/hits.csv
```
`-i` 는 대소문자 무시, `--ext .txt,.log` 로 검사할 확장자를 바꿀 수 있습니다.

## 입력 / 출력 예시
`batch1.log 2줄째 ERROR ...`, `memo.txt 3줄째 Timeout ...` 같은 줄이 CSV에 쌓입니다.

## 주의사항
- 하위 폴더까지 모두 찾습니다.
- utf-8로 안 읽히면 cp949로 읽어 봅니다. 둘 다 안 되면 그 파일은 건너뜁니다.
- 원본은 바꾸지 않습니다.
