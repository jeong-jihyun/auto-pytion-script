# 048 기념일·만기일 D-day 계산

## 무엇을 하나요?
이름과 날짜 목록을 읽어 **오늘 기준 며칠 남았는지(D-day)** 를 계산하고 가까운 순서로 정리합니다.

## 어떤 업무에 쓰나요?
- 팀원 생일·입사 기념일 챙기기
- 계약 만기, 자격증 갱신일, 라이선스 만료일 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/events.csv --today 2026-10-23 --within 90 -o output/dday.csv
```
(`--today` 를 빼면 실행한 날이 기준입니다.)

## 입력 / 출력 예시
입력 열: `이름,날짜,종류(매년/한번)`. 출력 예: `D-2 김대리 생일 (2026-10-25)`, `D-10 이과장 입사기념일`, `D-69 A사 계약 만기`.

## 주의사항
- `매년` 은 해마다 반복(생일 등), `한번` 은 그 날짜 한 번만(계약 만기).
- 날짜는 `YYYY-MM-DD` 만 읽습니다. 형식이 다르면 그 행은 건너뛰고 알려 줍니다(날짜 형식 통일은 026번 참고).
- 2월 29일 생일은 평년에 2월 28일로 계산합니다.
- 샘플 이름은 가짜입니다.
