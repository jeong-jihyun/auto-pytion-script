# 049 종가 이동평균·수익률·최대낙폭

## 무엇을 하나요?
날짜별 종가 CSV로 **이동평균(5일·20일 등)**, **일간 수익률**, **기간 수익률**, **최대 낙폭(MDD)** 을 계산합니다.

## 어떤 업무에 쓰나요?
- 지수·종목·환율·원자재 가격 추이를 간단히 점검할 때
- 가격 데이터 검증 업무에서 이상 변동 확인

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/price.csv --windows 5,20 -o output/ma.csv
```

## 입력 / 출력 예시
입력 `날짜,종가` → 출력 `날짜,종가,일간수익률(%),MA5,MA20`. 화면에 `기간 수익률 ...% / 최대 낙폭 ...%` 가 나옵니다. 샘플 가격은 **난수로 만든 가짜 데이터**입니다.

## 주의사항
- 이동평균은 기간만큼 데이터가 쌓이기 전에는 빈 칸입니다.
- 날짜 순서로 자동 정렬합니다(`YYYY-MM-DD` 형식).
- 배당·액면분할 조정은 하지 않습니다. **투자 판단 자료가 아닙니다.**
