# 050 필수 파일 도착 점검

## 무엇을 하나요?
"오늘 날짜 파일이 와 있나?"를 자동으로 확인합니다. **없음 / 크기 0 / 너무 작음 / 너무 오래됨** 을 찾아 표로 정리합니다.

## 어떤 업무에 쓰나요?
- 아침 배치 시작 전에 전일 체결·정산·시세 파일이 다 들어왔는지 확인
- 거래처가 보내는 일일 파일의 누락 점검

(참고: 016은 배치 "실행 결과"를 점검하고, 이 스크립트는 "입력 파일 도착"을 점검합니다.)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample --rules sample/rules.json --today 2026-10-23 -o output/arrival.csv
```
규칙 JSON 항목: `pattern`(필수, `{date:%Y%m%d}` 사용 가능), `min_bytes`, `max_age_hours`, `label`.

## 입력 / 출력 예시
체결 파일 OK, 정산 파일 EMPTY, 시세 파일 SMALL, 대사 결과 파일 MISSING 처럼 상태가 나옵니다.

## 주의사항
- 문제가 하나라도 있으면 **종료 코드 1** 로 끝납니다(다른 스크립트와 연결하기 쉽게).
- `*` 같은 와일드카드를 쓸 수 있고, 여러 파일이 맞으면 가장 최근 수정 파일을 봅니다.
- 샘플 파일 수정 시각은 만든 시점이라, 마스터 파일의 STALE 여부는 실행 시점에 따라 다릅니다.
