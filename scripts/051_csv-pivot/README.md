# 051 CSV 피벗(교차표) 만들기

## 무엇을 하나요?
CSV 한 장을 엑셀의 피벗 테이블처럼 **행 x 열 교차표**로 바꿉니다. 칸마다 합계·건수·평균을 계산하고, 오른쪽 끝과 아래 끝에 합계를 붙입니다.

## 어떤 업무에 쓰나요?
- 지점별 x 월별 매출표 만들기
- 부서별 x 항목별 경비 집계
- 엑셀을 열지 않고 빠르게 크로스 집계가 필요할 때

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/sales.csv --rows 지점 --cols 월 --value 금액 --agg sum -o output/pivot.csv
python3 main.py sample/sales.csv --rows 지점 --cols 상품 --agg count
```

## 입력 / 출력 예시
입력: 지점·월·상품·금액 열이 있는 CSV.
출력(합계): 첫 줄 `지점,2026-08,2026-09,합계`, 서울 행에는 1,500,000 / 1,500,000 / 3,000,000 처럼 나옵니다.

## 주의사항
- 금액에 쉼표(1,200,000)가 있어도 읽습니다. 숫자가 아닌 칸("주문취소")은 건너뛰고 몇 개인지 알려 줍니다.
- 평균(avg)의 맨 아래 합계 줄은 '전체 평균'이지 칸 평균의 합이 아닙니다.
- 원본은 바꾸지 않고 새 파일(기본 output/)에만 씁니다.
