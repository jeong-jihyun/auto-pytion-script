# 052 이상치(튀는 값) 찾기

## 무엇을 하나요?
숫자 열에서 다른 값들과 동떨어진 값을 찾아 CSV로 모아 줍니다. 방법은 IQR(사분위 범위)과 z-score(평균에서 떨어진 정도) 두 가지입니다.

## 어떤 업무에 쓰나요?
- 경비·정산 금액에서 0이 하나 더 붙은 입력 실수 찾기
- 월말 마감 전 데이터 이상 점검(대사 전 사전 점검)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/expenses.csv --column 금액 --method iqr -o output/outliers.csv
python3 main.py sample/expenses.csv --column 금액 --method zscore --k 2.5
```

## 입력 / 출력 예시
샘플의 `1800000`(보통 1~2만원대 사이에 하나만 튐)은 "너무 큼", `대기`는 "숫자 아님"으로 나옵니다. 출력 CSV 맨 앞에 원본 줄번호가 붙습니다.

## 주의사항
- 이상치는 오류가 아니라 **확인 대상**입니다. 진짜 큰 거래일 수도 있습니다.
- 값이 4개 미만이면 계산하지 않습니다.
- z-score는 이상치 하나가 평균을 끌어당기므로 값이 적을 때는 IQR이 더 잘 맞습니다.
