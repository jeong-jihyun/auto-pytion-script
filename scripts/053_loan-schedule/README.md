# 053 대출 상환 일정표

## 무엇을 하나요?
원금·연 이자율·개월 수를 넣으면 회차별 상환원금, 이자, 납입액, 남은 원금 표를 CSV로 만듭니다. 원리금균등, 원금균등, 만기일시 세 방식을 지원합니다.

## 어떤 업무에 쓰나요?
- 대출·리스 상환 계획을 미리 보기
- 방식별 총 이자 비교(어느 쪽이 이자가 적은지)
- 금융 상품 화면의 계산 결과를 검증하는 간단한 대조용

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --principal 10000000 --rate 5.0 --months 12 --method equal-payment
python3 main.py --principal 10000000 --rate 5.0 --months 12 --method equal-principal -o output/p.csv
```
`sample/cases.csv` 는 비교해 볼 만한 조건 예시 목록입니다(스크립트가 읽지는 않음).

## 입력 / 출력 예시
1,000만원, 연 5%, 12개월 원리금균등이면 매달 약 856,075원을 내고 총 이자는 약 27만원입니다.

## 주의사항
- 월 이율 = 연 이율 / 12 로 단순 계산한 **추정치**입니다. 실제 은행의 일할 계산과 다를 수 있습니다.
- 마지막 회차에서 반올림 오차를 맞춰서 남은 원금이 정확히 0이 됩니다.
- 금융 조언이 아니라 계산 연습용입니다.
