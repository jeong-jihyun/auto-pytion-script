# 054 로그 응답시간 통계

## 무엇을 하나요?
접속(액세스) 로그에서 주소별로 **건수, 평균, 중앙값(p50), p95, 최대, 느린 요청 수, 5xx 오류 비율**을 계산해 CSV로 만듭니다. p95가 큰 주소부터 정렬합니다.

## 어떤 업무에 쓰나요?
- 어떤 API가 느린지 찾기(성능 점검, 장애 후 원인 분석)
- 배치·온라인 시스템의 아침 점검 자료 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/access.log --slow-ms 1000 -o output/response_stats.csv
```
로그 형식이 다르면 `--pattern` 에 정규식을 넣습니다(그룹 이름 path, status, ms 필요).

## 입력 / 출력 예시
`2026-10-24 09:00:01 GET /api/order 200 120ms` 같은 줄을 읽어, 예를 들어 `/api/report` 의 p95=3100ms, 5xx 비율 33.3% 처럼 정리합니다.

## 주의사항
- p95는 "가까운 순위" 방식입니다. 건수가 적으면 p95가 최대값과 같아질 수 있습니다.
- `?id=7` 처럼 물음표 뒤는 떼고 같은 주소로 묶습니다.
- 형식이 맞지 않는 줄은 건너뛰고 개수를 알려 줍니다.
