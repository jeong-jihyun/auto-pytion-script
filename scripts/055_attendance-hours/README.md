# 055 근태(근무시간) 집계

## 무엇을 하나요?
출근·퇴근 시각 CSV로 하루 근무시간, 초과근무, 지각을 계산하고 사람별 합계표(summary.csv)를 만듭니다.

## 어떤 업무에 쓰나요?
- 월말 근태 집계 초안 만들기
- 초과근무 시간 확인(프로젝트 막바지 야근 파악)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/clock.csv --lunch 60 --standard 480 --start 09:00 -o output
```

## 입력 / 출력 예시
입력 열: `사번,이름,날짜,출근,퇴근`. 출력: `daily.csv`(일별), `summary.csv`(사람별 총 근무·초과·지각). 퇴근이 출근보다 이르면(22:00→06:00) 다음 날 퇴근으로 계산합니다.

## 주의사항
- 회사마다 휴게시간·연장근로 기준이 다릅니다. 이 결과는 **참고용 초안**이며 법정 수당 계산이 아닙니다.
- 4시간 미만 근무는 점심시간을 빼지 않습니다.
- 시간을 읽을 수 없는 줄은 건너뛰고 "확인 필요"로 알려 줍니다.
