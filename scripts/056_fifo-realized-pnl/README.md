# 056 선입선출(FIFO) 실현손익 계산

## 무엇을 하나요?
매수·매도 내역에서 **먼저 산 것부터 먼저 판 것으로 짝지어** 매도 건마다 실현손익을 계산합니다. 매도 후 남은 보유 수량과 평균 단가도 만듭니다.

## 어떤 업무에 쓰나요?
- 체결내역으로 손익이 맞는지 간이 점검(대사 전 확인)
- 재고 자산의 출고 원가를 선입선출로 계산할 때(주식 대신 품목으로 바꿔 사용)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/trades.csv --sell-cost-rate 0.2 -o output
```

## 입력 / 출력 예시
샘플: 가상전자 100주(7만원)+50주(7.2만원) 매수 후 120주 매도 → 100주는 7만원짜리, 20주는 7.2만원짜리와 짝지어 손익을 계산합니다. `realized.csv`(매도별 손익), `holdings.csv`(남은 보유)가 나옵니다. 가상화학은 보유 30주인데 40주를 팔아서 "보유보다 많음" 오류로 제외됩니다.

## 주의사항
- 가상의 종목 이름과 숫자입니다. 실제 세금·손익 신고는 증권사 자료를 따르세요.
- 일자는 `YYYY-MM-DD` 형식이어야 순서가 맞습니다.
- 수수료/세금은 매도금액의 일정 비율로만 계산하는 단순화입니다.
