# 057 엑셀 문제 칸 찾기

## 무엇을 하나요?
엑셀(xlsx) 파일을 읽기만 하면서 **#REF!·#DIV/0! 같은 오류 값, 깨진 수식, 숫자인데 글자로 저장된 칸, 외부 파일 링크 수식**을 찾아 CSV로 정리합니다.

## 어떤 업무에 쓰나요?
- 보고서를 보내기 전 엑셀 최종 점검
- 합계가 안 맞을 때 원인 찾기(글자로 저장된 숫자는 SUM에서 빠집니다)
- 남이 만든 엑셀에서 끊어진 링크 확인

## 설치
```
pip install -r requirements.txt
```

## 실행 예시
```
python3 sample/make_sample.py          # 샘플 book.xlsx 만들기 (이미 있으면 생략)
python3 main.py sample/book.xlsx -o output/xlsx_issues.csv
```

## 입력 / 출력 예시
샘플에서 `B3`의 "2,500"(글자), `B4`의 #DIV/0!, `D2`의 `=SUM(#REF!)`, `D3`의 외부 링크를 찾아 줍니다.

## 주의사항
- 원본 파일은 수정하지 않습니다.
- 수식의 계산 결과는 엑셀이 마지막에 저장할 때의 값(캐시)입니다. 파이썬으로 만든 파일은 캐시가 없어 오류 값 검사가 안 될 수 있습니다.
- 숫자처럼 보이는 글자(전화번호 같은 것)도 후보로 나올 수 있으니 사람이 확인하세요.
