# 058 크론 다음 실행 시각 계산

## 무엇을 하나요?
`30 2 * * 1-5` 같은 크론 표현식이 **언제 실행되는지** 앞으로 N번의 날짜·시각을 계산해 보여 줍니다. 여러 개를 파일로 한꺼번에 점검할 수도 있습니다. 작업을 실제로 실행하지는 않습니다.

## 어떤 업무에 쓰나요?
- 배치 스케줄이 의도한 시각에 도는지 사전 확인
- 여러 배치가 같은 시각에 몰리는지 비교
- 크론식을 잘못 썼는지(범위 밖 숫자 등) 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --expr "30 2 * * 1-5" --from "2026-10-24 12:00" -n 5
python3 main.py --file sample/jobs.txt --from "2026-10-24 12:00" -n 3
```

## 입력 / 출력 예시
`--file` 은 `이름|크론식` 형식(`#`로 시작하면 주석). 출력 예: `일일 정산 배치 [30 2 * * 1-5] -> 10-26(Mon) 02:30, 10-27(Tue) 02:30 ...`. 잘못된 식은 어느 칸이 틀렸는지 알려 주고 종료 코드 1로 끝납니다.

## 주의사항
- 지원: 숫자, `*`, 범위, 목록, 간격(`*/5`). `@daily` 같은 별칭과 `L` 같은 확장 문법은 지원하지 않습니다.
- 일(日)과 요일을 둘 다 쓰면 "둘 중 하나만 맞아도" 실행됩니다(표준 크론 규칙).
- 서버 시간대와 이 PC 시간대가 다르면 결과가 다를 수 있습니다.
