# 059 감사·검수용 표본 추출

## 무엇을 하나요?
전표·주문 같은 CSV에서 검수할 **표본**을 무작위 또는 일정 간격(계통)으로 뽑습니다. 금액이 큰 건은 상위 K건을 반드시 포함시킬 수 있고, 뽑은 방법과 씨앗값(seed)을 기록해 둡니다.

## 어떤 업무에 쓰나요?
- 월말 전표 샘플 검토, 내부 통제 점검
- 전수 확인이 어려운 대량 데이터의 품질 검수

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/vouchers.csv -n 8 --method random --seed 2026 --amount-col 금액 --top-amount 2 -o output
python3 main.py sample/vouchers.csv -n 8 --method systematic
```

## 입력 / 출력 예시
40건 중 큰 금액 2건 + 무작위 8건 = 10건이 `sample.csv`에 나오고(원본 줄번호, 구분 열 포함), `sample_summary.txt`에 방법·seed·모집단 크기가 남습니다. 같은 seed로 다시 돌리면 같은 결과가 나옵니다.

## 주의사항
- 통계적으로 엄밀한 감사 표본 크기를 정해 주지는 않습니다. 건수는 업무 기준에 따라 사람이 정하세요.
- 계통 추출은 데이터가 주기적으로 반복되는 경우 치우칠 수 있습니다.
- 원본 파일은 바꾸지 않습니다.
