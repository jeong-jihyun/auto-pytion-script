# 060 비슷한 이름 중복 후보 찾기

## 무엇을 하나요?
거래처명·고객명 목록에서 `(주)가나다상사` / `가나다상사 주식회사` / `가나다상서` 처럼 **표기만 다르거나 오타가 있는 비슷한 이름**을 쌍으로 묶어 유사도와 함께 보여 줍니다.

## 어떤 업무에 쓰나요?
- ERP·거래처 마스터 정리(같은 회사가 두 번 등록된 경우 찾기)
- 고객 명단 병합 전 중복 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/vendors.csv --column 거래처명 --threshold 0.8 -o output/fuzzy_pairs.csv
```

## 입력 / 출력 예시
샘플에서 `(주)가나다상사`와 `가나다상사 주식회사`는 "표기만 다름"(1.0), `가나다상서`는 "비슷함", `라마바 산업`/`라마바산업`은 "표기만 다름"으로 나옵니다. `전혀다른회사`는 나오지 않습니다.

## 주의사항
- 자동으로 합치거나 지우지 않고 **후보 목록만** 만듭니다. 이름이 비슷해도 다른 회사일 수 있습니다.
- 한글·영어 표기가 완전히 다른 경우(헬로 트레이딩 / Hello Trading)는 찾지 못합니다.
- 비교는 모든 쌍을 보므로 수만 건이 넘으면 느릴 수 있습니다.
