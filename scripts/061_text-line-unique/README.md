# 061 텍스트 줄 중복 제거·정렬

## 무엇을 하나요?
텍스트 파일 한 개의 줄을 읽어 고유한 줄만 남깁니다.

## 어떤 업무에 쓰나요?
- 한 줄에 하나씩 적힌 목록(품목 코드, 주소 목록)을 깔끔하게 만듭니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/items.txt --ignore-case --count -o output/lines.txt
```

## 입력 / 출력 예시
샘플 7줄이 고유 3줄로 줄고 `3 apple / 2 Banana / 2 cherry`처럼 횟수가 붙습니다.

## 주의사항
- 옵션 --sort(정렬), --ignore-case(대소문자 무시), --count(횟수), --keep-blank(빈 줄 유지). 원본은 바뀌지 않습니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
