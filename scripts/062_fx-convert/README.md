# 062 외화 금액 환산

## 무엇을 하나요?
거래 CSV와 환율표 CSV를 맞춰 `KRW환산`, `적용환율` 열을 붙입니다. 계산은 Decimal이라 오차가 없고 원 단위로 반올림합니다.

## 어떤 업무에 쓰나요?
- 해외 청구서·외화 전표를 원화로 환산해 정산할 때 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/invoices.csv --rates sample/rates.csv --date-col 날짜 -o output/converted.csv
```

## 입력 / 출력 예시
USD 1,200.50 × 1350.5 = 1,621,275원. KRW는 그대로, 환율표에 없는 EUR은 `환율 또는 금액 없음`으로 표시됩니다.

## 주의사항
- 샘플 환율은 가짜 값입니다. 실제 환율은 은행·한국은행 등 공식 값을 직접 넣으세요(이 스크립트는 환율을 인터넷에서 가져오지 않습니다).
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
