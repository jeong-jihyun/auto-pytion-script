# 063 업무시간 기준 SLA 점검

## 무엇을 하나요?
금요일 17시 접수, 월요일 10시 완료처럼 주말을 끼면 업무시간으로 2시간이라고 계산합니다.

## 어떤 업무에 쓰나요?
- 고객 요청·장애 처리·결재 지연 등 처리 시간 목표(SLA) 점검에 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/tickets.csv --holidays sample/holidays.txt --sla-hours 8 -o output/sla.csv
```

## 입력 / 출력 예시
R1은 2.00시간(충족), R2는 19.00시간(초과), R3는 휴일(10/9)을 빼서 4.00시간, R4는 시각 형식 오류로 표시됩니다.

## 주의사항
- 업무시간 기본값 평일 09~18시, 점심 12~13시(옵션으로 변경). 시각 형식은 `YYYY-MM-DD HH:MM`.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
