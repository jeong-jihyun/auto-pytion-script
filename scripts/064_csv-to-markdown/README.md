# 064 CSV를 마크다운 표로

## 무엇을 하나요?
한글은 폭이 2칸이라 칸 너비를 계산해 맞추고, 숫자 열은 오른쪽 정렬로 표시합니다.

## 어떤 업무에 쓰나요?
- 위키·깃허브·보고서에 표를 붙여 넣을 때 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/sales.csv -o output/table.md
```

## 입력 / 출력 예시
지점·담당자·매출·비고 4열 표가 만들어지고 매출 열은 오른쪽 정렬, 값 안의 `|`는 `\|`로 바뀝니다.

## 주의사항
- 아주 큰 CSV는 --max-rows로 앞쪽만 변환해 보세요.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
