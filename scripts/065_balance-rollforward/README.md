# 065 잔액 이월 검증

## 무엇을 하나요?
계좌별로 나눠 검사하고, 어긋난 줄의 기대 잔액·실제 잔액·차이를 CSV로 저장합니다.

## 어떤 업무에 쓰나요?
- 계좌 거래내역·원장·재고 수불부의 잔액 오류를 찾는 대사 업무에 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/ledger.csv --account-col 계좌 -o output/balance_errors.csv
```

## 입력 / 출력 예시
샘플에서 A 계좌 5번째 줄이 기대 120,000인데 130,000이라 차이 10,000으로 나옵니다.

## 주의사항
- 각 계좌의 첫 줄 잔액은 시작값으로 인정합니다. 틀린 줄 다음은 실제 잔액을 기준으로 이어 검사합니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
