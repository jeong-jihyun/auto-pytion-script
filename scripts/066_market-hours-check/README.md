# 066 장 운영시간 밖 체결 점검

## 무엇을 하나요?
기본 09:00~15:30. 장 시작 전·마감 후·주말·휴장일·형식 오류를 사유와 함께 모읍니다.

## 어떤 업무에 쓰나요?
- 증권 시스템의 체결·주문 로그 점검, 시각 오류 확인에 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/trades.csv --holidays sample/holidays.txt -o output/off_hours.csv
```

## 입력 / 출력 예시
샘플 7건 중 5건(장 시작 전, 마감 후, 주말, 휴장일, 형식 오류)이 잡히고 정상 2건은 빠집니다.

## 주의사항
- 시간외 거래가 있는 상품은 --open/--close 값을 바꿔 쓰세요. 시간대(타임존) 변환은 하지 않습니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
