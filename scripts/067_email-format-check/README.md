# 067 이메일 주소 형식 점검

## 무엇을 하나요?
@ 개수, 공백, 도메인 점 여부를 확인하고 gmial.com 같은 흔한 오타를 추정합니다. 도메인별 개수도 보여 줍니다.

## 어떤 업무에 쓰나요?
- 메일 발송 전 명단 정리, 고객 목록 품질 점검에 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/contacts.csv --column 이메일 -o output/email_check.csv
```

## 입력 / 출력 예시
샘플 7건 중 6건이 확인 필요(중복 2, 오타 의심 1, 형식 오류 2, 빈칸 1)로 나옵니다.

## 주의사항
- 실제로 메일이 가는지는 확인하지 않습니다. 샘플은 모두 가짜 주소입니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
