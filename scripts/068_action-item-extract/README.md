# 068 회의록 할 일 추출

## 무엇을 하나요?
파일 하나 또는 폴더(.txt, .md)를 읽어 할 일·담당(@이름, 담당:)·기한(~10/30, 기한:)을 뽑습니다.

## 어떤 업무에 쓰나요?
- 회의가 끝난 뒤 액션 아이템을 빠르게 정리하는 데 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/minutes.txt --year 2026 -o output/actions.csv
```

## 입력 / 출력 예시
샘플에서 할 일 4건이 나오고 기한이 없는 `회의실 예약하기`는 기한이 빈칸입니다.

## 주의사항
- `10/30`처럼 연도가 없는 날짜는 --year 값을 붙입니다. 정해진 표기 외의 문장은 인식하지 못합니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
