# 069 공급가액·세액·합계 검산

## 무엇을 하나요?
세액은 원 미만 반올림, 합계는 공급가액+세액으로 계산해 표의 값과 비교합니다.

## 어떤 업무에 쓰나요?
- 세금계산서·청구서 입력 오류 점검(ERP 전표 검수)에 씁니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/invoices.csv --rate 0.10 -o output/vat_check.csv
```

## 입력 / 출력 예시
샘플 5건 중 3번은 세액 차이 -1000, 4번은 합계 차이 -1000, 5번은 숫자 오류로 나옵니다.

## 주의사항
- 단순 산식 검산용입니다. 면세·영세율·세무 판단은 세무 담당자가 확인하세요.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
