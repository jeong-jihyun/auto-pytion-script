# 070 마크다운을 워드로

## 무엇을 하나요?
제목 3단계, 글머리표, 번호 목록, 표, **굵게**를 워드 서식으로 바꿉니다.

## 어떤 업무에 쓰나요?
- 주간보고·회의록을 마크다운으로 쓰고 워드로 제출할 때 씁니다.

## 설치
파이썬 3.8 이상, `python-docx` 패키지가 필요합니다.

## 실행 예시
```
pip install -r requirements.txt
python3 main.py sample/weekly.md -o output/report.docx
```

## 입력 / 출력 예시
샘플에서 제목 3, 문단 1, 목록 4, 표 1이 만들어집니다.

## 주의사항
- 이미지·링크·코드 블록은 지원하지 않습니다. python-docx 설치가 필요합니다.
- 결과 파일은 `output/` 폴더에 만들어지며 저장소에는 올라가지 않습니다.
- `sample/` 데이터는 모두 가짜입니다. 개인정보가 든 실제 파일은 공유하지 마세요.
