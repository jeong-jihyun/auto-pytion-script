# 071 숫자 금액을 한글 금액으로

## 무엇을 하나요?
`1234000` 같은 숫자를 `일금 일백이십삼만사천원정`처럼 한글 금액으로 바꿉니다. 금액 하나만 바꾸거나, CSV의 금액 열 전체를 바꿔 `금액_한글` 열을 붙일 수 있습니다.

## 어떤 업무에 쓰나요?
- 계약서·영수증·청구서·지출결의서에 한글 금액을 적을 때 손으로 쓰다 틀리는 일을 막습니다.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --amount 1234000
python3 main.py --input sample/invoices.csv --col 금액 -o output/amount_korean.csv
python3 main.py --amount 1234000 --plain --no-wrap   # 백이십삼만사천
```

## 입력 / 출력 예시
| 금액 | 금액_한글 |
|---|---|
| 1234000 | 일금 일백이십삼만사천원정 |
| 10,000,000 | 일금 일천만원정 |
| 12.5 | [확인필요] 정수 금액이 아닙니다 |

## 주의사항
- 정수(원 단위)만 바꿉니다. 소수점이 있으면 `[확인필요]`로 표시합니다.
- 기본은 위조 방지용 표기('일십', '일백'을 생략하지 않음)입니다. `--plain`을 쓰면 '십', '백'으로 씁니다.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다. `sample/` 데이터는 모두 가짜입니다.
