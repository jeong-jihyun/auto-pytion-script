# 072 사업자등록번호 점검

## 무엇을 하나요?
거래처 CSV의 사업자등록번호가 10자리인지, 마지막 검증번호가 계산과 맞는지, 같은 번호가 두 번 등록됐는지 확인합니다. 정상 번호는 `123-45-67890` 표준 형식으로 바꿔 줍니다.

## 어떤 업무에 쓰나요?
- ERP 거래처 마스터 정비, 세금계산서 발행 전 점검, 신규 거래처 등록 검수.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/vendors.csv --col 사업자번호 -o output/bizno_check.csv
```

## 입력 / 출력 예시
| 거래처 | 사업자번호 | 점검결과 | 표준형식 |
|---|---|---|---|
| 마바테크 | (끝자리 틀림) | 검증번호 불일치(기대 N) | |
| 사아유통 | 99999000 | 자릿수 오류(8자리) | |
| 다라물산 | (같은 번호 2번) | 정상(중복 등록) | 999-99-00024 |

## 주의사항
- **번호의 모양만** 검사합니다. 실제로 등록된 사업자인지, 휴업·폐업인지는 국세청 홈택스 조회로 따로 확인하세요.
- 샘플 번호는 검증 규칙으로 만든 임의 번호이며 실제 사업자와 관계없습니다.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다.
