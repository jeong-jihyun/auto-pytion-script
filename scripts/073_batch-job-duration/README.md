# 073 배치 작업 소요시간 계산

## 무엇을 하나요?
배치 로그의 `START 작업명`, `END 작업명 (상태)` 줄을 짝지어 작업마다 시작·종료·소요(분)를 표로 만듭니다. 오래 걸린 작업(지연), 실패, 끝나지 않은 작업(미종료), 시작 기록이 없는 작업도 표시합니다.

## 어떤 업무에 쓰나요?
- 증권·은행 야간 배치(마감, 정산, 원장 반영) 아침 점검.
- 작업 시간이 점점 늘어나는지 날짜별 결과를 모아 비교할 때.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/batch_20261025.log --max-minutes 60 -o output/job_durations.csv
```
로그 형식이 다르면 `--pattern` 으로 정규식을 바꿉니다. 이름 있는 그룹 `ts`(시각), `kind`(START/END), `job`, `status`가 있어야 합니다.

## 입력 / 출력 예시
| 작업 | 소요(분) | 상태 | 판정 |
|---|---|---|---|
| FX_RATE_LOAD | 3.1 | OK | 정상 |
| SETTLE_CALC | 80.0 | OK | 지연 |
| GL_POSTING | 10.0 | FAIL | 실패(FAIL) |
| REPORT_GEN | | | 미종료 |
| ARCHIVE_MOVE | | OK | 시작 기록 없음 |

## 주의사항
- 같은 작업이 동시에 여러 개 도는 구조(병렬 인스턴스)는 작업명에 번호가 붙어 있어야 정확합니다.
- 상태가 OK/SUCCESS 가 아니면 실패로 봅니다.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다. 샘플 로그는 가짜입니다.
