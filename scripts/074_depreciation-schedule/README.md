# 074 감가상각 일정표

## 무엇을 하나요?
자산 목록 CSV로 자산별·연도별 감가상각액, 누계액, 기말 장부가 표를 만듭니다. 정액법과 정률법을 고를 수 있고, 첫해는 취득 월부터 월할로 계산합니다.

## 어떤 업무에 쓰나요?
- 고정자산 대장 작성, 예산 편성 때 앞으로 몇 년간 비용(상각비) 미리 보기, ERP 상각 결과 검산.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/assets.csv -o output/depreciation.csv
python3 main.py sample/assets.csv --no-monthly   # 첫해도 12개월치
```

## 입력 / 출력 예시
입력 열: `자산명, 취득가, 잔존가, 내용연수, 방법(정액/정률), 취득일(YYYY-MM-DD)`

노트북 1,500만원·5년·정액·4월 취득 → 2026년 9개월치 2,250,000원, 2027~2030년 3,000,000원, 2031년 3개월치 750,000원, 마지막 장부가 0원.

## 주의사항
- 원 미만은 버리고 마지막 해에 끝수를 맞춥니다. 회사·세법 기준(상각률표, 반올림 방식)과 다를 수 있으니 **검산·계획용**으로 쓰세요.
- 정률법에서 잔존가가 0이면 취득가의 5%를 계산용 잔존가로 써서 상각률을 구하고, 마지막 해에 남은 금액을 모두 상각합니다.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다. 샘플은 가짜 자산입니다.
