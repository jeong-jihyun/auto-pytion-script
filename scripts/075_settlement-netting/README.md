# 075 정산 상계(네팅)

## 무엇을 하나요?
여러 상대방 사이의 '보낼 돈' 목록을 통화별로 상계해서 실제로 보낼 돈만 남깁니다.
- `netting_bilateral.csv`: 두 상대방끼리만 상계한 결과
- `netting_positions.csv`: 상대방별 순포지션(+면 받을 돈, -면 줄 돈)
- `netting_payments.csv`: 전체를 한꺼번에 상계해 송금 건수를 줄인 지급 목록

## 어떤 업무에 쓰나요?
- 증권사·은행 간 결제 대금 정산, 계열사 간 내부거래 정산, 모임 회비 정산.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/obligations.csv -d output
```

## 입력 / 출력 예시
샘플 원거래 7건 → 양자 상계 4건 → 다자 상계 3건(KRW 2건, USD 1건).
KRW 순포지션: 가나증권 -100,000 / 다라은행 -100,000 / 마바운용 +200,000 → 가나증권·다라은행이 마바운용에 각각 100,000원씩 보내면 끝납니다.

## 주의사항
- 금액은 Decimal로 계산하므로 소수점 오차가 없습니다. 통화가 다르면 절대 섞지 않습니다.
- 다자 상계 지급 목록은 계산 결과일 뿐입니다. 실제 결제는 계약(상계 합의) 범위 안에서만 하세요.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다. 샘플은 가짜 거래입니다.
