# 076 기간 이자(경과이자) 계산

## 무엇을 하나요?
계약별 원금·연이율·기간으로 이자를 계산합니다. 일수 계산 방식 ACT/365, ACT/360, 30/360, ACT/ACT 를 지원하고, `--as-of` 날짜를 주면 그날까지 쌓인 경과(미수)이자를 계산합니다.

## 어떤 업무에 쓰나요?
- 월말 결산 때 예금·대여금·채권의 미수이자 계상, 콜·외화 단기자금 이자 검산, 은행 이자 계산서 대조.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/contracts.csv -o output/interest.csv            # 만기까지 이자
python3 main.py sample/contracts.csv --as-of 2026-10-25                # 오늘까지 경과이자
```

## 입력 / 출력 예시
입력 열: `계약번호, 원금, 연이율(3.5 또는 3.5%), 시작일, 만기일, 방식`

| 계약번호 | 방식 | 일수 | 이자 |
|---|---|---|---|
| DEP-01 | ACT/365 | 365 | 3,500,000 |
| CALL-02 | ACT/360 | 30 | 1,750,000 |
| BOND-03 | 30/360 | 180 | 15,000,000 |

## 주의사항
- 시작일은 넣고 끝나는 날은 빼서 셉니다(한편 넣기). 양편 넣기 상품은 결과가 하루치 다릅니다.
- 30/360 은 미국식 간단 규칙입니다. 상품 약관의 규칙이 다르면 결과가 다를 수 있습니다.
- 원 미만은 버립니다. 세금(이자소득세)은 계산하지 않습니다.
- 결과는 `output/` 폴더에 저장되며 저장소에는 올라가지 않습니다. 샘플은 가짜 계약입니다.
