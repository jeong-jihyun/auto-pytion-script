# 078 전화번호 형식 통일

## 무엇을 하나요?
CSV의 전화번호 열을 읽어 `010-0000-1234`, `02-000-1234`, `1588-0000` 같은 한 가지 형식으로 정리합니다. 원래 열은 그대로 두고 `전화_정리`, `전화_종류`(휴대폰/유선/대표번호 등), `전화_점검` 열을 붙입니다.

## 어떤 업무에 쓰나요?
- 고객·거래처 명부 정리, CRM·ERP 이관 전 데이터 정비, 중복 연락처 찾기 전처리.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/contacts.csv --col 전화 -o output/phone_normalized.csv
```

## 입력 / 출력 예시
| 전화 | 전화_정리 | 전화_종류 | 전화_점검 |
|---|---|---|---|
| +82 10-0000-9999 | 010-0000-9999 | 휴대폰 | 정상 |
| (02)000-1234 | 02-000-1234 | 유선 | 정상 |
| 1588-0000 | 1588-0000 | 대표번호 | 정상 |
| 12345 | | | 확인필요(5자리) |

## 주의사항
- '내선 21', 'ext.21' 같은 내선 번호는 떼어 냅니다.
- 형식만 정리합니다. 실제로 쓰는 번호인지는 알 수 없습니다. 이 스크립트로 문자·전화를 보내지 않습니다.
- 샘플 번호는 모두 0000이 들어간 가짜 번호입니다. 결과는 `output/`에 저장되며 저장소에는 올라가지 않습니다.
