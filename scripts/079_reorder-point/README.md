# 079 재주문점·권장 발주량 계산

## 무엇을 하나요?
재고 목록과 최근 사용 내역으로 품목마다 하루 평균 사용량, 재주문점, 남은 일수를 계산하고, 발주가 필요한 품목의 권장 발주량(최소발주량·포장단위 반영)을 알려 줍니다.

## 어떤 업무에 쓰나요?
- 사무용품·소모품·부품 재고 관리, ERP 자재 소요 검토, 발주 품의 전 수량 근거 만들기.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/stock.csv sample/usage.csv --days 30 --cover-days 14 -o output/reorder.csv
```

## 입력 / 출력 예시
- 재고 CSV 열: `품목코드, 품목명, 현재고, 발주잔량, 안전재고, 조달일수, 최소발주량, 포장단위`
- 사용 CSV 열: `일자, 품목코드, 수량`

샘플 결과: A4 복사용지(권장 20개), 라벨지(권장 20개) 2개 품목이 발주 필요로 나옵니다.

계산식: 재주문점 = 하루평균사용 × 조달일수 + 안전재고. (현재고 + 발주잔량) ≤ 재주문점이면 발주 필요.

## 주의사항
- 사용량이 계절·행사에 따라 크게 바뀌는 품목은 평균이 맞지 않을 수 있습니다. `--days`를 바꿔 보세요.
- 사용 내역이 없는 품목은 '사용 없음'으로 표시하고 발주를 권하지 않습니다.
- 결과는 `output/`에 저장되며 저장소에는 올라가지 않습니다. 샘플은 가짜 데이터입니다.
