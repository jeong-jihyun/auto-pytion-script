# 080 예산 대비 실적 비교

## 무엇을 하나요?
부서·계정별 예산과 실제 쓴 돈(실적)을 비교해 잔액, 집행률(%), 판정(정상/주의/초과/예산 없음)을 계산하고, 부서 소계와 전체 합계를 붙입니다.

## 어떤 업무에 쓰나요?
- 월말·분기말 예산 집행 점검, 예산 초과 부서 사전 알림, 경영 보고 자료 기초 데이터.

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/budget.csv sample/actual.csv --until 2026-10-31 --warn 90 -o output/budget_vs_actual.csv
```

## 입력 / 출력 예시
| 부서 | 계정 | 예산 | 실적 | 집행률(%) | 판정 |
|---|---|---|---|---|---|
| 영업팀 | 접대비 | 5,000,000 | 5,400,000 | 108.0 | 초과 |
| 총무팀 | 소모품비 | 1,500,000 | 1,380,000 | 92.0 | 주의 |
| 총무팀 | 복리후생비 | 0 | 250,000 | | 예산 없음 |

## 주의사항
- `--until`은 날짜가 `YYYY-MM-DD` 형식일 때만 정확합니다(다른 형식이면 026 날짜 형식 통일 스크립트로 먼저 정리하세요).
- 결과의 금액에는 쉼표가 없습니다. 엑셀에서 열어 서식을 지정하세요.
- 결과는 `output/`에 저장되며 저장소에는 올라가지 않습니다. 샘플은 가짜 데이터입니다.
