# 081 당번 순번표 자동 생성

## 무엇을 하나요?
사람 목록과 각자 '안 되는 날'을 받아, 기간 동안의 당번(당직·청소·장애 모니터링 등) 순번표를 **공평하게** 만듭니다. 주말·휴일은 건너뛰고, 전날 한 사람은 되도록 연속으로 넣지 않으며, 횟수가 적은 사람부터 배정합니다.

## 어떤 업무에 쓰나요?
- 팀 당직표, 배치 모니터링 당번, 사무실 청소·당번표를 매달 손으로 짜는 일 줄이기
- 휴가·출장 날짜를 반영한 순번표 초안 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/people.csv --start 2026-11-02 --end 2026-11-13 --holidays 2026-11-06
python3 main.py sample/people.csv --start 2026-11-01 --end 2026-11-30 --per-day 2 --include-weekend
```

## 입력 / 출력 예시
- 사람 CSV 열: `이름, 안되는날`(여러 날은 `2026-11-03;2026-11-04`)
- 출력 CSV: `날짜, 요일, 당번, 비고` 표 + 아래에 `이름, 횟수` 요약. 비고에는 '인원 부족', '연속 배정(사람 부족)'이 적힙니다.

샘플 결과(11/2~11/13, 11/6 휴일 제외 9일): 가직원 3회, 나·다·라직원 2회 — 횟수 차이 1로 공평. 안 되는 날에는 배정되지 않습니다.

## 주의사항
- 무작위가 아니라 규칙으로 고르므로 같은 입력이면 늘 같은 결과입니다. 명단 순서를 바꾸면 결과도 바뀝니다.
- 사람이 모자라면 연속 배정이나 인원 부족이 생기며 비고에 표시합니다. 꼭 확인하세요.
- 샘플 이름은 가짜입니다.
