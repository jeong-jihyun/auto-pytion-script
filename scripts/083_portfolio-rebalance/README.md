# 083 목표 비중 리밸런싱 수량 계산

## 무엇을 하나요?
보유 종목(수량·현재가)과 목표 비중을 넣으면, 목표에 맞추려면 **어떤 종목을 몇 주 사고팔아야 하는지** 계산합니다. 허용 오차(±2%p) 안의 종목은 건드리지 않고, 매도로 만든 현금 안에서만 매수하며, 수수료를 반영합니다.

## 어떤 업무에 쓰나요?
- 연금·ISA·자산배분 계좌의 정기 리밸런싱 주문 수량 미리 계산
- 증권 시스템의 리밸런싱 기능 검증용 기대값 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/holdings.csv --cash 500000 --deposit 1000000 -o output/rebalance.csv
python3 main.py sample/holdings.csv --band 5 --fee 0.1      # 오차 ±5%p, 수수료 0.1%
```

## 입력 / 출력 예시
- 보유 CSV 열: `종목, 보유수량, 현재가, 목표비중%`
- 출력 CSV 열: `종목, 현재가, 보유수량, 현재비중%, 목표비중%, 주문(매수/매도/유지), 수량, 거래금액, 거래후비중%`

샘플 결과(총자산 13,150,000원): 국내주식ETF 매수 30주, 해외주식ETF 매도 4주, 채권ETF 유지(오차 이내), 금ETF 매수 57주 → 거래 후 예상 현금 34,648원. 이 숫자는 손으로 다시 계산해 맞는지 확인했습니다.

## 주의사항
- **투자 권유가 아닌 계산 도구** 입니다. 실제 주문은 하지 않습니다.
- 세금(매도 시 거래세·양도세 등)과 호가단위·체결가 변동은 반영하지 않았습니다. 실제 주문 전 증권사 화면에서 다시 확인하세요.
- 주 단위로 버림하므로 목표 비중과 조금 차이가 남습니다. 샘플 종목·가격은 가짜입니다.
