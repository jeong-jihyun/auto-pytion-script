# 084 엑셀 두 파일 셀 단위 비교

## 무엇을 하나요?
이전 엑셀과 수정한 엑셀을 **같은 시트, 같은 셀끼리** 비교해 바뀐 셀 목록(CSV)을 만들고, 수정본 사본에 바뀐 셀을 색칠(변경·삭제=노랑, 추가=초록)하고 메모로 이전 값을 달아 줍니다.

## 어떤 업무에 쓰나요?
- 거래처가 "조금 고쳤어요" 하고 보낸 견적서·단가표에서 실제로 바뀐 칸 찾기
- 배포 전후 설정표·코드표·매핑표 변경 검토, 감사 증적 남기기

## 설치
```
pip install -r requirements.txt
```

## 실행 예시
```
python3 make_sample.py                       # 샘플 old.xlsx / new.xlsx 만들기(처음 한 번)
python3 main.py sample/old.xlsx sample/new.xlsx -o output
python3 main.py old.xlsx new.xlsx --values   # 수식 대신 저장된 계산값으로 비교
```

## 입력 / 출력 예시
- 출력 `changes.csv` 열: `시트, 셀, 구분(변경/추가/삭제), 이전값, 새값`
- 출력 `new_비교표시.xlsx`: 수정본 사본에 색칠 + 메모

샘플 결과: 바뀐 셀 6개(B2 10→12, C3 1200→1300, 4행 추가 4칸), '메모' 시트는 수정 파일에만 있다고 알려 줍니다.

## 주의사항
- 행을 중간에 끼워 넣으면 그 아래가 모두 '변경'으로 나옵니다(위치 기준 비교). 행이 밀린 표는 키 열 기준 비교(005 정산 대사)가 더 맞습니다.
- `--values`는 엑셀이 저장해 둔 계산값을 씁니다. 파이썬 등으로 만든 파일은 계산값이 비어 있을 수 있습니다.
- 원본 두 파일은 바꾸지 않습니다. 샘플은 가짜 데이터입니다.
