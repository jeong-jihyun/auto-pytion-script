# 085 이미지 글자 워터마크 일괄 넣기

## 무엇을 하나요?
폴더 안 이미지(jpg·png·webp·bmp)에 '대외비', '회사명 © 2026' 같은 글자를 반투명하게 한꺼번에 넣습니다. 위치는 오른쪽 아래(`br`), 가운데(`center`), 비스듬히 반복(`tile`) 중 고릅니다. 원본은 바꾸지 않고 다른 폴더에 저장합니다.

## 어떤 업무에 쓰나요?
- 외부에 보내는 화면 캡처·도면·제품 사진에 '대외비' 표시
- 블로그·SNS용 사진에 출처 표시

## 설치
```
pip install -r requirements.txt
```
한글 글꼴이 필요합니다. 윈도우(맑은 고딕), 맥(애플 SD 고딕 Neo), 리눅스(나눔고딕·Noto Sans CJK)는 자동으로 찾고, 없으면 `--font 글꼴경로`로 지정하세요.

## 실행 예시
```
python3 main.py sample --text "대외비 · 샘플회사"                       # 미리보기(저장 안 함)
python3 main.py sample --text "대외비 · 샘플회사" --apply               # 오른쪽 아래에 저장
python3 main.py sample --text "대외비" --where tile --opacity 0.3 --apply  # 비스듬히 반복
```

## 입력 / 출력 예시
- 입력: 이미지 폴더(하위 폴더는 보지 않음)
- 출력: `output/watermarked/원래이름` (같은 이름, 같은 형식)
- `--size 0.05`: 글자 높이를 이미지 짧은 변의 5%로. `--opacity`: 0(투명)~1(진함)

샘플 결과: 사진 2장(640x480, 300x200)에 글자가 각각 24px, 12px로 들어갑니다. 결과 그림을 눈으로 열어 위치·글자를 확인했습니다.

## 주의사항
- 기본은 **미리보기** 입니다. `--apply`를 붙여야 저장합니다. 출력 폴더를 원본 폴더와 같게 주면 멈춥니다.
- 워터마크는 유출을 '어렵게' 할 뿐 완전히 막지는 못합니다.
- 다른 사람의 사진에 내 이름을 넣어 저작자를 속이는 데 쓰지 마세요. 샘플 그림은 직접 만든 단색 그림입니다.
