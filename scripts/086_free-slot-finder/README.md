# 086 모두 비어 있는 회의 시간 찾기

## 무엇을 하나요?
여러 사람의 바쁜 일정을 모아, 업무시간 안에서 **참석자 모두가 비어 있는 시간** 을 찾아 줍니다. 점심시간과 주말은 빼고, 회의 길이보다 짧은 틈은 버립니다.

## 어떤 업무에 쓰나요?
- 팀 회의·고객 미팅·프로젝트 점검 회의 시간을 잡을 때 "언제 다 되세요?" 메일 돌리기 대신 후보 뽑기
- 캘린더에서 내보낸 일정(CSV)으로 일주일치 빈 시간 표 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/busy.csv --start 2026-10-26 --days 3 --minutes 60
python3 main.py sample/busy.csv --people 김하나,이두리 --start 2026-10-26 --days 1 --minutes 30 --work 08:30-17:30 --lunch 11:30-12:30
```

## 입력 / 출력 예시
- 일정 CSV 열: `이름, 시작, 종료` (시각 형식 `2026-10-26 14:00`)
- 출력 CSV 열: `날짜, 요일, 빈시간시작, 빈시간종료, 길이(분)`

샘플 결과(3명, 3영업일, 60분): 10-26(월) 17:00~18:00, 10-28(수) 09:00~10:00 / 11:00~12:00 / 13:00~18:00. 10-27은 박세나가 하루 종일 바빠 후보가 없습니다.

## 주의사항
- 공휴일은 따로 빼지 않습니다. 공휴일이 끼면 그 날 후보는 무시하세요.
- 일정 파일에 없는 참석자는 '하루 종일 비어 있음'으로 보고 경고만 띄웁니다.
- 일정 제목 같은 내용은 읽지 않고 시각만 씁니다. 샘플 이름은 가짜입니다.
