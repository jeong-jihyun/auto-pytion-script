# 087 경비 사용 내역 규정 점검

## 무엇을 하나요?
법인카드·경비 내역을 회사 규칙(JSON)으로 점검해 **한도 초과, 쪼개기 결제, 휴일·심야 사용, 제한 업종, 중복 청구** 가 의심되는 건을 '확인 필요'로 표시하고 사유를 적어 줍니다.

## 어떤 업무에 쓰나요?
- 재무·감사팀의 월별 경비 사후 점검(수천 건을 다 보지 않고 의심 건만 보기)
- 경비 정산 전 자가 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/expenses.csv --rules sample/rules.json -o output/expense_flags.csv
```

## 입력 / 출력 예시
- 경비 CSV 열: `사용일시(2026-10-05 12:10), 사용자, 항목, 가맹점, 금액`
- 규칙 JSON: `limits`(항목별 1회 한도), `holidays`(휴일 날짜), `night_hours`([23, 5] = 23시~5시), `banned_keywords`
- 출력 CSV: 원래 열 + `판정(정상/확인 필요), 사유`

샘플 결과: 9건 중 7건 확인 필요 — 한도 초과 1, 쪼개기 의심 2(같은날 45,000+40,000원), 휴일 2, 심야+제한업종 1, 중복 청구 1.

## 주의사항
- '쪼개기'는 같은 날·같은 사람·같은 가맹점 결제가 각각은 한도 안인데 합하면 한도를 넘을 때 표시합니다. 여러 명 식사를 한 사람이 나눠 낸 경우처럼 정상일 수 있으니 **판정은 사람이** 합니다.
- 휴일 목록은 규칙 파일에 직접 넣어야 합니다(대체공휴일 포함).
- 결과에 사람 이름이 들어가므로 공유 범위에 주의하세요. 샘플 이름·가맹점은 가짜입니다.
