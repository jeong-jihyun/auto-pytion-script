# 088 계정·권한 정기 점검

## 무엇을 하나요?
시스템에서 내보낸 **사용자 계정 목록** 과 **인사 명단** 을 사번으로 맞춰, 퇴사자 잔존 계정(퇴사 후 접속 포함), 휴직자 활성 계정, 명단에 없는 계정(공용·테스트), 장기 미접속 계정, 허용 목록 밖 관리자 권한을 찾고 조치 제안을 붙입니다.

## 어떤 업무에 쓰나요?
- 금융권·ERP 시스템의 분기별 접근권한 재검토(권한 리뷰), 내부통제·감사 대응 자료
- 퇴사자 계정 정리 누락 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/accounts.csv sample/hr.csv --today 2026-10-25 --admins admin -o output/account_review.csv
python3 main.py accounts.csv hr.csv --idle-days 60 --admin-roles ADMIN,SUPER
```

## 입력 / 출력 예시
- 계정 CSV 열: `계정ID, 사번, 역할, 상태(사용/잠금), 마지막접속`
- 인사 CSV 열: `사번, 이름, 재직상태(재직/휴직/퇴사), 퇴사일`
- 출력 CSV 열: `계정ID, 사번, 이름, 역할, 계정상태, 마지막접속, 점검결과, 조치제안` (조치 필요한 계정이 위로)

샘플 결과(기준일 2026-10-25): 8개 중 5개 조치 필요 — 퇴사자 잔존+퇴사일 이후 접속(user02, 즉시 잠금), 허용 밖 관리자(user03), 146일 미접속(user04), 휴직자 활성(user05), 명단에 없고 접속 기록 없는 test_batch.

## 주의사항
- 이미 '잠금'인 계정은 미접속·퇴사 점검에서 정상으로 봅니다.
- 배치·연동용 공용 계정은 '명단에 없는 계정'으로 나옵니다. 담당자를 정해 예외 목록으로 관리하세요.
- 비밀번호·개인정보 열은 넣지 마세요(필요 없습니다). 결과 파일은 내부에서만 다루세요. 샘플은 가짜 데이터입니다.
