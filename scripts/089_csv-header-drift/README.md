# 089 연동 CSV 헤더(열 구성) 변경 점검

## 무엇을 하나요?
매일 받는 연동·인터페이스 CSV 파일의 **첫 줄(열 이름)** 만 읽어, 약속한 형식(schema.json)과 비교합니다. 빠진 열, 새로 생긴 열, 순서 바뀜, 공백·대소문자 표기 차이, 중복 열, 쉼표가 아닌 구분자를 알려 줍니다. 문제가 있으면 **종료 코드 1** 로 끝납니다.

## 어떤 업무에 쓰나요?
- 거래처·타 시스템이 예고 없이 파일 형식을 바꿔 배치가 깨지는 사고 미리 막기
- 배치 스케줄러에서 적재 전 단계로 넣어 "형식 이상이면 멈춤"

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/inbox --schema sample/schema.json -o output/header_check.csv
python3 main.py /data/inbox --ignore-order          # 순서는 상관없을 때
python3 main.py /data/inbox && python3 load.py      # 정상일 때만 다음 단계 실행
```

## 입력 / 출력 예시
- schema.json: `{"orders_*.csv": ["주문번호", "주문일자", "고객코드", "금액"]}` 처럼 패턴별 열 목록
- 출력 CSV 열: `파일, 적용 패턴, 결과(정상/이상/기준 없음), 내용`

샘플 결과: 4개 중 이상 2개 — orders_20261024(할인금액 열 추가, 순서 바뀜), settle_20261025(세미콜론 구분자, '정산금액 ' 끝 공백). unknown.csv는 '기준 없음'.

## 주의사항
- 헤더 한 줄만 봅니다. 값이 맞는지는 009 CSV 데이터 검증을 함께 쓰세요.
- 한글 cp949 파일이면 `--encoding cp949`를 주세요.
- 샘플은 가짜 데이터입니다.
