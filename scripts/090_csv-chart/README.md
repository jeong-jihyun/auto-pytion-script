# 090 CSV로 그래프(PNG) 만들기

## 무엇을 하나요?
CSV에서 x축 열과 y축 열(여러 개 가능)을 골라 **막대·선·가로막대 그래프 PNG** 를 만듭니다. 같은 x 값은 합계를 내고, 날짜는 `--month`로 월별로 묶을 수 있습니다. 막대 위에 천 단위 쉼표 값이 적히고, 한글 글꼴을 자동으로 찾아 씁니다.

## 어떤 업무에 쓰나요?
- 주간·월간 보고서에 붙일 매출·비용·건수 그래프를 매번 엑셀로 그리지 않고 한 줄로 만들기
- 배치로 매일 아침 그래프 파일 자동 생성(화면 없는 서버에서도 동작)

## 설치
```
pip install -r requirements.txt
```

## 실행 예시
```
python3 main.py sample/sales.csv --x 일자 --month --y 매출,비용 --title "월별 매출·비용" --unit 원 -o output/monthly.png
python3 main.py sample/sales.csv --x 지점 --y 매출 --kind barh -o output/branch.png
python3 main.py sample/sales.csv --x 일자 --month --y 매출 --kind line -o output/trend.png
```

## 입력 / 출력 예시
- 입력 CSV: 첫 줄이 열 이름. 숫자 칸의 쉼표("1,200,000")는 자동으로 지웁니다.
- 출력: PNG 그림 한 장

샘플 결과: 2026-07~10 월별 매출·비용 막대(7월 매출 2,100,000원 등), 지점별 가로막대(서울 5,600,000원, 부산 2,700,000원). '-' 처럼 숫자가 아닌 칸 1개는 건너뛰었다고 알려 줍니다. 결과 그림을 눈으로 열어 한글·숫자 표시를 확인했습니다.

## 주의사항
- 한글 글꼴(맑은 고딕, 애플고딕, 나눔고딕, Noto Sans CJK)이 하나도 없으면 한글이 네모로 나옵니다.
- x 값이 아주 많으면(수십 개 이상) 글자가 겹칩니다. `--month`로 묶거나 가로막대(`--kind barh`)를 쓰세요.
- 샘플은 가짜 데이터입니다. 결과는 `output/`에 저장되며 저장소에 올라가지 않습니다.
