# 091 거래내역 자동 분류

## 무엇을 하나요
은행·카드 거래내역의 '적요'에 들어 있는 글자(키워드)를 보고 식음료·교통비 같은 분류를 붙이고, 분류별 합계를 만듭니다.

## 어떤 업무에 쓰나요
월말 경비 정리, 가계부 정리, 법인카드 사용 내역 분류.

## 설치
파이썬 3.8 이상만 있으면 됩니다. 외부 패키지는 필요 없습니다.

## 실행 예시
```
python3 main.py --input sample/거래내역.csv --rules sample/규칙.csv --out-dir output
```

## 입력·출력
- 입력: 거래내역 CSV(일자,적요,출금,입금), 규칙 CSV(키워드,분류). 규칙은 위에서부터 먼저 맞는 것이 적용됩니다.
- 출력: `output/분류결과.csv`(각 줄에 분류 추가), `output/분류별합계.csv`.

## 주의사항
- 맞는 규칙이 없으면 '미분류'입니다. 미분류가 보이면 규칙 CSV에 줄을 추가하세요.
- 파일을 지우거나 덮어쓰지 않고 결과 폴더에 새로 만듭니다. 샘플은 가짜 데이터입니다.
