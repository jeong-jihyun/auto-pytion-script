# 092 비율 배분(합계 딱 맞추기)

## 무엇을 하나요
총액을 비율대로 나눌 때, 반올림 때문에 합계가 1~2원 틀어지는 문제를 없앱니다. 남는 금액은 소수 부분이 큰 쪽부터 1원씩 줍니다(최대잔여법).

## 어떤 업무에 쓰나요
공통 비용 부서별 배분, 수수료·세금 안분, 정산 금액 나누기.

## 실행 예시
```
python3 main.py --input sample/비율.csv --total 1000000
```
3팀에 100만 원을 똑같이 나누면 333,334 / 333,333 / 333,333 처럼 합계가 정확히 맞습니다.

## 입력·출력
- 입력: CSV(이름,비율), `--total` 총액, `--unit` 배분 단위(기본 1).
- 출력: `output/배분결과.csv`(이름,비율,배분액)와 화면 합계 확인.

## 주의사항
- 총액은 단위의 배수여야 합니다. 비율 합이 0이면 오류로 멈춥니다.
- 소수점 계산은 Decimal을 써서 오차가 없습니다.
