# 093 액면분할 수정주가 계산

## 무엇을 하나요
1주를 5주로 나누는 액면분할이 있으면, 그 전의 주가를 5로 나눠 분할 후 가격과 이어서 볼 수 있게 만듭니다.

## 어떤 업무에 쓰나요
주가 추이 분석, 수익률 계산 전 데이터 정리, 시세 대사.

## 실행 예시
```
python3 main.py --prices sample/가격.csv --events sample/이벤트.csv
```
샘플에서는 3월 3일 이전 가격(50만 원)이 10만 원으로 바뀝니다.

## 입력·출력
- 입력: 가격 CSV(일자,종가), 이벤트 CSV(일자,비율). 비율 5 = 분할, 0.2 = 5주를 1주로 병합.
- 출력: `output/수정주가.csv`(일자,종가,수정종가,적용비율).

## 주의사항
- 일자는 `YYYY-MM-DD` 형식이어야 문자 비교가 맞습니다.
- 배당·유상증자 조정은 하지 않습니다(분할/병합만).
