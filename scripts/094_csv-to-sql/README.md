# 094 CSV를 INSERT 문으로 변환

## 무엇을 하나요
CSV 한 줄을 SQL `INSERT` 한 줄로 바꿔 `.sql` 파일을 만듭니다. 만들기만 하고 데이터베이스에 실행하지는 않습니다.

## 어떤 업무에 쓰나요
테스트 데이터 넣기, 기준 정보 이관, 엑셀 데이터를 DB에 올리기 전 준비.

## 실행 예시
```
python3 main.py --input sample/고객.csv --table customer
```

## 입력·출력
- 입력: 첫 줄이 컬럼 이름인 CSV. 컬럼·테이블 이름은 영문, 숫자, 밑줄만 허용.
- 출력: `output/insert.sql`. 숫자만 있는 컬럼은 따옴표 없이, 빈 칸은 NULL, 작은따옴표는 `''`로 바꿉니다.

## 주의사항
- 만든 SQL은 반드시 사람이 확인한 뒤 실행하세요. 운영 DB에 바로 실행하지 마세요.
- 날짜 형식 변환이나 컬럼 타입 지정은 하지 않습니다(문자로 들어갑니다).
