# 095 주소 나누기

## 무엇을 하나요
"서울 강남구 테헤란로 123" 같은 한 줄 주소를 시도 / 시군구 / 상세주소로 나눕니다. '서울' 같은 줄임말은 '서울특별시'로 바꿉니다.

## 어떤 업무에 쓰나요
고객 명단 정리, 지역별 집계, 배송 주소 정리.

## 실행 예시
```
python3 main.py --input sample/주소.csv --column 주소
```

## 입력·출력
- 입력: 주소 컬럼이 있는 CSV.
- 출력: `output/주소분리.csv` (원래 컬럼 + 시도, 시군구, 상세주소, 비고).

## 주의사항
- 규칙 기반이라 아주 특이한 주소는 틀릴 수 있습니다. '비고'에 적힌 줄은 눈으로 확인하세요.
- 행정구역이 바뀌면 `main.py`의 SIDO 표를 고치면 됩니다. 도로명 주소 검증은 하지 않습니다.
