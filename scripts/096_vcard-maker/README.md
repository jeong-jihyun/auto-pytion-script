# 096 연락처 CSV를 vCard로 변환

## 무엇을 하나요
엑셀·CSV에 정리한 연락처를 휴대폰, 구글 연락처, 메일 프로그램이 가져올 수 있는 `.vcf` 파일로 바꿉니다.

## 어떤 업무에 쓰나요
거래처·고객 명단 일괄 등록, 직원 연락처 배포.

## 실행 예시
```
python3 main.py --input sample/연락처.csv
```

## 입력·출력
- 입력: CSV(이름,전화,이메일,회사). 이름이 비면 건너뜁니다.
- 출력: `output/연락처.vcf` (vCard 3.0, 여러 명이 한 파일).

## 주의사항
- 샘플 번호·메일은 가짜입니다. 실제 개인정보는 본인 동의 범위 안에서만 다루세요.
- 사진·주소 등 다른 항목은 넣지 않습니다. 앱별 가져오기 결과는 직접 확인하지 못했습니다(미확인).
