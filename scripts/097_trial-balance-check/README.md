# 097 전표 차대 균형 검사·시산표

## 무엇을 하나요
회계 분개 파일에서 전표마다 차변 합 = 대변 합인지 확인하고, 계정별 합계(시산표)를 만듭니다. 안 맞는 전표를 찾아 줍니다.

## 어떤 업무에 쓰나요
ERP 전표 이관 검증, 월마감 점검, 엑셀로 만든 분개 검수.

## 실행 예시
```
python3 main.py --input sample/분개.csv
```
샘플의 J003 전표는 일부러 1,000원이 어긋나 있어 '불균형'으로 나옵니다(종료 코드 1이 정상 동작입니다).

## 입력·출력
- 입력: CSV(전표번호,일자,계정,차변,대변).
- 출력: `output/불균형전표.csv`, `output/시산표.csv`, 화면 요약. 불균형이 있으면 종료 코드 1.

## 주의사항
- 계정과목 코드의 올바름, 통화 환산은 검사하지 않습니다.
- 원본 파일은 읽기만 합니다.
