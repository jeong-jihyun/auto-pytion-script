# 098 폴더 구조를 마크다운 트리로

## 무엇을 하나요
폴더 안의 파일·하위 폴더를 들여쓴 목록으로 만들어 README나 인수인계 문서에 붙일 수 있게 합니다.

## 어떤 업무에 쓰나요
프로젝트 구조 문서화, 인수인계 자료, 폴더 정리 전 현황 파악.

## 실행 예시
```
python3 main.py --root sample/프로젝트 --size
python3 main.py --root . --depth 2 --exclude .git node_modules
```

## 입력·출력
- 입력: `--root` 폴더. 옵션 `--depth`(깊이), `--exclude`(제외 이름), `--size`(크기 표시).
- 출력: `output/폴더구조.md`.

## 주의사항
- 읽기만 합니다. 파일을 바꾸거나 지우지 않습니다.
- 심볼릭 링크는 따라가지 않습니다. 파일이 아주 많으면 `--depth`로 줄이세요.
