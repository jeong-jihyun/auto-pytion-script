# 099 업무일지 주간 요약

## 무엇을 하나요
날마다 적은 업무일지를 주차별·프로젝트별 시간 합계로 묶어 마크다운 주간 보고서를 만듭니다.

## 어떤 업무에 쓰나요
주간 보고, 프로젝트별 투입 시간 집계, 월말 공수 정리.

## 실행 예시
```
python3 main.py --input sample/업무일지.csv
```

## 입력·출력
- 입력: CSV(일자,프로젝트,내용,시간). 일자는 `YYYY-MM-DD`, 시간은 숫자(예: 3.5).
- 출력: `output/주간보고.md`. 주차는 월요일 시작 ISO 주차입니다.

## 주의사항
- 날짜·시간이 잘못된 줄은 건너뛰며 개수를 알려 줍니다.
- 샘플은 가짜 데이터입니다.
