# 100 호가단위 사전 검사

## 무엇을 하나요
주문 목록의 가격이 가격대별 호가단위(예: 5만~20만 원 구간은 100원 단위)에 맞는지, 수량이 올바른지 미리 확인합니다.

## 어떤 업무에 쓰나요
주문 파일 업로드 전 점검, 테스트 주문 데이터 검증, 증권 시스템 입력 검수.

## 실행 예시
```
python3 main.py --input sample/주문.csv --market kospi
```

## 입력·출력
- 입력: CSV(종목,가격,수량), `--market` kospi 또는 kosdaq.
- 출력: `output/호가검사.csv`(정상/오류, 이유, 제안가격).

## 주의사항
- 호가단위 표는 참고용으로 코드에 넣어 둔 값이며 **최신 거래소 규정과 일치하는지는 확인하지 못했습니다(미확인)**. 실제 업무 전에 거래소 공시로 대조하세요.
- ETF·ETN 등 다른 상품의 호가단위는 다루지 않습니다. 실제 주문을 내지 않는 점검 도구입니다.
