# 101 슬로우 쿼리 로그 요약

## 무엇을 하나요?
DB 느린 쿼리 로그에서 값만 다른 같은 모양의 SQL을 하나로 묶고(숫자·문자열·IN 목록을 `?`로 바꿈), 모양별 건수·총시간·평균·최대·p95를 계산해 **총시간이 큰 순서** 로 보여 줍니다.

## 어떤 업무에 쓰나요?
- 배치·온라인 지연 원인 분석, DB 튜닝 대상 고르기
- "어제 어떤 쿼리가 DB를 가장 오래 잡았나" 보고

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/slow.log -o output/slow_query_summary.csv
python3 main.py slow.log --min-ms 1000 --top 20
python3 main.py my.log --pattern "^(?P<ts>\S+ \S+) took=(?P<ms>\d+) sql=(?P<sql>.+)$"   # 로그 형식이 다를 때
```

## 입력 / 출력 예시
- 기본 로그 한 줄: `2026-10-25 09:00:01 [1520ms] SELECT ...` (다르면 `--pattern`에 ts·ms·sql 이름 그룹을 넣은 정규식)
- 출력 CSV 열: `쿼리모양, 건수, 총시간ms, 평균ms, 최대ms, p95ms, 처음, 마지막, 예시SQL`

샘플 결과: 6건 → 모양 4개. 1위 UPDATE stock(4,200ms 1건), 2위 orders 조회(3건 합 3,810ms, 평균 1,270ms). 형식이 다른 줄 1개는 건너뜀.

## 주의사항
- MySQL 기본 슬로우 로그처럼 여러 줄짜리 형식은 바로 읽지 못합니다. 한 줄 형식으로 바꾸거나 `--pattern`을 맞추세요.
- 예시SQL에 실제 고객 값이 들어 있을 수 있으니 공유할 때 주의하세요. 샘플은 가짜 데이터입니다.
