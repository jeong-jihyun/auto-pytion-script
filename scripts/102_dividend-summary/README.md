# 102 배당 내역 요약(배당 달력·수익률)

## 무엇을 하나요?
배당금 입금 내역으로 **연도·종목별 세전/세후 배당 합계**, **월별 배당 현금흐름(배당 달력)** 을 만들고, 보유 파일이 있으면 투자원금 대비 **배당수익률** 을 계산합니다.

## 어떤 업무에 쓰나요?
- 개인·법인 배당 수입 정리, 연말 금융소득 확인 자료 만들기
- 월별 현금흐름 계획(몇 월에 배당이 들어오는지)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/dividends.csv --holdings sample/holdings.csv -o output
python3 main.py sample/dividends.csv --year 2026
```

## 입력 / 출력 예시
- 배당 CSV 열: `지급일(2026-04-20), 종목, 세전배당금, 원천징수세액`
- 보유 CSV 열(선택): `종목, 보유수량, 매입단가`
- 출력: `by_stock.csv`(연도·종목별 합계·수익률), `by_month.csv`(연도별 1~12월, 없는 달은 0)

샘플 결과: 2026년 세전 300,000원 / 세후 253,800원, 입금 달 1·4·5·7·8월. 마바리츠 수익률 6.00%(90,000 ÷ 1,500,000), 가나전자 1.50%.

## 주의사항
- 수익률은 '이 파일에 있는 배당 ÷ 현재 보유 원금'입니다. 중간에 사고판 경우 정확하지 않습니다.
- 세금 계산은 파일에 적힌 원천징수세액을 그대로 씁니다(종합과세 여부는 따지지 않음). 세무 판단은 전문가와 확인하세요.
- 샘플 종목·금액은 가짜입니다.
