# 103 연차 사용·잔여 계산

## 무엇을 하나요?
연차 부여 일수와 사용 내역(기간·구분)으로 사람별 **사용 일수와 남은 연차** 를 계산합니다. 기간 중 주말·휴일은 빼고, 반차(0.5일)·반반차(0.25일)도 셉니다. 초과 사용, 사용 촉진 대상, 같은 날 중복 신청을 표시합니다.

## 어떤 업무에 쓰나요?
- 인사·총무의 월말·연말 연차 현황표 만들기
- 연차 사용 촉진 안내 대상 뽑기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/grants.csv sample/usage.csv --holidays 2026-05-05,2026-10-09 --promote 10 -o output/leave_balance.csv
```

## 입력 / 출력 예시
- 부여 CSV 열: `이름, 부여일수, 이월일수`
- 사용 CSV 열: `이름, 시작일, 종료일, 구분(연차/반차/오전반차/오후반차/반반차)`
- 출력 CSV 열: `이름, 부여(이월포함), 사용, 잔여, 상태(정상/초과 사용/사용 촉진 대상)`

샘플 결과: 가직원 사용 7일(5/5 휴일 제외) 잔여 10, 나직원 사용 5.5일 잔여 9.5, 다직원 사용 1.25일(10/9 휴일 제외) 잔여 9.75. 나직원 9/10 반차+연차 중복 신청 경고.

## 주의사항
- 연차 '부여 일수' 계산(근속연수별 법정 일수)은 하지 않습니다. 회사 기준으로 계산한 값을 넣으세요.
- 휴일은 `--holidays`로 직접 넣어야 합니다. 이 결과는 참고용이며 최종 확인은 인사 담당자가 합니다.
- 샘플 이름은 가짜입니다.
