# 104 파일 이름 규칙 점검

## 무엇을 하나요?
폴더 안 파일 이름이 정한 규칙(기본: `문서번호_YYYYMMDD_제목_v버전.확장자`)을 지키는지 검사합니다. 규칙 위반, 실제로 없는 날짜, 공백·특수문자를 찾고, 같은 문서의 여러 버전 중 **최신이 아닌 옛 버전** 도 표시합니다. 파일 이름은 바꾸지 않습니다.

## 어떤 업무에 쓰나요?
- 공유 드라이브·산출물 폴더의 문서 이름 규칙 점검(프로젝트 산출물 관리, 감리 대응)
- 옛 버전 파일 정리 전 목록 만들기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/docs -o output/filename_check.csv
python3 main.py 산출물 --recursive
python3 main.py 사진 --rule "^\d{8}_\d{6}\.(jpg|png)$"       # 규칙을 바꿔서
```

## 입력 / 출력 예시
- 기본 규칙에 맞는 이름: `ABC-001_20261025_주간보고_v1.docx`
- 출력 CSV 열: `파일, 결과(정상/확인 필요), 문제, 버전(최신/옛 버전)`

샘플 결과: 6개 중 확인 필요 3개(날짜 20261345 오류, 소문자 문서번호 규칙 위반, '주간보고 최종.docx' 규칙 위반+공백), 옛 버전 1개(주간보고 v1, 최신 v2).

## 주의사항
- 규칙 정규식에 `(?P<date>...)`, `(?P<ver>...)`, `(?P<docno>...)`, `(?P<title>...)` 이름 그룹을 넣으면 날짜·버전 점검이 함께 됩니다.
- 이름을 고칠 때는 003 파일 이름 일괄 변경 스크립트를 쓰세요. 샘플 파일은 내용 없는 가짜 파일입니다.
