# 105 상태 전이(상태 변경 이력) 검사

## 무엇을 하나요?
주문·전표·요청 건의 **상태 변경 이력** 이 정해진 순서(접수→승인→출고→완료 등)대로 바뀌었는지 검사합니다. 단계 건너뛰기, 끝난 뒤 다시 바뀜, 시작 상태가 아님, 오래 멈춘 건(정체)을 찾습니다.

## 어떤 업무에 쓰나요?
- ERP·주문 시스템 데이터 정합성 점검, 장애 후 데이터 검증
- 업무 프로세스 위반(승인 없이 출고 등) 감사, 테스트 데이터 검증

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/history.csv --rules sample/rules.json --today "2026-10-25 09:00" -o output/transition_check.csv
python3 main.py history.csv --stale-days 3
```

## 입력 / 출력 예시
- 이력 CSV 열: `건번호, 변경일시(2026-10-20 09:00), 상태`
- 규칙 JSON: `start`(시작 상태), `final`(끝 상태), `transitions`(상태별 다음에 갈 수 있는 상태)
- 출력 CSV 열: `건번호, 상태경로, 현재상태, 결과, 문제`

샘플 결과: 5건 중 4건 확인 필요 — O-2 접수→완료(승인 건너뜀), O-3 취소 뒤 승인, O-4 15일째 승인에 정체, O-5 접수 없이 승인부터 시작.

## 주의사항
- 변경일시가 같은 줄이 여러 개면 순서를 알 수 없어 결과가 틀릴 수 있습니다. 초 단위까지 있으면 형식을 맞춰 고쳐 쓰세요.
- `--today`를 비우면 지금 시각 기준으로 정체를 계산합니다. 샘플은 가짜 데이터입니다.
