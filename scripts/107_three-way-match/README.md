# 107 발주·입고·청구 3자 대사

## 무엇을 하나요?
발주(PO), 입고(GR), 청구(Invoice) 세 파일을 `발주번호 + 품목코드`로 맞춰, **과입고, 입고보다 많은 청구, 단가 차이, 발주 없는 청구** 를 찾고 줄마다 '지급 가능 / 지급 보류 / 청구 대기'를 판정합니다. 나눠서 입고·청구된 건은 합쳐서 봅니다.

## 어떤 업무에 쓰나요?
- 구매·회계의 대금 지급 전 점검(ERP 3-way match를 엑셀로 하던 일)
- 협력사 청구서 검수, 월말 미청구·미입고 확인

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/po.csv sample/gr.csv sample/inv.csv -o output/three_way_match.csv
python3 main.py po.csv gr.csv inv.csv --price-tol 1     # 단가 1% 차이까지는 허용
```

## 입력 / 출력 예시
- 발주 CSV: `발주번호, 품목코드, 발주수량, 발주단가`
- 입고 CSV: `발주번호, 품목코드, 입고수량`
- 청구 CSV: `발주번호, 품목코드, 청구수량, 청구단가`
- 출력 CSV: `발주번호, 품목코드, 발주수량, 입고수량, 청구수량, 발주단가, 청구단가, 청구금액, 판정, 문제`

샘플 결과: 5줄 중 지급 보류 3줄(청구 495,000원) — B200 입고 30개인데 50개 청구, C300 과입고+단가 20,000→21,000원, Z999 발주·입고 없이 청구. D400은 청구 대기, A100(두 번 나눠 입고)은 지급 가능.

## 주의사항
- 단가는 여러 줄이면 가중평균으로 비교합니다.
- 부가세·할인·운임은 따로 보지 않습니다. 같은 기준(공급가)으로 맞춘 파일을 넣으세요.
- 판정은 참고용이며 실제 지급 결정은 담당자가 합니다. 샘플은 가짜 데이터입니다.
