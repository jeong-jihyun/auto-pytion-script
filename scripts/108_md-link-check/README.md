# 108 마크다운 내부 링크 점검

## 무엇을 하나요?
문서 폴더의 `.md` 파일에서 `[글자](주소)` 링크와 `![그림](주소)` 그림 경로를 뽑아, **가리키는 파일이 실제로 있는지**, `#제목` 앵커가 대상 문서에 **실제 제목으로 있는지** 확인합니다. 코드 블록 안 예시는 건너뛰고, 외부(http) 링크는 접속하지 않고 개수만 셉니다.

## 어떤 업무에 쓰나요?
- 사내 위키·README·운영 매뉴얼 정리 후 깨진 링크 찾기
- 폴더 구조를 바꾸거나 파일 이름을 바꾼 뒤 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/docs -o output/md_links.csv
python3 main.py ../..          # 이 저장소 전체 문서 점검
```

## 입력 / 출력 예시
- 입력: 폴더(하위 폴더 포함 모든 .md)
- 출력 CSV 열: `문서, 줄, 종류(링크/그림), 주소, 문제(파일 없음/제목(앵커) 없음)`

샘플 결과: 마크다운 2개, 깨진 링크 3개 — 없는 operation.md, 없는 제목 `#없는-제목`, 없는 그림 logo.png. 코드 블록 안 링크와 외부 링크 1개는 검사하지 않음.

## 주의사항
- 제목→앵커 변환은 GitHub 방식을 흉내 낸 것이라, 다른 위키 도구에서는 다를 수 있습니다.
- 외부 링크가 살아 있는지는 확인하지 않습니다(인터넷 접속 안 함).
- 샘플 문서는 가짜입니다.
