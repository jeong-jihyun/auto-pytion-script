# 109 회의실·자원 사용률 집계

## 무엇을 하나요?
회의실·차량·장비 예약 내역으로 자원별 **사용률(업무시간 대비 예약 시간)** 과 **시간대별 혼잡도** 를 계산합니다. 취소 예약은 빼고, 업무시간 밖은 잘라 내고, 겹친 예약은 한 번만 셉니다.

## 어떤 업무에 쓰나요?
- 총무팀의 회의실 증설·축소 검토 근거 자료
- 법인차량·공용 장비 활용도 보고

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/bookings.csv --start 2026-10-19 --end 2026-10-23 -o output
python3 main.py bookings.csv --start 2026-10-01 --end 2026-10-31 --work 08:30-17:30
```

## 입력 / 출력 예시
- 예약 CSV 열: `자원, 시작(2026-10-19 09:00), 종료, 상태(확정/취소)`
- 출력: `utilization.csv`(자원, 사용시간, 가능시간, 사용률%), `by_hour.csv`(시각별 평균 사용 자원 수, 혼잡도%)

샘플 결과(평일 5일, 하루 9시간): 회의실A 11.1%(겹친 예약 9~11·10~12시를 3시간으로 합침), 회의실B 4.4%(18시 이후·취소 예약 제외), 회의실C 2.2%. 가장 붐비는 시간 10시.

## 주의사항
- 공휴일은 빼지 않습니다. 공휴일이 낀 기간은 가능시간이 조금 크게 잡힙니다.
- 예약했지만 실제로 쓰지 않은 '노쇼'는 알 수 없습니다. 샘플은 가짜 데이터입니다.
