# 110 배치 작업 선후관계 실행 순서 계산

## 무엇을 하나요?
배치 작업 목록과 선행작업(이 작업이 끝나야 시작)을 읽어, **실행 순서(단계별로 동시에 돌릴 수 있는 묶음)**, **임계 경로(가장 오래 걸리는 줄기)와 전체 예상 시간**, **순환 의존**, **목록에 없는 선행작업(오타)** 을 알려 줍니다.

## 어떤 업무에 쓰나요?
- 야간 배치 스케줄 설계·변경 검토, 배치 지연 시 어느 작업을 줄여야 전체가 빨라지는지 찾기
- 스케줄러(잡 관리 도구) 등록 전 의존 관계 오류 점검

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/jobs.csv -o output/job_order.csv
```

## 입력 / 출력 예시
- 작업 CSV 열: `작업ID, 선행작업(여러 개는 ;), 예상분`
- 출력 CSV 열: `단계, 작업ID, 선행작업, 예상분, 예상시작(분), 예상종료(분)` (순환 작업은 단계 '순환')

샘플 결과: 9개 중 7개가 5단계로 실행 가능, 임계 경로 수신_주문파일 → 적재_주문 → 대사_주문정산 → 집계_일보 → 발송_일보(67분). 재처리_A·B는 서로 기다리는 순환, '메일서버점검'은 목록에 없는 선행작업으로 경고.

## 주의사항
- 예상 시간은 '선행이 모두 끝나면 바로 시작'한다고 가정합니다. 동시 실행 수 제한(서버 자원)은 반영하지 않습니다.
- 목록에 없는 선행작업은 무시하고 계산하니, 경고를 꼭 확인하세요. 샘플은 가짜 작업입니다.
