# 111 로그 공백 구간 탐지

## 무엇을 하나요?
로그 줄 사이 시간 간격을 보고 **로그가 기준 시간(분) 이상 끊긴 구간**을 찾습니다. 업무 시간(예: 09:00-18:00)을 주면 그 시간대에 겹친 공백만 셉니다.

## 어떤 업무에 쓰나요?
- "에러는 없는데 사실 프로그램이 멈춰 있었다"를 잡아내기 (수신 데몬·배치 서버·연계 프로그램)
- 장애 보고서 작성 때 멈춘 시간대 확인

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/app.log --gap 10 --window 09:00-18:00 -o output/log_gaps.csv
```

## 입력 / 출력 예시
- 입력: 줄 맨 앞에 `2026-10-26 09:00:10` 같은 시각이 있는 로그 (대괄호 `[...]`, `T` 구분도 됨). 시각 없는 줄은 건너뜀.
- 출력 CSV 열: `공백시작(마지막로그), 공백끝(다음로그), 전체공백분, 업무시간내공백분`

샘플 결과(업무시간 09-18시, 10분 기준): 09:09→09:41(31.4분), 09:50→12:00(130분), 12:03→17:50(347분), 17:50→23:30(전체 340분 중 업무시간 10분) 4건. 23:30→다음날 09:02는 업무시간에 겹친 것이 2분뿐이라 빠집니다.

## 주의사항
- 여러 파일을 주면 시각을 모두 합쳐 정렬합니다. 서버 시각이 서로 다르면 결과가 틀어질 수 있습니다.
- 주말·휴일도 업무 시간으로 계산합니다. 샘플은 가짜 로그입니다.
