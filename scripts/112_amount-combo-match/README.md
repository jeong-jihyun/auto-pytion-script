# 112 입금-청구 금액 조합 매칭

## 무엇을 하나요?
입금 1건이 **여러 청구서를 합쳐 낸 돈**일 때, 같은 거래처의 미결 청구 중 **합계가 입금액과 같은 조합**을 찾아 줍니다. 가장 적은 건수의 조합을 먼저 고르고, 송금수수료만큼 차이를 허용할 수도 있습니다.

## 어떤 업무에 쓰나요?
- 채권 입금 소액 대사(가상계좌·청구번호 없이 들어온 입금 정리)
- 미결 항목(가수금) 정리 전 후보 찾기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/deposits.csv sample/invoices.csv --tolerance 500 -o output
```

## 입력 / 출력 예시
- 입금 CSV: `입금ID, 거래처, 금액` / 청구 CSV: `청구ID, 거래처, 금액` (금액의 쉼표 허용)
- 출력: `matched.csv`(입금ID, 거래처, 입금액, 매칭청구ID, 청구합계, 차액), `unmatched_deposits.csv`, `unmatched_invoices.csv`

샘플 결과(허용 차액 500원): D01 1,350,000 ← INV-101+INV-102+INV-103, D03 749,500 ← INV-201+INV-202(차액 -500), D02 200,000은 INV-103이 이미 쓰여 INV-104(300,000)와 안 맞아 미매칭, D04 90,000도 미매칭.

## 주의사항
- 결과는 **제안**입니다. 같은 합계가 되는 조합이 여러 개일 수 있으니 반드시 사람이 확인하세요.
- 큰 입금부터 처리하므로 위 D02처럼 작은 입금이 밀릴 수 있습니다. 이럴 땐 확인 후 매칭을 직접 조정하세요.
- 후보가 많으면 계산이 오래 걸립니다. `--max-items`, `--max-candidates`로 줄이세요. 거래처명이 정확히 같아야 합니다. 샘플은 가짜 데이터입니다.
