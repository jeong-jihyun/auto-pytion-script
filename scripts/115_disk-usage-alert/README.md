# 115 디스크 사용률 경고

## 무엇을 하나요?
CSV에 적은 여러 경로(드라이브·마운트)의 **디스크 사용률**을 읽어 경로별 경고/위험 기준과 비교하고, 결과 표를 만듭니다. 위험이 있으면 종료 코드 2, 경고만 있으면 1을 돌려줍니다.

## 어떤 업무에 쓰나요?
- 야간 배치 시작 전 "디스크 꽉 참" 실패 예방 점검
- 로그·백업 폴더가 있는 서버의 아침 점검표 작성
- 작업 스케줄러(cron, 윈도우 작업 스케줄러)에 걸어 종료 코드로 알림

## 설치
파이썬 3.8 이상. 설치할 것 없음. 윈도우는 경로에 `C:\` 처럼 적으면 됩니다.

## 실행 예시
```
python3 main.py sample/targets.csv -o output/disk_usage.csv
echo $?   # 0 정상, 1 경고(또는 경로없음), 2 위험
```

## 입력 / 출력 예시
- 입력 CSV 열: `이름, 경로, 경고퍼센트, 위험퍼센트` (비우면 80, 90)
- 출력 CSV 열: `이름, 경로, 전체GB, 사용GB, 남은GB, 사용률%, 상태(정상/경고/위험/경로없음)`

샘플은 결과를 일부러 보여 주려고 '현재폴더' 기준을 1%·2%로 낮춰 두어 **위험**이 나오고, 없는 경로는 **경로없음**으로 표시되며 종료 코드는 2입니다. 실제 사용 땐 기준을 80·90 정도로 바꾸세요.

## 주의사항
- 읽기만 하고 아무것도 지우지 않습니다. 정리는 `024_old-file-cleaner` 같은 다른 스크립트를 쓰세요.
- 사용률은 `df` 명령처럼 '사용 ÷ (사용 + 남은 공간)'으로 계산합니다(관리자 예약 공간 제외).
- 네트워크 드라이브는 응답이 느리면 오래 걸릴 수 있습니다. 사용률 숫자는 실행한 컴퓨터마다 다릅니다.
