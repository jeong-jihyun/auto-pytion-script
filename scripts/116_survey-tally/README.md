# 116 설문 응답 집계

## 무엇을 하나요?
설문 도구에서 내려받은 응답 CSV를 **단일선택 / 복수선택 / 점수** 문항으로 나눠 집계하고, 결과 CSV와 읽기 쉬운 마크다운 요약을 만듭니다.

## 어떤 업무에 쓰나요?
- 사내 만족도 조사, 교육 후 설문, 시스템 도입 수요 조사 결과 정리
- 복수선택 칸(`엑셀;ERP`)을 일일이 나눠 세던 수작업 대체

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/responses.csv --single 소속 --multi 사용도구 --scale 만족도 -o output
```

## 입력 / 출력 예시
- 입력: 한 줄 = 응답자 1명, 한 열 = 문항 1개인 CSV. 복수선택은 한 칸에 `;`로 구분(`--sep`으로 변경 가능)
- 출력: `survey_tally.csv`(문항, 종류, 보기, 응답수, 비율%), `survey_summary.md`(문항별 표)

샘플 결과: 응답자 6명. 소속은 영업팀·재무팀 각 2명(33.3%), 무응답 1명. 사용도구는 엑셀 4명(66.7%), 메신저 3명, ERP 2명, 무응답 1명. 만족도 평균 3.83점.

## 주의사항
- 복수선택 비율은 '응답자 대비'라 합이 100%를 넘습니다.
- 주관식(의견) 문항은 집계하지 않습니다. 열 이름은 CSV 첫 줄과 정확히 같아야 합니다. 샘플은 가짜 응답입니다.
