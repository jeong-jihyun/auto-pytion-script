# 117 현금 지급 권종 계산

## 무엇을 하나요?
사람별 현금 지급액을 **5만원권·1만원권·5천원권·1천원권·동전**으로 나눠 몇 장씩 필요한지 계산하고, 권종별 합계(은행에서 찾을 목록)를 만듭니다.

## 어떤 업무에 쓰나요?
- 현금 봉투 준비(일용직 일당, 경조금, 시상금, 소액 환급)
- 시재(현금) 준비 금액 확인

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/payees.csv -o output/cash_denomination.csv
python3 main.py sample/payees.csv --denoms 50000,10000,5000,1000   # 지폐만
```

## 입력 / 출력 예시
- 입력 CSV 열: `이름, 금액` (쉼표 허용, 원 단위 정수)
- 출력 CSV: 사람별 권종 장수 + 마지막 줄 합계 + 나눌 수 없는 나머지

샘플 결과: 4명 총 295,965원 → 5만원 4장, 1만원 8장, 5천원 2장, 1천원 5장, 500원 1장, 100원 4장, 50원 1장, 10원 1장, 나눌 수 없는 나머지 5원(박가상).

## 주의사항
- 큰 권종부터 나누는 방식이라 원화 권종에서는 장수가 가장 적게 나옵니다. 권종을 특이하게 바꾸면(예: 30000원권) 최소 장수가 아닐 수 있습니다.
- 현금 지급은 영수증·지급 대장 같은 증빙을 꼭 함께 남기세요. 샘플은 가짜 이름입니다.
