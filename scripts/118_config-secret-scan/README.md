# 118 설정 파일 평문 비밀번호 점검

## 무엇을 하나요?
폴더 안의 설정 파일(.properties, .yml, .env, .ini, .json, .xml 등)에서 **비밀번호·토큰·API 키가 평문으로 적힌 줄**과 **URL 안의 `아이디:비밀번호@`**, **개인키 파일 내용**을 찾아 보고합니다. 보고서에도 값은 앞 2글자만 남기고 가립니다.

## 어떤 업무에 쓰나요?
- 배포·저장소 업로드 전 "비밀번호가 들어간 설정 파일" 사전 점검
- 공유 폴더·인수인계 자료에 남은 계정 정보 정리

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample -o output/secret_scan.csv
python3 main.py 내프로젝트폴더 --all-files
```

## 입력 / 출력 예시
- 입력: 점검할 폴더(하위 폴더 포함, `.git` 폴더는 제외)
- 출력 CSV 열: `파일, 줄, 종류(평문 비밀값/URL안 비밀번호/개인키), 키, 값(가림)`
- `${API_KEY}`, `<...>`, 빈 값, `changeme` 같은 자리표시자는 정상으로 보고 넘어갑니다.

샘플 결과: 3건 — application.properties의 `db.password`, config.yml의 `token`과 FTP 주소 안 비밀번호. `api.key=${API_KEY}`, `.env.example`의 `changeme`는 넘어갑니다.

## 주의사항
- **내가 관리하는 파일을 점검하는 용도**입니다. 남의 시스템·파일을 뒤지는 데 쓰지 마세요.
- 이름·모양 규칙으로 찾으므로 놓치는 것(예: 키 이름이 엉뚱한 경우)과 잘못 잡는 것이 있을 수 있습니다.
- 찾은 값이 이미 공유됐다면 지우는 것만으로는 부족합니다. 비밀번호를 바꾸세요. 샘플 값은 모두 가짜입니다.
