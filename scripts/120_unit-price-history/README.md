# 120 품목별 구매 단가 이력·급등 경고

## 무엇을 하나요?
구매 내역을 품목별·날짜순으로 정리해 **직전 구매 대비 단가 변동률**을 계산하고, 기준(기본 ±10%)을 넘게 오르거나 내린 구매를 **급등/급락**으로 표시합니다. 품목별 최저·최고·최근 단가와 수량가중 평균 단가 요약도 만듭니다.

## 어떤 업무에 쓰나요?
- 구매·원가 관리: 단가 인상 미보고, 계약 단가 위반, 단가 입력 실수 찾기
- 내부 감사의 구매 단가 적정성 점검, 원가 상승 보고 자료

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/purchases.csv --threshold 10 -o output
```

## 입력 / 출력 예시
- 입력 CSV 열: `일자(YYYY-MM-DD), 품목, 거래처, 수량, 단가` (쉼표 허용)
- 출력: `price_history.csv`(품목, 일자, 거래처, 수량, 단가, 직전단가, 직전대비%, 표시), `price_summary.csv`(품목, 구매횟수, 최저·최고·최근 단가, 수량가중평균단가, 처음대비%)

샘플 결과: A4용지는 9-02 다라오피스 구매가 24,500 → 28,900(+17.96%) 급등, 10-06은 다시 25,000(-13.49%) 급락. 토너는 10-12에 88,000 → 79,000(-10.23%) 급락.

## 주의사항
- 품목 이름이 정확히 같아야 같은 품목으로 묶입니다(규격·단위가 다르면 다른 이름으로 적으세요).
- 거래처가 달라도 같은 품목이면 함께 비교합니다. 부가세 포함/제외 기준을 한 가지로 맞추세요. 샘플은 가짜 데이터입니다.
