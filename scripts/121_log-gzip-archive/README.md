# 121 오래된 로그 gzip 압축

## 무엇을 하나요?
로그 폴더에서 **며칠(기본 7일)보다 오래된 로그 파일**을 골라 `.gz`로 압축합니다. 압축본을 다시 풀어 원본과 내용이 똑같은지 확인한 뒤에만 원본을 지웁니다(`--keep`이면 원본도 남김).

로그 날짜는 **파일 이름 속 날짜**(`app-2026-10-01.log`, `batch_20261001.log`)로 먼저 판단하고, 이름에 날짜가 없으면 파일 수정일로 판단합니다.

## 어떤 업무에 쓰나요?
- 배치·서버의 디스크가 로그로 가득 차기 전에 정리할 때
- 지우면 안 되는(감사·장애 분석용) 로그를 작게 보관할 때

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
# 1) 미리보기: 무엇이 압축될지만 보여 줍니다(파일은 그대로)
python3 main.py sample/logs --days 7 --today 2026-10-27

# 2) 실제 압축 (샘플은 복사본으로 해 보세요)
python3 main.py 내로그폴더 --days 7 --apply

# 하위 폴더까지, .txt 로그도
python3 main.py 내로그폴더 --recursive --pattern "*.txt" --apply
```

## 입력 / 출력 예시
- 입력: 로그 폴더 (샘플: `app-2026-10-01.log` 등 가짜 로그 6개)
- 출력: 같은 자리에 `원래이름.log.gz`. 화면에 압축 전후 크기와 절약한 용량을 보여 줍니다.

샘플(기준일 2026-10-27, 7일 초과) 결과: `app-2026-10-01.log`, `app-2026-10-10.log`, `batch_20261005.log` 3개가 압축 대상, 나머지 3개는 그대로.

## 주의사항
- 기본은 **미리보기**입니다. `--apply`를 붙여야 실제로 바뀝니다.
- 지금 프로그램이 쓰고 있는 로그는 기준일 안쪽이라 대상이 되지 않지만, 날짜 없는 파일은 수정일로 판단하니 기준 일수를 넉넉히 주세요.
- 이미 `.gz`가 있는 파일은 건너뜁니다. 압축본은 `zcat`, `gzip -d`, 반디집·7-Zip 등으로 열 수 있습니다.
- 샘플 로그는 가짜 데이터입니다.
