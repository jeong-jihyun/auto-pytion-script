# 122 URL 상태 점검(헬스체크)

## 무엇을 하나요?
CSV에 적은 웹 주소(사내 시스템, API, 홈페이지)에 한 번씩 접속해 **응답 코드·응답 시간·본문 문구**를 확인하고 `정상 / 느림 / 이상 / 실패`로 나눠 보여 줍니다. 결과는 `health_날짜시간.csv`로 남고, 정상이 아닌 것이 하나라도 있으면 **종료 코드 1**을 돌려줍니다.

## 어떤 업무에 쓰나요?
- 아침 시스템 점검(관리 화면·API·배치 서버 상태 페이지 열어 보기)을 자동으로
- 배포 후 주요 화면이 잘 뜨는지 확인, 작업 스케줄러에 걸어 두고 실패 시 알림

## 설치
파이썬 3.8 이상. 설치할 것 없음(표준 라이브러리 `urllib`).

## 실행 예시
```
python3 main.py sample/targets.csv --timeout 5 -o output
```
샘플은 내 컴퓨터(127.0.0.1:8765)를 점검합니다. 먼저 다른 창에서 아무 폴더에 `index.html`(내용에 '정상 운영' 포함)을 두고 `python3 -m http.server 8765 --bind 127.0.0.1`을 켜 두세요.

## 입력 / 출력 예시
- 입력 CSV 열: `이름, url, 기대코드(기본 200), 기준ms(기본 1000), 포함문구(선택)`
- 출력 CSV 열: `이름, url, 상태, 응답코드, 응답ms, 메모`

샘플 결과(테스트 실행):
```
[정상] 로컬-메인        200  15ms
[이상] 로컬-문구틀림     200   1ms  본문에 '점검중' 없음
[이상] 로컬-없는페이지   404   1ms  기대 200, 실제 404
[정상] 로컬-404기대     404   0ms
[실패] 닫힌포트               Connection refused
```

## 주의사항
- **내가 관리하거나 점검을 허락받은 주소만** 넣으세요. 남의 사이트를 짧은 간격으로 반복 요청하면 안 됩니다.
- 로그인이 필요한 화면은 점검하지 않습니다(비밀번호를 파일에 적지 마세요). 로그인 없이 열리는 상태 페이지를 쓰세요.
- 회사 프록시 환경에서는 `HTTPS_PROXY`, `NO_PROXY` 환경변수를 따릅니다.
