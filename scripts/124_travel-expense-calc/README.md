# 124 출장비(여비) 계산

## 무엇을 하나요?
출장 내역(누가, 어느 지역 등급으로, 언제부터 언제까지, 숙박비·교통비 실비)과 **여비 규정 JSON**을 넣으면
- 일수·박수를 세고(당일 출장 = 1일 0박)
- 일비·식비 = 일수 × 하루 금액, 숙박 인정액 = min(실제 숙박비, 박수 × 1박 한도), 교통비 = 실비
- 한도를 넘은 숙박비는 '본인 부담'으로 따로 표시하고
- 출장 건별 계산표와 사람별 합계표를 만듭니다.

## 어떤 업무에 쓰나요?
- 총무·회계팀의 월별 출장비 정산, 출장 신청서 금액 미리 계산
- 숙박비 한도 초과, 당일 출장인데 숙박비가 있는 이상한 신청 찾기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/trips.csv --rules sample/rules.json -o output
```

## 입력 / 출력 예시
- 출장 CSV 열: `이름, 부서, 지역등급, 시작일(YYYY-MM-DD), 종료일, 숙박비, 교통비` (쉼표 금액 가능)
- 규정 JSON: `{"지역등급": {"일비": 25000, "식비": 25000, "숙박한도": 100000}, ...}` — **회사 규정 금액으로 바꿔 쓰세요**(샘플 금액은 예시일 뿐입니다).
- 출력: `trip_detail.csv`(건별 일수·박수·일비·식비·숙박인정·교통비·지급합계·메모), `person_total.csv`(사람별 합계)

샘플 결과:
```
김가상(정산팀) 출장 2건 4일 → 지급 491,800원
  [메모] 김가상 2026-10-05~2026-10-07: 숙박 한도 초과 30,000원 본인 부담
  [메모] 박예시 2026-10-21~2026-10-21: 당일 출장인데 숙박비 있음(확인 필요)
  [오류] 7행 박예시: 규정에 없는 지역등급 '제주'
```

## 주의사항
- 해외 출장의 환율 환산은 하지 않습니다. 숙박비·교통비는 원화로 바꿔 넣으세요(062 외화 금액 환산 스크립트 활용).
- 규정에 없는 지역등급, 종료일이 시작일보다 빠른 줄은 계산하지 않고 오류로 알려 줍니다.
- 샘플의 이름·금액은 가짜입니다.
