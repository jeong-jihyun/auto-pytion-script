# 126 부서가 섞이는 테이블(조) 배정

## 무엇을 하나요?
교육·워크숍·회식 참석자 명단(이름, 부서)을 넣으면 **같은 부서가 한 테이블에 몰리지 않게** 테이블(조)을 짜 줍니다.
사람 많은 부서부터 한 명씩, '그 부서 사람이 가장 적고 인원이 가장 적은 테이블'에 앉히는 방식입니다.
`--seed` 값이 같으면 언제 돌려도 같은 결과가 나와서 "공정하게 무작위로 짰다"는 근거로 남길 수 있습니다.

## 어떤 업무에 쓰나요?
- 사내 교육·워크숍 조 편성, 신입사원 멘토 조, 행사 좌석 배치
- 부서 간 교류 프로그램 테이블 배정

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/people.csv --seats 5 -o output           # 테이블 수 자동(20명 ÷ 5석 = 4개)
python3 main.py sample/people.csv --tables 5 --seats 6 --seed 7  # 테이블 수 직접 지정
```

## 입력 / 출력 예시
- 입력 CSV 열: `이름, 부서`
- 출력 `seating.csv` 열: `테이블, 좌석, 이름, 부서`. 화면에 테이블별 명단과 '같은 부서 최대 몇 명'을 보여 줍니다.

샘플(20명, 5개 부서, 5석) 결과: 테이블 4개 × 5명, 한 테이블에 같은 부서 최대 2명(IT운영팀 6명 ÷ 4테이블이라 2명이 최소).
자리가 모자라면(`--tables 2 --seats 5`) 배정 전에 "자리가 모자랍니다"라고 알려 주고 멈춥니다.

## 주의사항
- 이름이 같은 사람이 있으면 구분되도록 이름 뒤에 사번 등을 붙여 주세요.
- '이 두 사람은 떨어뜨려 주세요' 같은 조건은 지원하지 않습니다. 결과를 보고 손으로 바꾸세요.
- 샘플 이름은 모두 지어낸 가명입니다.
