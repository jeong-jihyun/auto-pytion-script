# 127 주문-체결 대사

## 무엇을 하나요?
주문 내역과 체결 내역을 **주문번호**로 맞춰서
- 주문마다 체결수량 합계, 미체결수량, 평균 체결가(수량가중), 상태(전량체결·부분체결·미체결)를 정리하고
- 있으면 안 되는 일(**과체결, 주문 없는 체결, 지정가 위반 체결**)을 문제 목록으로 뽑습니다.
문제가 하나라도 있으면 종료 코드 1을 돌려줍니다(장 마감 후 배치 점검용).

## 어떤 업무에 쓰나요?
- 증권·선물 시스템의 장 마감 후 주문/체결 정합성 점검
- 외부 거래소·브로커 체결 통보와 내부 주문 원장 대사, 시스템 전환·테스트 결과 검증

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/orders.csv sample/fills.csv -o output
```

## 입력 / 출력 예시
- 주문 CSV 열: `주문번호, 계좌, 종목, 매매(매수/매도), 주문유형(지정가/시장가), 주문수량, 주문가격`
- 체결 CSV 열: `체결번호, 주문번호, 체결수량, 체결가격, 체결시각`
- 출력: `order_status.csv`(주문별 상태), `issues.csv`(문제 목록)

샘플 결과:
```
주문 상태: 전량체결 3건, 부분체결 1건, 과체결 1건, 미체결 1건
  [문제:주문없는체결] 주문 O-0999 체결 F-08 - 체결 5주 @ 9,900
  [문제:과체결] 주문 O-0004 - 주문 200주인데 체결 합계 220주
  [문제:지정가위반] 주문 O-0005 체결 F-07 - 매도 지정가 412000인데 411500에 체결
```
O-0001의 평균 체결가 = (60×70,900 + 40×71,000) ÷ 100 = 70,940

## 주의사항
- 정정·취소 주문은 따로 다루지 않습니다. 정정 후 최종 주문수량·가격으로 주문 CSV를 만들어 넣으세요.
- 시장가 주문은 가격 위반 검사를 하지 않습니다.
- 샘플 종목·계좌는 지어낸 가짜입니다.
