# 128 채권 수익률·단가·듀레이션 계산

## 무엇을 하나요?
고정금리 채권(표면금리, 연 이자 지급횟수, 결제일, 만기일)마다
- **수익률을 주면 단가**(액면 10,000원 기준, 경과이자 뺀 clean)를,
- **단가를 주면 수익률**(만기수익률, YTM)을 거꾸로 구하고,
- 경과이자, 경과이자 포함 가격(dirty), 다음 이자 지급일, 맥컬리·수정 듀레이션을 함께 계산합니다.

## 어떤 업무에 쓰나요?
- 채권 매매·운용 화면 값의 검산, 시스템 개발 시 계산 로직 테스트 기대값 만들기
- 금리가 1%p 변하면 가격이 얼마나 변하는지(수정 듀레이션) 빠르게 확인

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/bonds.csv -o output/bond_result.csv
python3 main.py sample/bonds.csv --face 100     # 액면 100 기준으로
```

## 입력 / 출력 예시
- 입력 CSV 열: `종목, 표면금리(%), 지급횟수(1/2/4/12), 결제일, 만기일, 수익률(%), 단가` — 수익률과 단가 중 **하나만** 채웁니다.
- 출력 CSV 열: `종목, 계산, 수익률%, 단가(clean), 경과이자, 가격(dirty), 다음지급일, 남은지급횟수, 맥컬리듀레이션(년), 수정듀레이션`

샘플 결과:
```
검산용-액면발행  수익률 5.0000% | 단가 10,000.00 + 경과이자 0.00 = 10,000.00 | 수정듀레이션 4.376
가상국고채3년   수익률 2.9500% | 단가 10,074.90 + 경과이자 123.43 = 10,198.33 | 수정듀레이션 2.467
예시금융채1년   단가→수익률: 수익률 3.3572% | 단가 10,012.50
```
검산: 표면금리 = 수익률이고 이자 지급일에 사면 단가가 정확히 10,000원, 구한 단가를 다시 넣으면 같은 수익률(2.95%)이 나오고, 수정 듀레이션이 금리를 ±0.01%p 움직인 실제 가격 변화와 같습니다(2.467).

## 주의사항
- **교육·검산용 단순 모형**입니다. 휴일 조정, 이표일 관행(말일 규칙), 세금, 민평 평가사의 계산 방식과 소수점 처리는 다를 수 있습니다.
- 이자 지급일은 만기일에서 거꾸로 같은 날짜로 만듭니다(31일 → 짧은 달은 말일).
- 변동금리·할인채(무이표)·옵션부 채권은 다루지 않습니다. 샘플 종목은 가짜입니다.
