# 129 새 파일·바뀐 파일만 복사(한 방향 동기화)

## 무엇을 하나요?
원본 폴더와 대상 폴더를 비교해 **새 파일·바뀐 파일만** 대상으로 복사합니다. 하위 폴더 구조도 그대로 맞춥니다.

| 상태 | 뜻 | 하는 일 |
|---|---|---|
| 새파일 | 대상에 없음 | 복사 |
| 바뀜 | 내용이 다름 | 대상의 옛 파일을 `_mirror_backup/날짜시간/`에 보관한 뒤 복사 |
| 충돌 | 내용이 다른데 대상 쪽이 더 최근에 고쳐짐 | 건너뛰고 알림(누가 대상에서 직접 고쳤을 수 있음) |
| 같음 | 같은 내용 | 그대로 |
| 대상에만있음 | 원본엔 없음 | **알리기만 하고 지우지 않음** |

## 어떤 업무에 쓰나요?
- 내 작업 폴더 → 팀 공유 폴더·NAS·USB로 바뀐 것만 올릴 때
- 매일 퇴근 전 자료 백업(전체 복사보다 빠르고, 무엇이 바뀌었는지 남음)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
# 1) 미리보기(기본): 무엇이 복사될지만 보여 줌
python3 main.py sample/src sample/dst

# 2) 실제 복사
python3 main.py 내작업폴더 Z:/공유/팀자료 --apply

# 파일이 아주 많으면 크기+수정시각만 비교(빠름)
python3 main.py 내작업폴더 Z:/공유/팀자료 --quick --apply
```

## 입력 / 출력 예시
- 입력: 원본 폴더, 대상 폴더
- 출력: 화면 요약 + `output/mirror_report.csv`(상태, 상대경로, 크기)

샘플 결과: `report.txt` 바뀜, `sub/data.csv`·`sub/minutes.txt` 새파일, `same.txt` 같음, `old_only.txt` 대상에만있음, `work.tmp`는 제외 패턴이라 무시.

## 주의사항
- 기본은 **미리보기**입니다. `--apply`를 붙여야 복사합니다. 샘플로 해 볼 때는 sample 폴더를 복사해서 쓰세요.
- 삭제는 절대 하지 않습니다. 원본에서 지운 파일은 대상에 그대로 남습니다.
- 기본 제외 패턴: `~$*`(열려 있는 오피스 임시파일), `*.tmp`, `Thumbs.db`, `.DS_Store`. `--exclude`로 바꿀 수 있습니다.
- 샘플 파일 내용은 가짜입니다.
