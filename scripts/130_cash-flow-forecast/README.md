# 130 자금 수지 예측(일별 예상 잔액)

## 무엇을 하나요?
오늘 잔액과 **입금·출금 예정표**를 넣으면 앞으로 N일 동안 날짜별 예상 잔액을 계산하고, 최소 유지 잔액 아래로 내려가는 날을 미리 알려 줍니다.
- **예상잔액**: 모든 입금·출금 반영
- **보수적잔액**: '확정' 입금만 + 모든 출금 반영 → "예상 입금이 안 들어와도 버틸 수 있나?"
- 경고: `부족`(예상잔액도 모자람), `주의`(예상 입금이 안 오면 모자람)

## 어떤 업무에 쓰나요?
- 재무·자금팀의 주간 자금 수지 점검, 급여일·세금 납부일 전 잔액 확인
- 작은 회사·개인사업자의 통장 잔고 계획

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/cash_plan.csv --start-balance "30,000,000" --start 2026-11-01 --days 30 --min "5,000,000" -o output/cash_forecast.csv
```

## 입력 / 출력 예시
- 입력 CSV 열: `예정일, 구분(입금/출금), 거래처, 금액, 확정여부(확정/예상)` — 확정여부가 비면 확정으로 봅니다.
- 출력 CSV 열: `일자, 요일, 입금합, 출금합, 예상잔액, 보수적잔액, 경고, 내역` (기간의 모든 날짜)

샘플 결과(시작 3,000만 원, 최소 500만 원):
```
2026-11-10(화) 입금 0 출금 10,700,000 → 잔액 14,300,000 / 보수적 6,300,000
2026-11-15(일) 입금 0 출금  3,100,000 → 잔액 20,200,000 / 보수적 3,200,000 주의(예상입금 안 오면 부족)
가장 낮은 잔액: 14,300,000원(2026-11-10), 보수적으로는 3,200,000원(2026-11-15)
경고 일수: 부족 0일, 주의 5일
```

## 주의사항
- 주말·휴일에 잡힌 예정은 그날 그대로 계산하고 알림만 줍니다. 실제 이체일로 옮기려면 113 휴일 날짜 조정 스크립트를 먼저 쓰세요.
- 시작일 '아침' 잔액 기준입니다. 시작일 당일 예정도 계산에 들어갑니다.
- 샘플 거래처·금액은 가짜입니다.
