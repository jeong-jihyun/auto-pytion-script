# 131 CSV 빈칸을 위 값으로 채우기(병합셀 풀기)

## 무엇을 하나요?
엑셀에서 '부서' 칸을 여러 줄 병합해 둔 표를 CSV로 저장하면 첫 줄에만 값이 남고 나머지는 빈칸이 됩니다.
이 스크립트는 지정한 열의 빈칸을 **바로 위 줄의 값**으로 채워 집계·필터가 되는 표로 바꿉니다.
- 열 순서를 **상위→하위**로 적으면, 상위 값(부서)이 바뀔 때 하위 값(팀)을 이전 부서에서 끌어오지 않습니다.

## 어떤 업무에 쓰나요?
- 병합셀이 많은 엑셀 보고서를 피벗·SQL로 다시 집계할 때
- ERP 화면에서 내려받은 '그룹 머리글만 있는' 목록 정리

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/merged_export.csv --cols 부서,팀 -o output/filled.csv
python3 main.py sample/merged_export.csv --cols 부서,팀 --drop-empty
```

## 입력 / 출력 예시
입력(일부):
```
개발본부,,최지우,70000      ← 팀이 비어 있음(영업2팀을 끌어오면 안 됨)
,플랫폼팀,정하늘,90000
```
출력:
```
개발본부,,최지우,70000      ← 부서가 바뀌었으므로 팀은 빈칸 그대로
개발본부,플랫폼팀,정하늘,90000
개발본부,플랫폼팀,한바다,40000
```
화면: `부서: 5칸 채움`, `팀: 3칸 채움`

## 주의사항
- 원본은 바뀌지 않고 새 파일로 저장합니다.
- 원래부터 비어 있어야 하는 칸이 있는 열은 --cols 에 넣지 마세요.
- 샘플 이름·금액은 가짜입니다.
