# 133 두 텍스트 파일 비교 보고서(HTML)

## 무엇을 하나요?
이전 파일과 새 파일(SQL, 설정, 배치 스크립트, 문서 등)의 **바뀐 줄**을 찾아
- 화면에 `추가 N줄, 삭제 N줄, 변경 N줄` 요약을 보여 주고
- 좌우 나란히 색칠된 **HTML 보고서**를 만듭니다(브라우저로 열기, 결재·메일 첨부용).

## 어떤 업무에 쓰나요?
- 운영 반영 전 '무엇이 바뀌었나' 검토(변경관리 요청서 첨부)
- git이 없는 서버에서 내려받은 설정 파일 비교

## 설치
파이썬 3.8 이상. 설치할 것 없음(기본 모듈 difflib 사용).

## 실행 예시
```
python3 main.py sample/batch_v1.sql sample/batch_v2.sql -o output/diff_report.html
python3 main.py sample/batch_v1.sql sample/batch_v2.sql --ignore-space --show
```
- `--ignore-space`: 띄어쓰기 개수만 다른 줄은 같은 줄로 봅니다
- `--show`: 화면에 `-`/`+` 형식(unified diff)도 출력
- `--context 5`: 바뀐 곳 앞뒤 5줄까지 보여 줌

## 출력 예시
```
추가 1줄, 삭제 0줄, 변경 3줄 (이전 8줄 → 새 9줄)
--ignore-space 를 주면 → 추가 1줄, 삭제 0줄, 변경 2줄
```
HTML 색: 초록=추가, 노랑=변경, 빨강=삭제

## 주의사항
- 줄 단위 비교입니다. 엑셀·워드 같은 바이너리 파일은 084(엑셀 셀 비교)나 023(워드 글자 추출) 뒤에 쓰세요.
- utf-8로 못 읽으면 cp949로 다시 읽습니다.
- `--ignore-space` 를 주면 HTML에도 공백을 정리한 줄이 표시됩니다.
