# 134 증권 잔고 롤포워드 검증

## 무엇을 하나요?
계좌·종목별로 **전일 잔고 + 매수 − 매도 + 입고 − 출고 = 당일 잔고** 가 맞는지 확인합니다.
세 파일(전일 잔고, 당일 변동, 당일 잔고)을 계좌번호+종목코드로 맞춰 보고, 어긋난 줄만 CSV로 뽑습니다.

상태: `일치`, `수량차이`, `당일잔고없음`(있어야 할 잔고 줄이 없음), `마이너스`(기대 잔고가 음수 → 체결 누락·공매도 의심)

## 어떤 업무에 쓰나요?
- 증권·자산운용 일 마감 잔고 검증, 예탁 기관 잔고와 대조하기 전 자체 점검
- 시스템 이관 후 잔고 정합성 확인(127 주문-체결 대사 다음 단계)

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --prev sample/prev_position.csv --moves sample/moves.csv --today sample/today_position.csv -o output/position_check.csv
python3 main.py --prev ... --moves ... --today ... --all     # 일치한 줄도 포함
```

## 입력 / 출력 예시
- 잔고 CSV: `계좌번호,종목코드,수량`
- 변동 CSV: `계좌번호,종목코드,구분,수량` (구분: 매수/매도/입고/출고)

출력(`--all`):
```
계좌번호,종목코드,전일,매수,매도,입고,출고,기대잔고,당일잔고,차이(당일-기대),상태
1001-01,000660,50,0,50,0,0,0,,0,일치               ← 전량 매도라 당일 줄이 없어도 정상
1001-01,005930,100,20,10,0,0,110,105,-5,수량차이
1002-01,035420,30,0,40,0,0,-10,0,10,마이너스
1002-01,051910,0,5,0,0,0,5,,-5,당일잔고없음
1003-01,KR5101,"1,234.5678",0,0,100.0001,0,"1,334.5679","1,334.5679",0,일치   ← 펀드 좌수 소수도 정확히
```
화면: `계좌·종목 5쌍 점검: 당일잔고없음 1, 마이너스 1, 수량차이 1, 일치 2`

## 주의사항
- 결제일 기준 잔고와 체결일 기준 잔고를 섞으면 차이가 납니다. 같은 기준 파일끼리 비교하세요.
- 권리(배당주·무상증자) 입고는 '입고'로 넣어 주세요.
- 샘플 계좌·수량은 가짜입니다.
