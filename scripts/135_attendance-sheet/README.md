# 135 출석부(서명부) 엑셀 만들기

## 무엇을 하나요?
참석자 명단 CSV로 **바로 인쇄할 수 있는 출석부 엑셀**을 만듭니다.
- 위쪽: 행사명, 일시, 장소 / 표: 번호 + 명단 열 + 서명 칸(여러 개 가능)
- 아래: 총원·참석·불참(참석 = 첫 서명 칸에 무언가 적힌 사람 수, 엑셀 수식)
- A4 세로·가로 1쪽 맞춤·머리글 줄 반복 인쇄 설정
- `--group 부서` 를 주면 부서별로 시트를 나눕니다.

## 어떤 업무에 쓰나요?
- 법정 의무교육(정보보호·성희롱 예방 등) 출석 증빙
- 회의·워크숍 참석 서명부

## 설치
```
pip install -r requirements.txt     # openpyxl
```

## 실행 예시
```
python3 main.py sample/roster.csv --title "정보보호 교육 출석부" --when "2026-11-05 14:00" --where "본사 3층 대회의실" --cols 이름,부서,직급 --sign-cols 오전서명,오후서명 --sort 이름 -o output/attendance.xlsx
python3 main.py sample/roster.csv --cols 이름,직급 --group 부서 -o output/attendance_by_dept.xlsx
```

## 입력 / 출력 예시
입력: `이름,부서,직급,연락처` (연락처는 `--cols` 에서 빼서 출석부에 안 나오게 함)

출력 시트:
```
정보보호 교육 출석부
일시: 2026-11-05 14:00    장소: 본사 3층 대회의실
번호 | 이름 | 부서 | 직급 | 오전서명 | 오후서명
1    | 김철수 | 개발팀 | 대리 |        |
...
총원 5 / 참석 =COUNTA(E5:E9) / 불참 =B11-B12
```

## 주의사항
- 종이에 서명받은 뒤 엑셀 서명 칸에 O 를 적으면 참석 수가 자동으로 계산됩니다.
- 출석부에 꼭 필요한 열만 `--cols` 로 고르세요(개인정보 최소화).
- 샘플 이름·연락처는 가짜입니다.
