# 136 포트폴리오 VaR·기대손실(역사적 시뮬레이션)

## 무엇을 하나요?
보유 종목의 평가금액과 과거 종가로 **VaR**(평소라면 N% 확률로 하루 손실이 넘지 않는 금액)와 **ES**(그보다 나쁜 날들의 평균 손실)를 계산합니다.
방식: 과거 하루하루의 수익률을 지금 보유 금액에 그대로 적용해 '그날 같았으면 손익'을 만들고, 나쁜 순서로 정렬해 경계 값을 읽습니다(역사적 시뮬레이션).
- 경계 시나리오 날의 **종목별 손익(기여도)** 도 보여 줘서 어느 종목 때문에 위험한지 알 수 있습니다.

## 어떤 업무에 쓰나요?
- 리스크관리팀 일일 VaR 점검·한도 비교의 간단한 검산
- 개인·소규모 펀드의 '하루에 얼마까지 잃을 수 있나' 감 잡기

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --prices sample/prices.csv --positions sample/positions.csv -o output/var_scenarios.csv
python3 main.py --prices sample/prices.csv --positions sample/positions.csv --conf 0.95 --horizon 10
```

## 입력 / 출력 예시
- 종가 CSV: `일자,AAA,BBB,CCC` (날짜 오름차순, 열 이름 = 종목)
- 보유 CSV: `종목,평가금액`

화면(샘플, 99%·1일):
```
보유 총액 100,000,000원, 시나리오 100일
  VaR : 3,235,723원 (총액의 3.24%)  ← 경계 시나리오 2026-09-24, 아래에서 1번째
  ES  : 3,235,723원 (경계일 포함 가장 나빴던 1일 평균)
```
출력 CSV: 손익이 나쁜 순서로 `순위,일자,포트폴리오손익,종목별 손익`

## 주의사항
- 경계 위치는 `올림(표본 수 × (1-신뢰수준))` 번째로 정합니다. 기관마다 보간 방식이 달라 조금씩 다를 수 있습니다.
- `--horizon` 이 1보다 크면 √N 을 곱하는 근사입니다(실제 다일 수익률과 다를 수 있음).
- 표본이 적으면(기본 60일 미만) 경고합니다. 보통 250일 이상을 씁니다.
- 샘플 종가는 고정 씨앗으로 만든 가짜 무작위 값이고, 계산 결과는 투자 권유가 아닙니다.
