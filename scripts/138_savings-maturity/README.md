# 138 예금·적금 만기 이자·실수령액 계산

## 무엇을 하나요?
정기예금(한 번에 맡김)과 적금(매달 넣음)의 **세전 이자 → 세금 → 세후 이자 → 만기 수령액**을 계산하고,
여러 상품을 CSV로 넣으면 **세후 이자가 큰 순서로 비교표**를 만듭니다.

계산식(연이율 r, 개월 n, 월이율 m = r/12)
| 종류 | 단리 | 월복리 |
|---|---|---|
| 예금 | 원금 × r × n/12 | 원금 × ((1+m)^n − 1) |
| 적금 | 월납입 × m × n(n+1)/2 | Σ 월납입 × ((1+m)^k − 1), k=1..n |

적금은 첫 달 돈만 n개월 이자를 받고 마지막 달 돈은 1개월만 받기 때문에, 같은 연이율이라도 예금보다 이자가 훨씬 적습니다.

## 어떤 업무에 쓰나요?
- 회사 여유자금·개인 저축 상품 비교, 직원 복지 적금 안내문 숫자 검산

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py --csv sample/products.csv -o output/savings_compare.csv
python3 main.py --kind 적금 --method 단리 --amount 500,000 --rate 4.0 --months 12
python3 main.py --kind 예금 --method 월복리 --amount 10000000 --rate 3.1 --months 12 --tax 비과세
```
과세(`--tax` 또는 CSV `과세` 열): `일반`(15.4%), `세금우대`(9.5%), `비과세`(0%), 또는 숫자(예: `1.4` → 1.4%)

## 출력 예시
```
가은행 정기예금: 예금 단리 3.2% 12개월 / 원금 10,000,000원 → 세전 320,000 − 세금 49,280 = 세후 270,720원, 만기 10,270,720원
다은행 자유적금: 적금 단리 4.0% 12개월 / 원금 6,000,000원 → 세전 130,000 − 세금 20,020 = 세후 109,980원, 만기 6,109,980원
```
CSV 열: `상품,종류,방식,납입(원금),연이율(%),개월,과세,세전이자,세금,세후이자,만기수령액,세후연수익률(%)`

## 주의사항
- 이자는 원 미만, 세금은 10원 미만을 버립니다. 은행마다 끝자리 처리·일할 계산이 달라 몇 원 차이 날 수 있습니다.
- 세율·비과세 제도는 바뀔 수 있습니다. 실제 가입 전 은행 안내를 확인하세요.
- 중도해지 이율, 우대금리 조건은 반영하지 않습니다.
- 샘플 상품·금리는 가짜이며 투자·가입 권유가 아닙니다.
