# 139 일정 CSV로 간트 차트(HTML) 만들기

## 무엇을 하나요?
작업·담당·시작일·종료일·진척률을 적은 CSV로 **브라우저에서 바로 보는 간트 차트 HTML 한 장**을 만듭니다.
- 진척률만큼 막대 앞부분을 진하게 칠합니다.
- 기준일(`--today`)에 빨간 세로선, 기준일이 지났는데 100% 미만인 작업은 **지연**(빨간 막대)으로 표시합니다.
- 주말 칸은 회색. 기간이 길면 `--unit week` 로 주 단위 칸.
- 인터넷·외부 라이브러리 없이 열리는 HTML이라 메일 첨부·사내망에서도 그대로 보입니다.

## 어떤 업무에 쓰나요?
- SI·ERP 프로젝트 주간 보고 일정표, 팀 업무 진행 현황 공유

## 설치
파이썬 3.8 이상. 설치할 것 없음.

## 실행 예시
```
python3 main.py sample/tasks.csv --today 2026-10-28 -o output/gantt.html
python3 main.py sample/tasks.csv --title "차세대 1단계 일정" --unit week -o output/gantt_week.html
```

## 입력 / 출력 예시
입력 CSV: `작업,담당,시작일,종료일,진척률` (날짜는 YYYY-MM-DD, 진척률은 0~100, `%` 붙여도 됨)
```
배치 개발,최개발,2026-10-20,2026-10-27,70
```
화면: `작업 5개, 기간 2026-10-19~2026-11-13, 칸 26개(day), 기준일 2026-10-28 지연 1개`
HTML: 표 왼쪽에 작업·담당·진척·상태(완료/진행/지연), 오른쪽에 날짜별 막대

## 주의사항
- 종료일이 시작일보다 빠른 줄이 있으면 몇 번째 줄인지 알려 주고 멈춥니다.
- 주 단위 보기에서는 기준일 선이 그 주 칸의 왼쪽에 그려집니다.
- 휴일은 표시하지 않고 주말만 회색으로 칠합니다.
- 샘플 작업·담당자는 가짜입니다.
