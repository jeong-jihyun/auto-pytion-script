# 141 전표 기간 귀속(컷오프) 점검

## 무엇을 하나요?
전표 CSV를 읽어 **거래한 달과 장부에 올린 달이 다른 전표**, **마감 뒤에 지난달로 입력된 전표**, **주말 전기**, **오래 소급한 전기**를 찾아 줍니다.

## 어떤 업무에 쓰나요?
- 월말·분기말 결산 마감 전 점검 (ERP에서 내려받은 전표 목록)
- 감사 대응: "마감 뒤에 들어온 전표가 있나요?" 질문에 바로 답하기

## 설치
파이썬 3.8 이상만 있으면 됩니다. 추가 설치는 없습니다.

## 실행 예시
```bash
python main.py sample/journal.csv --close-date 2026-10-05
python main.py 전표.csv --close-date 2026-10-05 --backdate-days 15 -o 결과.csv
```
- `--close-date` : 마감일. 이 날 **다음 날부터** 입력된 전표가 지난달(마감된 달)에 전기되어 있으면 `AFTER_CLOSE`로 표시합니다.
- `--no-weekend` : 주말 전기 점검을 끕니다.
- 열 이름이 다르면 `--col-id`, `--col-txn`, `--col-post`, `--col-entry`, `--col-amount`로 바꿉니다.

## 입력 예시 (sample/journal.csv)
| 전표번호 | 거래일 | 전기일 | 입력일 | 계정 | 차변 | 대변 |
|---|---|---|---|---|---|---|
| JV-0902 | 2026-09-30 | 2026-10-02 | 2026-10-02 | 외주용역비 | 3300000 | 0 |

## 출력 예시
```
전표 7건 점검, 의심 7줄 → cutoff_issues.out.csv
  MONTH_DIFF      2건  금액 3,510,000
  AFTER_CLOSE     2건  금액 660,000
  WEEKEND         1건  금액 80,000
  BACKDATED       1건  금액 210,000
  DATE_ERROR      1건 (날짜 형식 확인 필요)
```
결과 CSV에는 전표번호, 날짜, 차변합계, 사유코드, 설명이 들어갑니다. 한 전표가 여러 사유에 걸리면 여러 줄이 나옵니다.

## 주의사항
- 같은 전표번호의 여러 줄은 한 건으로 보고 차변을 합칩니다. 날짜는 첫 줄 기준입니다.
- 선급·미지급처럼 **일부러** 달을 다르게 처리한 전표도 걸릴 수 있습니다. 목록은 '확인할 대상'이지 '틀린 전표'가 아닙니다.
- 공휴일은 따로 보지 않습니다(주말만).
