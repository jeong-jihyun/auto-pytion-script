# 142 휴면 계좌 후보 추출

## 무엇을 하나요?
계좌 목록과 거래 내역을 맞춰 계좌별 **마지막 거래일**을 구하고, 오래 거래가 없는 계좌를 **휴면 대상**과 **사전 안내 대상**으로 나눠 줍니다.

## 어떤 업무에 쓰나요?
- 은행·증권사의 휴면 계좌 정기 분류, 휴면 전 고객 안내 대상 뽑기
- 포인트·회원 계정처럼 '일정 기간 미사용' 기준이 있는 업무 전반

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/accounts.csv sample/transactions.csv --as-of 2026-10-29
python main.py 계좌.csv 거래.csv --dormant-days 1825 --notice-days 60 --min-balance 10000
```
- `--dormant-days` : 무거래 며칠부터 휴면인지 (기본 365일, 5년이면 1825)
- `--notice-days` : 휴면까지 며칠 남았을 때부터 안내 대상인지 (기본 30일)
- `--min-balance` : 이보다 잔액이 적으면 `소액=Y` 표시

## 입력
- 계좌 CSV: `계좌번호, 고객명, 개설일, 잔액, 상태` (상태가 `해지`면 제외)
- 거래 CSV: `계좌번호, 거래일` (다른 열은 있어도 됩니다)

## 출력 예시
```
기준일 2026-10-29 / 휴면 기준 365일 / 사전안내 30일 전
  휴면 대상 3건, 사전 안내 1건, 정상 1건, 해지 제외 1건
```
| 계좌번호 | 마지막거래일 | 기준 | 무거래일수 | 휴면예정일 | 구분 | 잔액 | 소액 |
|---|---|---|---|---|---|---|---|
| 100-03 | 2024-11-20 | 개설일 | 708 | 2025-11-20 | DORMANT | 0 | Y |
| 100-04 | 2025-11-15 | 거래 | 348 | 2026-11-15 | NOTICE | 880000 | |

## 주의사항
- 거래가 한 번도 없으면 **개설일**을 마지막 거래일로 봅니다(`기준=개설일`).
- 기준일보다 뒤 날짜의 거래는 계산에서 뺍니다.
- 실제 휴면 기준(어떤 거래를 '거래'로 볼지, 이자 입금 포함 여부 등)은 회사 규정을 따르세요. 필요한 거래만 걸러서 넣으면 됩니다.
- 샘플의 이름·계좌번호는 모두 가짜입니다.
