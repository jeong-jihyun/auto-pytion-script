# 143 호가 스프레드·불균형 계산

## 무엇을 하나요?
호가(오더북) 스냅샷 CSV를 읽어 줄마다 **스프레드(원·bp)**, **중간가**, **가중 중간가**, **호가 잔량 불균형**을 계산하고, 종목별로 요약합니다. 역전 호가·빈 호가 같은 데이터 이상도 세어 줍니다.

## 어떤 업무에 쓰나요?
- 시세 수신 데이터 품질 점검 (역전 호가, 빈 호가 탐지)
- 유동성이 나쁜(스프레드가 넓은) 종목·시간대 찾기
- 매수·매도 잔량 쏠림 확인

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/orderbook.csv
python main.py 호가.csv --levels 5 --wide-bp 30 -o 결과.csv
```
- `--levels` : 불균형 계산에 몇 단계 호가까지 쓸지 (0 = 있는 만큼 전부)
- `--wide-bp` : 스프레드가 이 bp 이상이면 `WIDE` 표시 (기본 20bp)

## 입력 형식
`time, symbol, bid1, bid1_qty, ask1, ask1_qty, bid2, bid2_qty, ask2, ask2_qty, ...`
단계 수는 열 이름(bid1, bid2…)을 보고 자동으로 찾습니다.

## 계산식
- 스프레드 = 매도1 − 매수1, bp = 스프레드 ÷ 중간가 × 10,000
- 가중 중간가 = (매수1 × 매도1잔량 + 매도1 × 매수1잔량) ÷ (두 잔량 합)
- 불균형 = (매수잔량합 − 매도잔량합) ÷ (두 합의 합). **+면 매수 우위, −면 매도 우위**

## 출력 예시
```
스냅샷 6줄 중 4줄 계산 (호가 단계 3개 사용)
종목         건수     평균bp     최대bp      평균불균형  WIDE
AAA001      2    14.28    14.28     +0.153     0
BBB002      2    65.68    98.52     -0.790     2
[데이터 이상] CROSSED: 1줄
[데이터 이상] EMPTY: 1줄
```

## 주의사항
- 샘플 종목코드·가격은 가짜입니다.
- 투자 판단용 도구가 아니라 데이터 점검·분석 보조용입니다.
- 이상 줄(역전·빈 호가)은 결과 CSV에서 빠지고 개수만 알려 줍니다.
