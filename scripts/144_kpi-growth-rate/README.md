# 144 전월·전년 동월 대비 증감률

## 무엇을 하나요?
월별 실적 CSV(월, 항목, 값)를 읽어 항목마다 **전월 대비(MoM)**, **전년 동월 대비(YoY)**, **연간 누적(YTD)과 누적 YoY**를 계산합니다. 특정 달을 고르면 증감률 순위 요약도 보여 줍니다.

## 어떤 업무에 쓰나요?
- 월간 실적 보고서(지점별 매출, 제품별 판매량, 서비스별 거래 건수)
- 엑셀 수식 끌어쓰기 없이 매달 같은 계산을 빠르게 반복할 때

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/monthly.csv --month 2026-09
python main.py 실적.csv --col-month 기준월 --col-item 지점 --col-value 매출 -o 증감.csv
```

## 입력 예시
| 월 | 항목 | 값 |
|---|---|---|
| 2026-09 | 서울지점 | 9000000 |
| 2025-09 | 서울지점 | 8780000 |

월은 `2026-09`, `2026/09`, `2026.09`, `2026-09-01` 모두 됩니다. 같은 달·항목이 여러 줄이면 합칩니다.

## 출력 예시
```
[2026-09 요약] YoY 높은 순
항목                    값      MoM      YoY            YTD  YTD YoY
부산지점          7,230,000    26.8%    20.7%     50,330,000     7.8%
서울지점          9,000,000    -0.2%     2.5%     93,080,000     3.5%
```
결과 CSV: `월, 항목, 값, 전월, MoM, 전년동월, YoY, YTD, YTD_YoY`

## 주의사항
- 비교할 달이 없거나 값이 0이면 증감률은 **빈칸**입니다(0으로 나누지 않음).
- 자료가 빠진 달(샘플의 부산지점 2026-03)은 건너뛰어 비교하지 않습니다. 그래서 4월의 MoM은 빈칸입니다.
- YTD YoY는 **올해와 작년 모두 자료가 있는 달끼리만** 더해서 비교합니다. 그래서 YTD 금액 열과 비교 기준이 조금 다를 수 있습니다.
- 샘플 숫자는 무작위로 만든 가짜 값입니다.
