# 145 폴더 구조 일괄 생성

## 무엇을 하나요?
들여쓰기 텍스트나 CSV로 적은 목록대로 **폴더 구조를 한 번에** 만듭니다. `{year}` 같은 자리표시와 `{month:01-12}` 같은 범위 펼치기를 지원합니다. 기본은 **미리보기**이고, 아무것도 지우지 않습니다.

## 어떤 업무에 쓰나요?
- 새 연도·분기 시작 때 팀 공용 드라이브 폴더 만들기
- 새 프로젝트마다 같은 폴더 틀(제안서/계약서/산출물…) 깔기
- 사람마다 폴더 이름이 달라지는 것 막기

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
# 1) 미리보기
python main.py sample/structure.txt --root D:/공용 --var year=2027
# 2) 실제 생성
python main.py sample/structure.txt --root D:/공용 --var year=2027 --apply
# CSV 목록으로
python main.py sample/structure.csv --root D:/공용 --apply
```

## 입력 예시
들여쓰기 텍스트(공백 2칸 또는 탭 = 한 단계):
```
{year}_재무팀
  결산
    {month:01-12}월
  세무신고
    부가세
```
CSV(첫 줄은 머리글, 빈 칸에서 멈춤):
```
부서,구분,세부
영업1팀,계약서,진행중
영업2팀,제안서,
```

## 출력 예시
```
[예정] D:/공용/2027_재무팀
[예정] D:/공용/2027_재무팀/결산/01월
...
전체 21개 중 새로 21개, 이미 있음 0개 — 미리보기 (실제로 만들려면 --apply)
```

## 주의사항
- `\ / : * ? " < > |` 가 들어간 이름이나 `..` 은 거부합니다(엉뚱한 위치에 만들지 않도록).
- 이미 있는 폴더는 건드리지 않습니다. 삭제 기능은 없습니다.
- 자리표시 값을 빼먹으면 멈추고 어떤 `--var`가 필요한지 알려 줍니다.
