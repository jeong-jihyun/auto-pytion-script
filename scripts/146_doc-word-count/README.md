# 146 문서 글자 수·원고지 매수 집계

## 무엇을 하나요?
폴더 안의 **txt, md, docx** 파일을 한 번에 읽어 공백 포함/제외 글자 수, 단어 수, 문단 수, 한글 비율, **200자 원고지 매수(추정)**를 표로 만들어 줍니다. 분량 상한을 주면 넘는 파일에 `OVER`를 붙입니다.

## 어떤 업무에 쓰나요?
- 제안서·보고서·자기소개서의 분량 제한 확인
- 여러 사람이 낸 원고의 분량 비교, 번역·교정 분량 산정

## 설치
파이썬 3.8 이상. 추가 설치 없음(docx도 표준 라이브러리로 읽습니다).

## 실행 예시
```bash
python main.py sample --limit 150
python main.py D:/원고 --recursive -o 분량.csv
```

## 출력 예시
```
파일                           공백포함     공백제외     단어   문단    원고지 판정
notes.md                       42       31     14    3    0.4
자기소개.txt                      165      123     45    3    1.0 OVER
제안요약.docx                      57       44     16    3    0.4
```

## 계산 기준
- 공백 포함 글자 수: 줄바꿈은 빼고, 띄어쓰기·탭은 셉니다.
- 원고지 매수: 문단마다 새 줄에서 시작하고 첫 칸을 한 칸 비운다고 보고 20칸 × 10줄로 나눈 **추정치**입니다. 문장부호 위치 규칙까지는 반영하지 않습니다.
- txt는 UTF-8을 먼저, 안 되면 CP949(윈도우 한글)로 읽습니다.

## 주의사항
- docx의 머리글·바닥글·각주·텍스트 상자는 세지 않고 본문만 셉니다. 워드의 '단어 개수' 창과 몇 자 차이 날 수 있습니다.
- `sample/제안요약.docx`는 테스트용 최소 구조 파일이라 워드에서 열리지 않을 수 있습니다. 스크립트 확인용입니다.
- hwp, pdf는 지원하지 않습니다(PDF 글자 추출은 012 스크립트를 쓰세요).
