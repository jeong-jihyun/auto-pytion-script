# 147 재무비율 계산

## 무엇을 하나요?
재무제표 요약 CSV(행=계정, 열=연도)를 읽어 **안정성·수익성·활동성·성장성** 주요 비율 15가지를 기간별로 계산합니다.

## 어떤 업무에 쓰나요?
- 거래처 신용 검토, 협력사 재무 상태 점검
- 사업계획·투자 검토 보고서의 재무 지표 표 만들기

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/financials.csv
python main.py 재무제표.csv -o 비율.csv
```

## 입력 예시 (단위는 자유, 모든 칸이 같은 단위여야 함)
```
계정,2024,2025
유동자산,"5,200","6,100"
자본총계,"5,600","6,700"
매출액,"15,000","17,200"
```
- 쉼표 있는 숫자, 괄호 음수 `(1,000)` 를 읽습니다.
- 계정 이름은 비슷한 말도 찾습니다(예: `자본`, `총자본` → 자본총계, `매출`/`영업수익` → 매출액).

## 출력 예시
```
구분     비율                          2024        2025
안정성    유동비율(%)                   152.94      169.44
안정성    부채비율(%)                   123.21      105.97
수익성    ROE(%)                     16.07       19.19
활동성    매출채권회전일수(일)                43.80       40.85
성장성    매출액증가율(%)                      -       14.67
```

## 계산 기준
- 당좌비율 = (유동자산 − 재고자산) ÷ 유동부채
- ROA·ROE·총자산회전율·회전일수는 **앞 기간이 있으면 평균 잔액**, 첫 기간은 기말 잔액으로 계산합니다.
- 회전일수는 365일 기준입니다.

## 주의사항
- 필요한 계정이 없거나 분모가 0이면 `-` 로 나오고, 찾지 못한 계정을 처음에 알려 줍니다.
- 샘플 숫자는 가짜입니다. 비율 해석(업종 평균 비교 등)은 사람이 판단해야 합니다.
