# 148 큐 적체 추세·소진 예상

## 무엇을 하나요?
배치·메시지 큐의 **대기 건수 기록**(시각, 큐이름, 대기건수)을 읽어, 큐마다 최근 추세(분당 증감)를 직선으로 맞추고 **언제 다 처리될지** 또는 **언제 한도에 닿을지**를 추정합니다.

## 어떤 업무에 쓰나요?
- 야간 배치·정산 큐 모니터링: "이 속도면 개장 전에 끝나나?"
- 메시지 큐(MQ) 적체 경보 기준 잡기, 장애 보고서의 근거 수치

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/queue_depth.csv --limit 10000
python main.py depth.csv --window 24 --flat 0.5 -o 추세.csv
```
- `--window` : 최근 몇 개 기록으로 추세를 볼지 (기본 12개)
- `--limit` : 큐 한도. 주면 도달 예상 시각을 계산합니다
- `--flat` : 분당 변화가 이보다 작으면 '정체' (기본 1건/분)

## 입력 예시
```
time,queue,depth
2026-10-29 09:00,order-settle,2410
2026-10-29 09:05,order-settle,2238
```

## 출력 예시
```
큐                  마지막값       분당    R² 상태     예상시각             설명
fee-calc           1340    +12.1  0.99 증가     2026-10-29 22:05 약 716분 뒤 한도 도달
notice-mail         121     +0.0  0.03 정체
order-settle        294    -30.2  1.00 감소     2026-10-29 10:19 약 10분 뒤 소진
report-gen        10400    +60.0  1.00 OVER                    이미 한도 10000 이상
```

## 주의사항
- 예상 시각은 '지금 속도가 그대로 간다면'이라는 가정의 단순 직선 추정입니다.
- R²(직선이 맞는 정도)가 0.5보다 낮으면 설명에 `참고용`이 붙습니다.
- 기록이 3개 미만인 큐는 `자료부족`으로 표시합니다.
- 샘플 숫자는 무작위로 만든 가짜 값입니다.
