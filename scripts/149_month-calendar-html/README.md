# 149 일정 CSV로 월간 달력 HTML

## 무엇을 하나요?
일정 목록 CSV를 읽어 **월간 달력 모양의 HTML 한 장**을 만듭니다. 여러 날 일정(휴가 등)은 기간 내 모든 날에 표시하고, `구분`마다 색을 자동으로 정해 범례를 붙입니다. 공휴일 파일을 주면 빨간 글씨로 표시합니다.

## 어떤 업무에 쓰나요?
- 팀 휴가·마감·배포·점검 일정을 한눈에 보기
- 회의실 벽·공유 폴더에 붙일 월간 일정표 (브라우저에서 가로 인쇄)

## 설치
파이썬 3.8 이상. 추가 설치 없음. 결과 HTML도 외부 파일 없이 혼자 열립니다.

## 실행 예시
```bash
python main.py sample/schedule.csv --month 2026-11 --holidays sample/holidays.csv
python main.py 팀일정.csv --month 2026-12 --monday --title "IT운영팀 12월" -o 12월.html
```
- `--monday` : 월요일부터 시작 (기본 일요일 시작)
- `--holidays` : `날짜,이름` 형식 CSV (머리글 없이)

## 입력 예시
| 제목 | 시작일 | 종료일 | 구분 |
|---|---|---|---|
| 김대리 휴가 | 2026-11-09 | 2026-11-11 | 휴가 |
| 정기 배포 v2.3 | 2026-11-12 | | 배포 |

종료일이 비면 하루 일정입니다. 구분이 비면 `기타`입니다.

## 출력 예시
```
2026-11 달력: 이 달에 걸친 일정 7건, 구분 5종 → calendar.out.html
[경고] 날짜를 읽지 못했거나 종료일이 시작일보다 빠른 일정 1건은 뺐습니다
```
브라우저로 열면 날짜 칸마다 색깔 띠로 일정이 보입니다. 지난달·다음달 날짜는 회색입니다.

## 주의사항
- 한 칸에 일정이 많으면 칸이 길어집니다. 제목이 길면 말줄임(…)으로 잘립니다.
- 공휴일은 직접 파일로 넣어야 합니다(샘플의 공휴일은 가상의 날입니다).
- 샘플 이름은 모두 가짜입니다.
