# 150 정규식 규칙으로 텍스트 → CSV 추출

## 무엇을 하나요?
입금 알림 문자, 배치 결과 통보 메일, 일정한 모양의 로그처럼 **틀이 정해진 글**에서 원하는 값(날짜·금액·상대방·작업명 등)을 뽑아 **CSV 표**로 만듭니다. 규칙은 JSON 파일에 정규식으로 적고, 어떤 규칙에도 안 맞은 글은 따로 모아 줍니다.

## 어떤 업무에 쓰나요?
- 입출금 알림 문자 → 입출금 대장
- 배치 결과 메일 본문 → 일일 배치 결과표
- 주문 접수·발주 확인 메일 → 주문 목록

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
# 줄 단위 (한 줄 = 한 건)
python main.py sample/rules_sms.json sample/sms.txt --clean-number 금액,잔액
# 블록 단위 (---- 줄로 나뉜 덩어리 = 한 건). 구분자는 반드시 = 로 붙여 씁니다
python main.py sample/rules_mail.json sample/batch_mails.txt --block-sep=---- --clean-number 처리건수
# 빈 줄로 나뉜 블록이면 값 없이
python main.py rules.json mails.txt --block-sep
```

## 규칙 파일 쓰는 법
```json
[
  {"name": "입금", "pattern": "\\[입금\\] (?P<날짜>\\d{2}/\\d{2}) (?P<금액>[\\d,]+)원 (?P<상대>\\S+)"}
]
```
- `(?P<열이름>...)` 부분이 CSV의 열이 됩니다.
- JSON 안에서는 역슬래시를 두 번(`\\d`) 써야 합니다.
- 규칙이 여러 개면 **위에서부터 처음 맞는 규칙** 하나만 씁니다.

## 출력 예시
```
전체 5건 중 추출 4건 → extracted.out.csv
  규칙 '입금': 2건
  규칙 '출금': 2건
  안 맞음 1건 → unmatched.out.txt (규칙을 보완하세요)
```
| 출처 | 규칙 | 날짜 | 시각 | 금액 | 상대 | 잔액 |
|---|---|---|---|---|---|---|
| sms.txt:1 | 입금 | 10/27 | 09:12 | 1250000 | 가나상사 | 3480000 |

## 주의사항
- `--clean-number` 로 지정한 열은 숫자·소수점·마이너스만 남깁니다.
- 글자 인코딩은 UTF-8 기준입니다. 문자·메일을 텍스트로 저장할 때 UTF-8로 저장하세요.
- 본인 업무 자료에만 쓰세요. 남의 개인정보를 모으는 용도로 쓰면 안 됩니다. 샘플 이름·금액은 가짜입니다.
