# 151 구간별 인센티브(수수료) 계산

## 무엇을 하나요?
담당자별 실적 CSV와 구간표(하한, 요율%)를 넣으면 **누진 방식** 또는 **일괄 방식**으로 인센티브를 계산하고, 구간별 계산 내역까지 CSV로 남깁니다.

## 어떤 업무에 쓰나요?
- 영업 사원 월 인센티브 계산·검증
- 대리점·중개 수수료 구간 정산
- "누진이면 얼마, 일괄이면 얼마" 규정 변경 전 비교

## 두 방식의 차이 (실적 2,500만 원, 위 샘플 구간표)
- 누진: 1,000만×2% + 1,500만×3% = 65만 원
- 일괄: 2,500만×3% = 75만 원

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/sales.csv sample/tiers.csv               # 누진(기본)
python main.py sample/sales.csv sample/tiers.csv --mode flat   # 일괄
python main.py 실적.csv 구간.csv --round half_up -o 10월인센티브.csv
```

## 입력·출력 예시
구간표 `tiers.csv`
```
하한,요율%
0,2
10000000,3
30000000,5
```
출력
```
방식: 누진 / 4명 / 합계 2,220,000원 → commission.out.csv
  이테스트: 실적 25,000,000 → 650,000원 (10,000,000×2% + 15,000,000×3%)
```

## 주의사항
- 구간표 첫 하한은 반드시 0이어야 합니다.
- 금액 계산은 Decimal로 해서 소수 오차가 없습니다. 원 미만은 기본 버림입니다.
- 경계값은 "이하"로 봅니다(실적이 딱 1,000만 원이면 일괄 방식에서 2% 구간). 실제 지급 전에는 회사 규정과 한 번 맞춰 보세요. 샘플 이름은 가짜입니다.
