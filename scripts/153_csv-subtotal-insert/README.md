# 153 CSV 소계·총계 행 넣기 (엑셀 부분합 자동화)

## 무엇을 하나요?
CSV를 그룹 열(예: 부서, 팀) 기준으로 정렬하고, 그룹이 바뀔 때마다 **소계 행**, 맨 끝에 **총계 행**을 넣은 보고용 CSV를 만듭니다. 소계 행에는 건수도 적습니다.

## 어떤 업무에 쓰나요?
- 부서·팀별 경비 집계표
- 거래처별 매출 소계가 들어간 월말 보고 자료
- 엑셀 '부분합'을 매달 손으로 누르던 작업

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/expense.csv --group 부서,팀 --sum 금액,수량
python main.py 매출.csv --group 거래처 --sum 공급가액,부가세 --no-sort -o 매출_소계.csv
```

## 출력 예시
```
원본 6행 + 소계 6행 + 총계 1행 → subtotal.out.csv
총계: 금액=562000, 수량=17
```
| 부서 | 팀 | 항목 | 금액 | 수량 | 건수 |
|---|---|---|---|---|---|
| IT본부 | 개발팀 | 도서 | 28000 | 1 | |
| IT본부 | 개발팀 | 교육비 | 300000 | 1 | |
| IT본부 | 개발팀 소계 | | 328000 | 2 | 2 |
| ... | | | | | |
| IT본부 소계 | | | 343000 | 3 | 3 |
| 총계 | | | 562000 | 17 | 6 |

## 주의사항
- 정렬은 글자 순입니다. 원하는 순서가 따로 있으면 미리 정렬하고 `--no-sort` 를 쓰세요.
- 숫자가 아닌 값은 0으로 계산합니다. 결과 파일을 다시 합계 내면 소계가 두 번 더해지니 조심하세요.
