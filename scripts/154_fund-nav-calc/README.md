# 154 펀드 기준가격(NAV) 계산

## 무엇을 하나요?
날짜별 자산총액·부채총액·좌수를 넣으면 **기준가격(1,000좌당 순자산)**, 전일 대비 등락, 누적 수익률을 계산합니다. 순자산 증감과 좌수 증감을 같이 보여 줘서 "설정금이 들어와 커진 것"과 "운용 성과"를 구분해 볼 수 있습니다.

## 어떤 업무에 쓰나요?
- 펀드 사무관리·운용사 기준가 검증(시스템 값과 대조)
- 사내 모의 포트폴리오·동호회 공동 투자 장부의 지분 가치 계산
- 기준가 공시 전 이상 등락 확인

## 계산식
기준가격 = (자산총액 − 부채총액) ÷ 좌수 × 1,000 (소수 둘째 자리 반올림)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/fund_daily.csv
python main.py 일별자산.csv --unit 1 --digits 4 -o nav_check.csv   # 1좌 기준, 소수 4자리
```

## 출력 예시
```
5일 계산 → nav.out.csv
  2026-10-26 기준가 1,020.00 (첫날) 순자산증감 - / 좌수증감 -
  2026-10-28 기준가 1,027.12 (+0.05%) 순자산증감 +981000000 / 좌수증감 +950000000
```
10/28은 순자산이 9.8억 늘었지만 대부분 신규 설정(좌수 증가) 때문이고, 기준가는 0.05%만 올랐다는 것을 알 수 있습니다.

## 주의사항
- 실제 펀드 기준가는 미수·미지급 비용, 보수 일할 계산 등이 반영된 회계 값이 필요합니다. 이 스크립트는 입력값으로 **나눗셈과 비교를 정확히** 해 주는 검증 도구입니다.
- 샘플 숫자는 가짜입니다.
