# 155 송·수신 파일 건수·합계(컨트롤 토털) 검증

## 무엇을 하나요?
`헤더 / 데이터 / 트레일러` 구조의 일괄 파일에서 **실제 데이터 건수와 금액 합계**를 세어 **트레일러에 적힌 값과 비교**합니다. 헤더 개수, 트레일러 위치, 이상한 줄도 함께 찾습니다. 맞으면 종료코드 0, 틀리면 1입니다.

## 어떤 업무에 쓰나요?
- 은행·카드사·VAN·대외기관 수신 파일 1차 검증
- 송신 전 우리가 만든 파일 자체 점검
- 배치에서 "파일 검증 실패 시 후속 작업 중단" 조건

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/ok_20261030.txt sample/bad_20261030.txt
# 탭 구분, 금액이 5번째 열(0부터 4), 트레일러 건수 2열·합계 3열, 한글 윈도우 인코딩
python main.py recv.dat --delim tab --amount-col 4 --t-count-col 2 --t-sum-col 3 --encoding cp949
# 배치에서
python main.py recv.dat || echo "검증 실패 - 후속 작업 중단"
```

## 출력 예시
```
[일치] sample/ok_20261030.txt  데이터 3건 / 합계 3,730,500
[불일치] sample/bad_20261030.txt  데이터 2건 / 합계 1,630,000
    - 4행 알 수 없는 구분 'X'
    - 건수 불일치: 트레일러 3 / 실제 2 (차이 -1)
    - 금액 불일치: 트레일러 3,730,500 / 실제 1,630,000 (차이 -2,100,500)
```

## 주의사항
- 열 위치는 **0부터** 셉니다. 고정길이(자리수) 파일은 먼저 027번 `fixed-width` 스크립트로 CSV로 바꾼 뒤 쓰세요.
- 샘플 거래처·금액은 가짜입니다.
