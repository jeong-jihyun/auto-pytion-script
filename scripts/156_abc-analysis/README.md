# 156 ABC(파레토) 분석

## 무엇을 하나요?
판매 내역이나 품목별 금액 CSV로 **ABC 분석**을 합니다. 같은 품목은 합치고, 금액이 큰 순으로 누적 비율을 구해 **A(상위 ~80%) / B(~95%) / C(나머지)** 등급을 매깁니다.

## 어떤 업무에 쓰나요?
- 재고 관리: A등급 품목은 매일, C등급은 월 1회 점검처럼 관리 강도 나누기
- 구매: 금액 비중 큰 품목부터 단가 협상
- 고객 분석: 품목 대신 '고객' 열을 넣으면 우량 고객 등급

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/sales_lines.csv                      # 금액 기준
python main.py sample/sales_lines.csv --value 수량          # 수량 기준
python main.py 매출.csv --item 거래처 --value 공급가액 --a 70 --b 90
```

## 출력 예시
```
품목 8개 / 합계 3,073,000 → abc.out.csv
  A등급: 3개(38%) · 금액 비중 80.8%  품목A, 품목B, 품목C
  B등급: 3개(38%) · 금액 비중 17.0%  품목E, 품목D, 품목Q
  C등급: 2개(25%) · 금액 비중 2.2%  품목H, 품목K
```

## 주의사항
- 기준선(80%)에 걸치는 품목은 위 등급(A)에 넣습니다.
- 반품처럼 음수 금액이 있으면 품목 합계가 줄어듭니다. 필요하면 미리 걸러 주세요.
- 샘플 데이터는 무작위로 만든 가짜입니다.
