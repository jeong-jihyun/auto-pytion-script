# 157 TCP 포트 점검

## 무엇을 하나요?
CSV에 적은 서버·포트마다 TCP 접속을 한 번 해 보고 **열림 / 닫힘 / 시간초과**와 응답 시간(ms)을 표로 남깁니다. `기대` 열(open/closed)과 다르면 **[이상]** 으로 표시하고 종료코드 1을 돌려줍니다.

## 어떤 업무에 쓰나요?
- 아침 시스템 점검: DB, MQ, WAS, 대외 회선 포트가 살아 있는지
- 작업(방화벽 변경·배포) 전후 비교
- 배치 시작 전 선행 조건 확인 (`python main.py list.csv || exit 1`)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
# 연습용: 다른 창에서 18080 포트로 간단한 웹서버를 띄운 뒤 실행
python -m http.server 18080 &
python main.py sample/targets.csv
python main.py 운영서버.csv --timeout 2 --workers 20 -o 1030_점검.csv
```

## 입력·출력 예시
```
이름,호스트,포트,기대
테스트웹,127.0.0.1,18080,open
닫힌포트,127.0.0.1,18081,closed
```
```
점검 3개 / 이상 1개 (2026-10-30 09:00:01) → port_check.out.csv
         테스트웹      127.0.0.1:18080  open (기대 open) 0.3ms
         닫힌포트      127.0.0.1:18081  closed (기대 closed) 접속 거부
  [이상] DB(예시)     127.0.0.1:18082  closed (기대 open) 접속 거부
```

## 주의사항
- **내가 관리하거나 점검 허락을 받은 서버에만** 쓰세요. 허락 없는 포트 스캔은 법·사내 규정 위반이 될 수 있습니다. 그래서 한 번에 500개까지만 받습니다.
- 접속만 하고 바로 끊으며 데이터는 보내지 않습니다. 그래도 일부 보안 장비는 접속 기록을 남깁니다.
- '열림'은 포트가 열려 있다는 뜻일 뿐, 서비스가 정상 응답한다는 뜻은 아닙니다. HTTP 점검은 122번 `url-health-check` 를 함께 쓰세요.
