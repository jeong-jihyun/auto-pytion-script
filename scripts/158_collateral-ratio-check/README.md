# 158 신용계좌 담보비율 점검

## 무엇을 하나요?
보유 종목·종가·대출금으로 계좌별 **담보비율**을 계산해 **추가담보요구(유지비율 미달)**, **반대매매후보(반대매매 기준 미달)** 계좌를 먼저 보여 줍니다. 유지비율까지 모자란 금액도 계산합니다. `--shock -10` 으로 "가격이 10% 떨어지면?"도 볼 수 있습니다.

## 어떤 업무에 쓰나요?
- 증권사 신용·담보대출 일일 점검 결과 검증(시스템 값과 대사)
- 장 시작 전 위험 계좌 미리 보기, 스트레스 테스트
- 개인 투자자의 내 신용계좌 위험도 확인

## 계산식
- 담보평가금액 = Σ(수량 × 종가 × 담보인정비율) + 예수금
- 담보비율 = 담보평가금액 ÷ 대출금 × 100
- 부족액 = 대출금 × 유지비율 − 담보평가금액 (0 이상만)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/positions.csv sample/prices.csv sample/loans.csv
python main.py sample/positions.csv sample/prices.csv sample/loans.csv --shock -10
python main.py 보유.csv 종가.csv 대출.csv --maintain 150 --liquidate 140
```

## 출력 예시
```
계좌 4개 / 유지 140% · 반대매매 130% · 가격충격 0% → collateral.out.csv
  [반대매매후보] 1002-01 담보비율 121.23% 부족액 1,220,000원
  [추가담보요구] 1001-01 담보비율 135.00% 부족액 1,150,000원
  [확인필요] 1003-01 담보비율 178.75% 부족액 0원 가격 없음: A9999
  [정상] 1004-01 담보비율 187.00% 부족액 0원
```

## 주의사항
- 가격 파일에 없는 종목이 있으면 그 계좌는 **'확인필요'** 로 따로 둡니다(0원으로 계산해 잘못 반대매매 대상이 되는 것을 막기 위함).
- 실제 반대매매·고객 통지는 반드시 회사 시스템과 규정대로 하세요. 이 스크립트는 **점검·검증용**입니다.
- 샘플 계좌·종목은 가짜입니다.
