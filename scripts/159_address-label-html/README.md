# 159 주소 라벨 인쇄용 HTML 만들기

## 무엇을 하나요?
주소록 CSV(우편번호, 주소, 상세주소, 이름, 호칭)를 **A4 라벨지 칸에 맞춘 HTML**로 만듭니다. 브라우저로 열고 인쇄하면 됩니다. 칸 수·여백을 옵션으로 맞출 수 있고, 이미 몇 칸 쓴 라벨지는 `--skip` 으로 앞 칸을 비웁니다.

## 어떤 업무에 쓰나요?
- 고지서·안내문·명절 선물 발송 라벨
- 워드 '편지 병합'이 번거로울 때

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/addresses.csv                         # 2열×8행(16칸)
python main.py 주소록.csv --cols 3 --rows 7 --top 15 --left 7 # 21칸 라벨지
python main.py 주소록.csv --skip 5                            # 앞 5칸은 이미 사용함
```

## 출력 예시
```
주소 3건 / 빈칸 0 / 라벨 2×8 (100.0×34.6mm) / 1장 → labels.out.html
```
호칭 열이 비어 있으면 `--honorific`(기본 "님")을 붙입니다.

## 주의사항
- 인쇄할 때 **배율 100%(실제 크기)**, 머리글·바닥글 끄기로 설정하세요.
- 라벨지 제품마다 여백이 다르니 처음엔 **일반 종이에 인쇄해 라벨지와 겹쳐 보고** 옵션을 조정하세요.
- 주소록은 개인정보입니다. 만든 HTML 파일은 인쇄 후 지우고, 공용 폴더에 두지 마세요. 샘플 주소는 가짜입니다.
