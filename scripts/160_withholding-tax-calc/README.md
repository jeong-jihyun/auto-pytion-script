# 160 원천징수(3.3% / 8.8%) 계산

## 무엇을 하나요?
프리랜서 용역비(사업소득)와 일시 강연료·원고료(기타소득)의 **소득세·지방소득세·실수령액**을 계산합니다. `--reverse` 를 주면 "실수령액을 100만 원으로 맞춰 주세요" 같은 요청에 맞는 **세전 지급액을 거꾸로** 찾아 줍니다.

## 어떤 업무에 쓰나요?
- 외부 강사료·원고료·프리랜서 비용 지급 전 금액 확인
- 원천세 신고 전 지급 내역 검산
- 실수령액 기준 계약 금액 역산

## 계산 방법
| 구분 | 소득세 | 지방소득세 | 대략 세율 |
|---|---|---|---|
| 사업소득 | 지급액 × 3% | 소득세 × 10% | 3.3% |
| 기타소득 | (지급액 − 필요경비 60%) × 20% | 소득세 × 10% | 8.8% |

- 세액 10원 미만 버림(`--truncate 1` 로 1원 단위)
- 기타소득금액(필요경비 뺀 금액)이 5만 원 이하면 세금 0 (과세최저한, `--other-min`)
- `--small-exempt` 를 주면 소득세 1,000원 미만은 징수하지 않음(소액부징수)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/payments.csv
python main.py sample/payments.csv --small-exempt
python main.py sample/target_net.csv --reverse      # 실수령액 → 지급액
```

## 출력 예시
```
계산 4건 → withholding.out.csv
  김가상 [사업소득] 지급 1,500,000 - 소득세 45,000 - 지방 4,500 = 실수령 1,450,500원 (3.3%)
  이테스트 [기타소득] 지급 300,000 - 소득세 24,000 - 지방 2,400 = 실수령 273,600원 (8.8%)
  박샘플 [기타소득] 지급 120,000 - 소득세 0 - 지방 0 = 실수령 120,000원 (0.0%)
```
박샘플은 기타소득금액이 48,000원(12만 원의 40%)이라 과세최저한(5만 원 이하)에 걸려 세금이 0원입니다.

## 주의사항
- 세법(필요경비율, 과세최저한, 소액부징수 적용 범위)은 바뀔 수 있습니다. **지급·신고 전에 국세청 안내나 세무 담당자와 기준을 꼭 확인**하세요. 기준값은 옵션으로 바꿀 수 있습니다.
- 근로소득(급여) 간이세액표 계산은 다루지 않습니다.
- 이 스크립트는 계산 도구일 뿐 세무 자문이 아닙니다. 샘플 이름은 가짜입니다.
