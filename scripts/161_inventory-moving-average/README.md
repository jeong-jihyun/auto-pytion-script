# 161 재고 수불부(이동평균법)

## 무엇을 하나요?
입고·출고 기록 CSV로 품목별 **재고 수불부**(입고·출고·잔량·평균단가·재고금액)를 만들고, **이동평균법**으로 출고원가와 기말재고 금액을 계산합니다.

## 어떤 업무에 쓰나요?
- ERP 없이 엑셀로 관리하던 소모품·상품 재고의 월말 원가 계산
- ERP가 계산한 출고원가·기말재고 금액 검산
- 재고보다 많이 나간 출고(마이너스 재고) 찾기

## 계산 방법
- 입고할 때: 새 평균단가 = (기존 재고금액 + 입고금액) ÷ (기존 수량 + 입고 수량)
- 출고할 때: 출고원가 = 출고 수량 × 그 시점 평균단가
- 처리 순서: 일자 → 파일에 적힌 순서. 같은 날 입고를 먼저 처리하려면 `--in-first`
- 금액은 원 단위 반올림(내부 계산은 소수 그대로 유지)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/movements.csv --opening sample/opening.csv
python main.py sample/movements.csv --opening sample/opening.csv --in-first
```

## 입력 예시 (movements.csv)
| 일자 | 품목 | 구분 | 수량 | 단가 |
|---|---|---|---|---|
| 2026-11-02 | A4용지 | 입고 | 20 | 26500 |
| 2026-11-03 | A4용지 | 출고 | 15 | |

기초재고(opening.csv): `품목,수량,단가`

## 출력 예시
```
수불부 7줄 → ledger.out.csv, 품목 요약 2개 → ledger_summary.out.csv
  A4용지: 출고원가 650,000원, 기말 15개 / 400,000원
  토너: 출고원가 495,000원, 기말 -1개 / 0원  ⚠ 경고 1건
```
- `ledger.out.csv`: 줄마다 입고금액·출고원가·잔량·평균단가·재고금액·경고
- `ledger_summary.out.csv`: 품목별 기초·입고·출고·기말 수량과 금액

## 주의사항
- 재고가 마이너스가 되면 계산은 계속하지만 `경고` 열에 표시하고, 그 품목의 재고금액은 0으로 둡니다(출고원가는 직전 평균단가로 잡음). 입고 누락이 없는지 확인하세요.
- 회사 회계 기준(총평균법·선입선출법 등)이 다르면 결과도 다릅니다. 이 스크립트는 이동평균법만 계산합니다.
- 샘플 데이터는 가짜입니다.
