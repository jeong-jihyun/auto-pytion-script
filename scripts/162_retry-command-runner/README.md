# 162 실패 시 재시도 실행기

## 무엇을 하나요?
배치 명령을 실행하다 **실패하면 기다렸다가 다시 실행**합니다. 기다리는 시간은 점점 늘릴 수 있고(지수 백오프), 시도마다 시작 시각·소요 시간·종료 코드·출력 마지막 줄을 CSV로 남깁니다.

## 어떤 업무에 쓰나요?
- 네트워크가 잠깐 끊겨 실패하는 파일 전송·외부 연동 배치
- 새벽에 실패한 배치를 사람이 손으로 다시 돌리던 일 줄이기
- 실행 시간이 너무 길어지는 배치를 시간 제한으로 끊기

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
`--` 뒤에 실행할 명령을 그대로 적습니다(셸을 거치지 않으므로 `|`, `>` 같은 기호는 쓸 수 없습니다).
```bash
# 연습: 처음 2번 실패하고 3번째 성공하는 가짜 배치
python main.py --retries 3 --delay 1 -- python sample/flaky_job.py /tmp/count.txt 2

# 실제 예: 최대 5번 재시도, 30초부터 2배씩, 한 번 실행 10분 제한, 종료코드 2는 재시도 안 함
python main.py --retries 5 --delay 30 --timeout 600 --no-retry-codes 2 --name 정산파일전송 -- python send_file.py
```

## 출력 예시
```
[1/4] 실패 (종료코드 1, 0.03초) 1번째 실행: 연결 실패(가짜)
  → 1초 기다렸다가 다시 시도합니다.
[2/4] 실패 (종료코드 1, 0.03초) 2번째 실행: 연결 실패(가짜)
  → 2초 기다렸다가 다시 시도합니다.
[3/4] 성공 (종료코드 0, 0.03초) 3번째 실행: 전송 완료 120건(가짜)
최종: 성공 (종료코드 0), 기록 → retry_log.out.csv
```
`retry_log.out.csv` 는 이어 쓰기라 여러 날의 기록이 쌓입니다.

## 종료 코드
- 마지막 시도의 종료 코드를 그대로 돌려줍니다(성공 0). 시간초과는 124, 명령 없음은 127.

## 주의사항
- **같은 일을 두 번 해도 괜찮은(멱등) 작업에만** 쓰세요. 예를 들어 '이체 실행'처럼 중간까지 처리된 뒤 실패할 수 있는 작업을 자동 재시도하면 중복 처리될 수 있습니다.
- 비밀번호는 명령 인자에 넣지 말고 환경변수로 전달하세요(인자는 기록·프로세스 목록에 보일 수 있습니다).
