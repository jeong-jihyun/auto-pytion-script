# 163 중도상환수수료 계산

## 무엇을 하나요?
대출을 만기 전에 갚을 때 내는 **중도상환수수료**를 잔존기간 체감 방식으로 계산합니다. 대출금리를 함께 주면 **앞으로 아낄 이자(어림)** 와 **이득(어림)** 도 보여 줍니다.

## 어떤 업무에 쓰나요?
- 여유 자금으로 어떤 대출을 먼저 갚을지 비교
- 은행이 안내한 수수료 검산
- 회사 차입금 조기 상환 검토 자료 만들기

## 계산 방법
```
수수료 = 상환금액 × 수수료율 × (남은 일수 ÷ 기준 일수)
기준 기간 = 대출일 ~ min(만기일, 대출일 + 면제기간(기본 3년))
남은 일수 = 상환일 ~ 기준 기간 끝 (0 이하면 수수료 0원)
아낄 이자(어림) = 상환금액 × 대출금리 × (만기까지 남은 일수 ÷ 365)
```
- 10원 미만 버림(`--truncate`)
- 수수료율·면제기간이 빈칸이면 `--rate`(기본 1.2%), `--free-years`(기본 3년)를 씁니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/loans.csv
python main.py sample/loans.csv --rate 1.0 --free-years 2
```

## 입력 예시
| 대출ID | 대출일 | 만기일 | 상환일 | 상환금액 | 수수료율 | 면제기간 | 대출금리 |
|---|---|---|---|---|---|---|---|
| L-001 | 2025-03-15 | 2030-03-15 | 2026-11-20 | 30,000,000 | 1.2 | 3 | 4.5 |

## 출력 예시
```
계산 4건, 오류 1건 → prepay_fee.out.csv
  L-001: 30,000,000원 상환 → 수수료 157,990원 (남은 481/1096일), 이득(어림) 4,321,051원
  L-003: 50,000,000원 상환 → 수수료 0원 (남은 0/1096일), 이득(어림) 11,621,917원
```
L-003은 대출한 지 3년이 지나 수수료가 0원입니다. L-005는 상환일이 대출일보다 빨라 오류로 표시됩니다.

## 주의사항
- 실제 수수료는 **대출 약정서의 계산식이 우선**합니다(면제 조건, 연간 일부 상환 무료 한도, 일할 기준 등). 이 결과는 참고용입니다.
- '아낄 이자'는 남은 원금이 만기까지 그대로라고 가정한 단순 어림입니다. 원리금균등 상환이면 실제보다 크게 나옵니다.
- 이 스크립트는 계산 도구일 뿐 금융 자문이 아닙니다. 샘플 데이터는 가짜입니다.
