# 164 한글 이름 로마자 변환

## 무엇을 하나요?
한글 이름을 **국어의 로마자 표기법(인명 규칙)** 으로 바꾸고, 성씨는 **표준 표기(Gim, I, Bak)** 와 **흔히 쓰는 표기(Kim, Lee, Park)** 를 함께 보여 줍니다. 명부에 이미 영문 이름이 있으면 비교해서 다른 사람을 표시합니다.

## 어떤 업무에 쓰나요?
- 해외 출장·교육 참가자 영문 명단 만들기
- 영문 명함·영문 증명서 이름 일괄 작성
- 인사 명부의 영문 이름 오타 검수

## 변환 규칙
- 글자별로 바꿉니다(인명은 소리 나는 대로 바꾸지 않음): 복남 → Boknam
- 앞 글자 받침 ㄹ + 뒤 글자 첫소리 ㄹ 은 `ll`: 별라 → Byeolla
- 두 글자 성(남궁, 황보, 제갈, 선우, 독고, 사공, 서문 등)을 먼저 확인
- `--surname standard` 면 성도 표준 표기(Gim, I)로 씁니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py 홍길동 남궁민수 이별라
python main.py --csv sample/members.csv
python main.py --csv sample/members.csv --style passport --hyphen
```

## 출력 예시
```
홍길동 → Hong Gildong  (표준 성: Hong, 하이픈: Gil-dong)
남궁민수 → Namgoong Minsu  (표준 성: Namgung, 하이픈: Min-su)
이별라 → Lee Byeolla  (표준 성: I, 하이픈: Byeol-la)
CSV 7명 변환 → romanized.out.csv, 기존 영문과 다른 사람 1명
```
- E002 '김복남'의 기존 영문 Bongnam 은 소리 나는 대로 적은 것이라 '다름(확인)'으로 표시됩니다.
- 영문 열이 비어 있으면 '영문 없음'으로 표시합니다.
- E007처럼 한글이 아닌 글자가 섞이면 `비고` 열에 이유를 적습니다.

## 주의사항
- **여권 영문 이름은 본인이 이미 정한 표기가 우선**입니다. '다름'은 틀렸다는 뜻이 아니라 확인해 보라는 뜻입니다.
- 성씨 관용 표기 목록은 대표적인 것만 넣었습니다. 목록에 없는 성은 표준 표기를 씁니다.
- 샘플 이름은 가짜입니다.
