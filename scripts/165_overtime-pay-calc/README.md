# 165 연장·야간·휴일 근로 수당 계산

## 무엇을 하나요?
출퇴근 기록과 시급으로 하루 근무를 **연장·야간·휴일(8시간 이내/초과)** 시간으로 나누고, **가산수당**(평일 8시간 이내 기본 근무를 뺀, 추가로 줄 돈)을 계산합니다. 사람별 합계도 만듭니다.

## 어떤 업무에 쓰나요?
- 월말 급여 작업 전 초과근무 수당 계산·검산
- 야간 배치·장애 대응 당직 근무 수당 정리
- 근태 시스템이 낸 수당 금액 확인

## 계산 기준 (상시 5인 이상 사업장)
| 종류 | 시간 | 지급 |
|---|---|---|
| 연장 | 평일 실근로 8시간 초과분 | 시급 × 1.5 |
| 휴일(8h 이내) | 휴일 근로 처음 8시간 | 시급 × 1.5 |
| 휴일(8h 초과) | 휴일 근로 8시간 넘는 부분 | 시급 × 2.0 |
| 야간 | 22:00~06:00 근로(연장·휴일과 겹쳐도 따로) | 시급 × 0.5 가산 |

- 휴게는 `12:00-13:00;18:00-18:30` 처럼 구간으로 적으면 그 시간을 뺍니다.
- 퇴근이 출근보다 이르면 자정을 넘긴 것으로 봅니다.
- `--small`: 5인 미만 사업장(가산 없음, 연장·휴일 1.0배, 야간 가산 0)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/timesheet.csv
python main.py sample/timesheet.csv --small
```

## 출력 예시
```
5인 이상(가산 적용) 기준, 5일 계산 → overtime_daily.out.csv, overtime_person.out.csv
  김가상: 연장 4h, 휴일 0h, 야간 1h → 수당 78,000원
  이테스트: 연장 1h, 휴일 10h, 야간 7h → 수당 315,000원
```
예) 11-09 이테스트: 20:00~06:00, 휴게 02:00-03:00 → 실근로 9h, 연장 1h(22,500원) + 야간 7h 가산(52,500원) = 75,000원

## 주의사항
- **주 40시간 초과(주 단위 연장), 주휴수당, 포괄임금제, 대체휴일**은 다루지 않습니다.
- 통상시급 계산(월급 ÷ 209시간 등)은 회사 기준에 따라 다르므로 시급 열에 직접 넣으세요.
