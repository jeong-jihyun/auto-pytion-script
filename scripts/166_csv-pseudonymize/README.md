# 166 CSV 가명처리(같은 값 → 같은 가명)

## 무엇을 하나요?
CSV의 고객번호·이름·전화 같은 식별 열을 **비밀 키를 섞은 해시(HMAC-SHA256)** 로 만든 가명(`CUST_3f9a1c…`)으로 바꿉니다. **같은 값은 항상 같은 가명**이 되므로, 가명처리한 뒤에도 고객별 집계나 파일 간 연결을 할 수 있습니다.

## 어떤 업무에 쓰나요?
- 운영 데이터를 개발·테스트 환경에 넘길 때
- 외부 분석 업체·다른 부서에 데이터를 줄 때(고객별 패턴은 남기고 신원은 가림)
- 036번 마스킹(*** 가리기)과 달리 '같은 고객인지'는 알아야 하는 경우

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 준비: 비밀 키
키는 **환경변수로만** 넣습니다(.env.example 참고). 같은 키를 써야 다음 달 파일도 같은 가명이 나옵니다.
```bash
export PSEUDO_KEY='충분히-길고-무작위인-문자열-예시입니다'
```

## 실행 예시
```bash
python main.py sample/transactions.csv -c 고객번호:CUST,이름:NAME,전화:TEL
python main.py sample/transactions.csv -c 고객번호:CUST --mapping secret_mapping.out.csv
```

## 출력 예시
```
5행 가명처리 → pseudonymized.out.csv
  고객번호: 서로 다른 값 3개 → CUST_xxxx
  이름: 서로 다른 값 3개 → NAME_xxxx
  전화: 서로 다른 값 2개 → TEL_xxxx
```
(가명 값은 키에 따라 달라집니다.)

| 거래일 | 고객번호 | 이름 | 전화 | 지점 | 금액 |
|---|---|---|---|---|---|
| 2026-11-02 | CUST_9c1e… | NAME_41d0… | TEL_7a2b… | 강남 | 50000 |
| 2026-11-03 | CUST_9c1e… (같은 고객) | NAME_41d0… | TEL_7a2b… | 강남 | 30000 |

## 주의사항
- 가명처리한 데이터도 **다른 정보와 합치면 누구인지 알 수 있는 개인정보**일 수 있습니다. 제공·이용은 회사 개인정보 담당 부서의 기준(개인정보 보호법의 가명정보 규정 등)을 따르세요.
- 키가 새면 가명을 대입해 원본을 찾을 수 있습니다. 키는 코드·메일·메신저에 붙이지 마세요.
- `--mapping` 대응표는 원본을 되찾을 수 있는 파일입니다. 꼭 필요할 때만 만들고 따로 보관하세요.
- 날짜·지점·금액처럼 가명으로 바꾸지 않은 열만으로도 사람이 특정될 수 있는지 함께 확인하세요.
- 샘플 데이터는 가짜입니다.
