# 168 고객 RFM 분석

## 무엇을 하나요?
주문 내역으로 고객마다 **R(최근 주문 후 경과일)·F(주문 횟수)·M(총금액)** 을 계산해 1~5점을 매기고, **핵심·이탈 위험·충성·신규·휴면·관심 필요** 무리로 나눠 무리별 고객 수와 매출 비중, 할 일 제안을 보여 줍니다.

## 어떤 업무에 쓰나요?
- 마케팅·CRM 대상자 고르기(재방문 쿠폰을 누구에게 보낼까)
- 거래처 관리 우선순위 정하기(B2B 주문 데이터도 가능)
- 월별로 돌려 무리 이동(핵심 → 이탈 위험) 살피기

## 점수와 무리 규칙
- 점수: 고객들 사이 순위로 5등분(같은 값은 같은 점수). R은 경과일이 짧을수록 5점.
- 무리(위에서부터 먼저 맞는 것):

| 무리 | 조건 | 제안 |
|---|---|---|
| 핵심 고객 | R≥4, F≥4, M≥4 | 감사 혜택·VIP 관리 |
| 이탈 위험 | R≤2, F≥3 | 재방문 쿠폰·연락 |
| 충성 고객 | F≥4 | 추가 구매 제안 |
| 신규 고객 | R≥4, F≤1 | 두 번째 구매 유도 |
| 휴면 고객 | R≤1 | 저비용 재활성화 메시지 |
| 관심 필요 | 그 밖 | 관찰 |

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/orders.csv
python main.py sample/orders.csv --as-of 2026-11-30 --since 2026-01-01   # 기준일·기간 지정
python main.py 내주문.csv --customer 거래처코드 --date 일자 --amount 공급가액   # 열 이름이 다를 때
```

## 출력 예시
```
기준일 2026-10-28, 고객 15명 → rfm.out.csv
  핵심 고객    3명  매출 비중  44.6%  → 감사 혜택·VIP 관리
  이탈 위험    3명  매출 비중  16.0%  → 재방문 쿠폰·연락
  충성 고객    1명  매출 비중  28.3%  → 추가 구매 제안
  신규 고객    3명  매출 비중   3.9%  → 두 번째 구매 유도
  휴면 고객    3명  매출 비중   2.8%  → 저비용 재활성화 메시지(수신동의자만)
  관심 필요    2명  매출 비중   4.5%  → 관찰
```
`rfm.out.csv`: 고객ID, 마지막주문, 경과일, 주문수, 총금액, R, F, M, RFM(예: 545), 무리, 제안

## 주의사항
- 고객 수가 아주 적으면(수십 명 이하) 5등분 점수가 거칠어집니다.
- 광고성 메시지는 **수신 동의한 고객에게만** 보내야 합니다. 이 스크립트는 대상 목록만 만들고 발송은 하지 않습니다.
- 샘플 데이터는 무작위로 만든 가짜입니다.
