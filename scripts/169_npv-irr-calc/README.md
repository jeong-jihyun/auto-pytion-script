# 169 투자안 NPV·IRR·회수기간 계산

## 무엇을 하나요?
투자안별 연도 현금흐름으로 **NPV(순현재가치), IRR(내부수익률), 수익성지수, 회수기간, 할인 회수기간**을 계산하고 NPV 큰 순으로 비교합니다.

## 어떤 업무에 쓰나요?
- 시스템 도입(자체 구축 vs 클라우드)·설비 교체 품의서의 경제성 분석
- 여러 안을 같은 할인율로 한 번에 비교
- 엑셀로 계산한 NPV·IRR 검산

## 계산 방법
- NPV = Σ 현금흐름ₜ ÷ (1+할인율)ᵗ, t=0은 할인하지 않음 (엑셀: `=NPV(r, 1기~마지막) + 0기`)
- IRR: NPV를 0으로 만드는 할인율. -99%~1000%를 촘촘히 훑고 이분법으로 찾습니다.
  - IRR이 여러 개(현금흐름 부호가 여러 번 바뀌는 경우)면 IRR 칸을 비우고 비고에 모두 적습니다 → 이때는 NPV로 판단하세요.
- 수익성지수(PI) = (NPV + 총투자) ÷ 총투자
- 회수기간: 누적 현금흐름이 0을 넘는 시점(그 해 안은 고르게 들어온다고 보고 소수로)

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/plans.csv            # 할인율 8%
python main.py sample/plans.csv -r 12      # 할인율 12%
```

## 입력 예시 (세로 형식)
| 안 | 기간 | 현금흐름 |
|---|---|---|
| A_자체구축 | 0 | -300000000 |
| A_자체구축 | 1 | 60000000 |

## 출력 예시
```
할인율 8%, 투자안 4개 (NPV 큰 순) → npv_irr.out.csv
  B_클라우드: NPV 79,708,401원, IRR 41.04%, 회수 2.0년 / 할인회수 2.27년 → 채택 검토
  A_자체구축: NPV 62,143,367원, IRR 15.03%, 회수 3.36년 / 할인회수 3.99년 → 채택 검토
  D_설비교체: NPV 1,013,565원, IRR -, ... ⚠ IRR 여러 개(-63.52%, 8.97%) → NPV로 판단하세요
  C_현상유지: NPV -17,832,647원, IRR -, 회수 회수 못 함 ... → 기각 검토
```

## 주의사항
- '채택 검토/기각 검토'는 NPV 부호만 본 기계적 표시입니다. 위험·전략·예산 한도는 따로 판단하세요.
- 현금흐름은 연말에 한 번 들어온다고 가정합니다. 세금·감가상각 효과는 현금흐름에 미리 반영해서 넣으세요.
- 계산 도구일 뿐 투자 자문이 아닙니다. 샘플 숫자는 가짜입니다.
