# 171 거래 로그 TPS 피크 분석

## 무엇을 하나요?
거래(주문·이체·조회) 로그의 줄마다 시각을 찾아 **초당 처리 건수(TPS)** 를 셉니다. 평균·p95·p99·최대 TPS, **가장 몰린 초 상위 N개**, 설계 용량(`--limit`)을 넘은 초, 분 단위 추이 CSV를 만듭니다.

## 어떤 업무에 쓰나요?
- 장 시작(09:00) 직후 주문 폭주 때 순간 TPS가 용량을 넘었는지 확인
- 성능 시험·용량 산정 보고서에 넣을 피크·백분위 수치 뽑기
- 장애 시각 전후로 거래량이 얼마나 몰렸는지 확인

## 생각의 흐름
평균 TPS는 한산한 시간까지 섞여 낮게 나옵니다. 그래서 **초 단위로 세고**, 거래가 없던 초도 0건으로 채운 뒤 백분위와 피크를 봅니다. 054번(응답시간 통계)이 "얼마나 느렸나"라면, 이 스크립트는 "얼마나 몰렸나"를 봅니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/trade.log                       # 전체 거래
python main.py sample/trade.log --limit 12 --top 3    # 용량 12 TPS 초과 초 표시
python main.py logs/*.log --grep ORDER -o out/order.csv   # ORDER 줄만
```

## 입력 예시
시각이 `2026-11-12 09:00:01` 또는 `2026-11-12T09:00:01.123` 모양으로 들어간 줄이면 됩니다.
```
2026-11-12 09:00:02.415 INFO [ORDER] tx=T00031 acct=A012 elapsed=12ms
```

## 출력 예시
```
기간 2026-11-12 08:59:50 ~ 2026-11-12 09:01:19 (90초), 총 336건, 시각 없는 줄 1개 건너뜀
평균 TPS 3.73 / p95 12 / p99 18 / 최대 18
[피크 상위 3초]
  2026-11-12 09:00:02  18건
[용량 12 TPS 초과] 3초
  2026-11-12 09:00:02  18건 (+6)
```
`out/tps_per_minute.csv` : 분, 건수, 평균TPS, 최대TPS

## 주의사항
- 초 단위로 셉니다(밀리초는 버림). 더 잘게 보려면 스크립트를 고쳐야 합니다.
- 줄에서 **처음 나오는 시각**을 씁니다. 요청·응답 시각이 둘 다 있는 로그라면 `--grep` 으로 한쪽 줄만 고르세요.
- 여러 서버 로그를 함께 넣으면 합산 TPS가 됩니다(서버 시계가 맞아야 정확합니다).
- 기간이 아주 길면(며칠) 0건 초를 채우느라 메모리를 씁니다. 하루 단위로 나눠 돌리세요.
