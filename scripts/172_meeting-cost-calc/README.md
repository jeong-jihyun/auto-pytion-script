# 172 회의 비용 계산

## 무엇을 하나요?
회의 목록(시간, 직급별 참석 인원, 반복 주기)과 **직급별 시간당 인건비**로 회의 1회 비용과 **연간 비용**을 계산합니다. 비용이 큰 회의부터 정렬해 CSV로 저장합니다.

## 어떤 업무에 쓰나요?
- "주간 회의가 1년에 얼마짜리인지" 숫자로 보여 주고 회의 줄이기 근거 만들기
- 프로젝트 착수·정기 보고 회의 운영비 추정
- 회의 시간·참석 인원을 줄였을 때 절감액 비교(목록을 고쳐 다시 실행)

## 생각의 흐름
회의 비용 = Σ(직급 시간당 비용 × 인원) × 시간. 반복 회의는 1회만 보면 작아 보여서, 연간 횟수(매일 250, 매주 52, 격주 26, 매월 12, 매분기 4)를 곱해 연간 비용도 냅니다. 참석자는 이름 대신 **직급:인원** 으로만 적어 개인정보를 다루지 않습니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/meetings.csv --rates sample/rates.csv
python main.py sample/meetings.csv --rates sample/rates.csv --top 3 -o out/cost.csv
```

## 입력 예시
`meetings.csv`
```
회의명,시간(분),참석자,반복
주간 업무 보고,60,부장:1;차장:2;과장:3;대리:4,매주
분기 전략 회의,120,부장:3;차장:4,매분기
```
`rates.csv` (가짜 금액입니다. 회사 기준으로 바꾸세요)
```
직급,시간당비용
과장,40000
```
반복 칸: 비우거나 `없음`, `매일`, `매주`, `격주`, `매월`, `매분기`

## 출력 예시
```
회의 5개, 1회 합계 1,692,000원, 연간 합계 37,024,500원
[연간 비용 상위 4]
  주간 업무 보고: 10명 × 60분 = 1회 402,000원, 매주 → 연 20,904,000원
  [확인] 5행 '신규 시스템 착수 회의': 직급 '인턴' 비용이 rates 파일에 없음(0원으로 계산)
```

## 주의사항
- 시간당 비용은 급여·4대보험 등을 넣을지 회사 기준을 먼저 정하세요. 샘플 금액은 예시입니다.
- rates에 없는 직급은 0원으로 계산하고 `[확인]` 으로 알려 줍니다.
- 연간 횟수는 휴가·공휴일을 빼지 않은 어림값입니다.
