# 173 한글 파일 이름 자모 분리(NFD) 고치기

## 무엇을 하나요?
맥(macOS)에서 받은 파일의 한글 이름이 윈도우에서 **`ㅂㅗㄱㅗㅅㅓ`처럼 자모로 갈라져 보이는 문제**를 고칩니다. 폴더 안 파일·하위 폴더 이름을 모두 훑어, 풀어 쓴 모양(NFD)을 모아 쓴 모양(NFC)으로 바꿉니다. **기본은 미리보기**이고 `--apply` 를 붙여야 실제로 바뀝니다.

## 어떤 업무에 쓰나요?
- 맥 사용자에게 zip·USB·클라우드로 받은 자료의 파일명 정리
- 파일명으로 검색·대조(예: 104번 파일명 규칙 점검)가 안 될 때 먼저 정리
- 공유 폴더에 같은 이름처럼 보이는 파일이 두 개 생겼을 때 원인 확인

## 생각의 흐름
겉보기는 같아도 NFD 이름은 글자 수가 더 많습니다(예: `주간보고서.docx` 가 16글자). 그래서 화면에 **글자 수**를 같이 보여 줍니다. 하위 폴더 이름을 먼저 바꾸면 안쪽 경로가 깨지므로 **가장 깊은 곳부터** 바꾸고, NFC 이름의 다른 파일이 이미 있으면 **덮어쓰지 않고 건너뜁니다**.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python sample/make_sample.py              # 연습용 sample_mac_files/ 폴더 만들기
python main.py sample_mac_files           # 미리보기
python main.py sample_mac_files --apply   # 실제로 바꾸기
python main.py "D:/받은자료" --no-recursive   # 하위 폴더는 빼고
```
> git은 운영체제에 따라 NFD 파일명을 바꿔 버릴 수 있어, 샘플 파일 대신 `make_sample.py` 로 만들어 씁니다.

## 출력 예시
```
[미리보기] 바꿀 대상 5개
  회의자료/발표.pptx (글자 19개)  →  발표.pptx
  회의자료 (글자 8개)  →  회의자료
  건너뜀(같은 이름이 이미 있음): 견적서.pdf (글자 12개) → 견적서.pdf
  주간보고서.docx (글자 16개)  →  주간보고서.docx
미리보기: 4개 바뀔 예정, 1개 건너뜀. 실제로 바꾸려면 --apply 를 붙이세요.
```

## 주의사항
- 건너뛴 파일은 NFC·NFD 두 파일이 따로 있는 경우입니다. 내용을 비교해 하나를 직접 정리하세요(015번 중복 파일 찾기 활용).
- 맥 자체 디스크에서는 두 모양을 같은 이름으로 보므로 바꿀 필요가 거의 없습니다. 윈도우·리눅스·NAS에서 쓰세요.
- 실행 전 중요한 폴더는 010번 폴더 백업으로 먼저 백업하세요.
