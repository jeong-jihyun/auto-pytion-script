# 174 가로 표 → 세로 표 (언피벗)

## 무엇을 하나요?
`지점 | 1월 | 2월 | 3월` 처럼 **가로로 펼친 표**를 `지점 | 월 | 매출` 처럼 **한 줄에 값 하나인 세로 표**로 바꿉니다. 051번(피벗)의 반대 방향입니다.

## 어떤 업무에 쓰나요?
- 엑셀 월별 실적표를 DB·BI 도구에 올리기 전 정리
- 여러 달 보고서를 이어 붙여 다시 피벗·그래프(090번)로 만들기
- 예산표(항목이 열로 펼쳐진 표)를 080번 예산 대비 실적에 넣을 모양으로 바꾸기

## 생각의 흐름
그대로 둘 열(`--id`)은 줄마다 복사하고, 나머지 열은 "열 이름 → 항목 칸, 칸 값 → 값 칸"으로 한 줄씩 풉니다. 빈칸은 기본으로 버리고, `--number` 를 주면 `1,200` 같은 쉼표 숫자를 `1200` 으로 바꿉니다. 숫자가 아닌 값(예: `확인중`)은 그대로 두고 개수를 알려 줍니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/branch_sales.csv --id 지점,담당 --cols 1월,2월,3월 --var-name 월 --value-name 매출 --number
python main.py sample/branch_sales.csv --id 지점 --keep-empty -o out/all.csv   # id 아닌 모든 열, 빈칸 유지
```

## 입력 예시
```
지점,담당,1월,2월,3월,비고
강남,김가나,"1,200","1,350",1500,
판교,이다라,980,,"1,120",2월 집계 누락
```

## 출력 예시
```
입력 3행 × 풀 열 3개 → 출력 8행 (빈칸 1개 버림)
  [확인] 숫자가 아닌 값 1개는 글자 그대로 두었습니다
```
```
지점,담당,월,매출
강남,김가나,1월,1200
판교,이다라,3월,1120
```

## 주의사항
- `--cols` 를 비우면 id가 아닌 **모든 열**(비고 포함)을 풉니다. 메모 열이 있으면 `--cols` 로 골라 주세요.
- 엑셀 파일은 022번(xlsx → CSV)으로 먼저 CSV로 바꾸세요.
- 열 머리글이 두 줄(병합 셀)인 표는 먼저 한 줄 머리글로 고쳐야 합니다.
