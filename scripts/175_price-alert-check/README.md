# 175 보유 종목 손절·익절 기준 점검

## 무엇을 하나요?
보유 종목의 **매입가와 현재가**를 비교해 수익률을 계산하고, 내가 정한 **손절선·익절선·목표가**에 닿은 종목, 손절선에 가까워진 종목, 가격이 없는 종목을 골라 알려 줍니다. **주문은 하지 않습니다.** 알림 목록만 만듭니다.

## 어떤 업무에 쓰나요?
- 장 마감 뒤 보유 종목 원칙(손절 -10%, 익절 +20%) 지키기 점검
- 고객·운용 계좌의 한도 손실률 모니터링 보조 자료
- 083번(리밸런싱), 102번(배당 요약)과 함께 보유 현황 정리

## 생각의 흐름
수익률 = (현재가 − 매입가) ÷ 매입가. 종목마다 손절%·익절%를 따로 줄 수 있고, 비어 있으면 기본값(`--stop -10`, `--take 20`)을 씁니다. 순서는 **손절 → 목표가 → 익절 → 손절 근접(기본 2%p 이내)** 으로 판단하고, 급한 것(손절)이 맨 위에 오게 정렬합니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/holdings.csv sample/prices.csv
python main.py sample/holdings.csv sample/prices.csv --stop -7 --take 15 --near 3
```

## 입력 예시
`holdings.csv` (가짜 종목입니다)
```
종목코드,종목명,수량,매입가,손절%,익절%,목표가
A00001,가나전자,30,"72,000",-8,25,
A00004,사아금융,100,"12,300",,,15000
```
`prices.csv` : `종목코드,현재가` — 증권사 HTS에서 내려받은 종가 파일을 이 모양으로 맞추세요.

## 출력 예시
```
보유 6종목 중 알림 4건
  [손절] 가나전자(A00001) 매입 72,000 → 현재 65,800 (-8.61%, 기준 -8.0% / 25.0%) 평가손익 -186,000원
  [손절 근접] 다라화학(A00002) 매입 410,000 → 현재 376,000 (-8.29%, 기준 -10.0% / 20.0%) ...
  [목표가 도달] 사아금융(A00004) ...
  [가격 없음] A00006 카타통신 — 가격 파일을 확인하세요
```

## 주의사항
- 수수료·세금은 빼지 않은 단순 수익률입니다. 정확한 실현손익은 056번(FIFO 실현손익)을 쓰세요.
- 액면분할이 있었다면 매입가를 093번(수정주가)으로 먼저 맞추세요.
- 이 결과는 참고용이며 투자 권유가 아닙니다. 매매 판단은 직접 하세요.
