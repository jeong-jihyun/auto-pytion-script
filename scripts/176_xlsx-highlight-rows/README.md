# 176 CSV → 엑셀, 규칙대로 행·칸 색칠

## 무엇을 하나요?
CSV를 엑셀(xlsx)로 바꾸면서 **규칙(JSON)에 맞는 행이나 칸에 색**을 칠합니다. 예: 금액 1억 이상 행은 노랑, 상태가 실패인 행은 빨강, 담당이 빈칸이면 그 칸만 회색. 머리글은 굵게·틀 고정, 숫자는 천 단위 쉼표, 열 너비는 자동으로 맞춥니다.

## 어떤 업무에 쓰나요?
- 점검·대사 결과 CSV를 팀에 공유할 때 볼 곳을 색으로 표시
- 매일 받는 거래 목록에서 고액·실패·보류 건 강조
- 누락값(빈칸) 표시로 데이터 보완 요청

## 생각의 흐름
조건부 서식을 매번 손으로 거는 대신, 규칙을 파일로 적어 두고 반복합니다. 숫자처럼 보이는 값은 숫자로 넣어 엑셀에서 합계가 되게 하고, `00123` 같은 앞자리 0 코드는 글자로 둡니다. 규칙은 위에서부터 적용하며, 같은 칸에 여러 규칙이 맞으면 **뒤 규칙 색이 덮습니다**.

## 설치
```bash
pip install -r requirements.txt   # openpyxl
```

## 실행 예시
```bash
python main.py sample/transfers.csv --rules sample/rules.json
python main.py sample/transfers.csv --rules sample/rules.json --sheet 이체내역 -o out/이체점검.xlsx
```

## 규칙 파일 예시 (`rules.json`)
```json
[
  {"열": "금액", "비교": ">=", "값": 100000000, "색": "노랑", "범위": "row"},
  {"열": "상태", "비교": "==", "값": "실패", "색": "빨강", "범위": "row"},
  {"열": "담당", "비교": "empty", "색": "회색", "범위": "cell"}
]
```
- 비교: `>=` `<=` `>` `<` `==` `!=` `contains`(글자 포함) `empty`(빈칸)
- 색: `노랑` `빨강` `초록` `파랑` `회색` 또는 `FFC7CE` 같은 6자리 색 코드
- 범위: `row`(행 전체) / `cell`(그 칸만)

## 출력 예시
```
5행을 엑셀로 저장 → out/transfers.xlsx
  [노랑/row] 금액 >= 100000000: 2건
  [빨강/row] 상태 == 실패: 1건
  [파랑/cell] 상태 == 보류: 1건
  [회색/cell] 담당 empty : 1건
```

## 주의사항
- 색은 엑셀 조건부 서식이 아니라 **고정 색**입니다. 엑셀에서 값을 고쳐도 색은 바뀌지 않습니다.
- 크기 비교(`>=` 등)는 숫자 칸에만 맞습니다. 글자 칸은 맞지 않는 것으로 봅니다.
- 행이 수십만 개면 느려질 수 있습니다.
