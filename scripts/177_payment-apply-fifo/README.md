# 177 입금액 오래된 청구서부터 충당(FIFO)

## 무엇을 하나요?
거래처가 청구서 번호 없이 한꺼번에 입금했을 때, 입금액을 **오래된 청구서부터 차례로 갚은 것으로 맞춥니다**(선입선출 충당). 청구서별 남은 잔액, 다 갚고도 남은 입금(**선수금**), 거래처별 요약을 만들고 `청구 − 입금 = 미수 − 선수금` 검산도 합니다.

## 어떤 업무에 쓰나요?
- 월말 매출채권 잔액 정리(입금 소거·반제)
- 039번 채권 연령 분석 전에 청구서별 잔액 맞추기
- 거래처에 "어느 청구서가 아직 남았는지" 안내 자료 만들기

## 생각의 흐름
거래처별로 청구서는 청구일 순, 입금은 입금일 순으로 세웁니다. 입금 하나를 들고 맨 앞 청구서 잔액부터 깎고, 다 갚으면 다음 청구서로 넘어갑니다. 금액은 소수 오차가 없게 `Decimal` 로 계산합니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/invoices.csv sample/payments.csv
python main.py 청구.csv 입금.csv -o out/2026-11
```

## 입력 예시
`invoices.csv` : `거래처,청구번호,청구일,금액`
`payments.csv` : `거래처,입금번호,입금일,금액` (날짜는 `YYYY-MM-DD`)

## 출력 예시
```
거래처 4곳, 청구서 6건, 충당 내역 8줄
  가나상사: 청구 2,250,000 / 입금 1,800,000 → 미수 450,000, 선수금 0 (검산 OK)
  다라물산: 청구 2,500,000 / 입금 2,600,000 → 미수 0, 선수금 100,000 (검산 OK)
  사아식품: 청구 0 / 입금 150,000 → 미수 0, 선수금 150,000 (검산 OK)
```
- `applied.csv` : 입금번호 → 청구번호, 충당액, 충당 후 청구서 잔액
- `invoice_balance.csv` : 청구서별 청구액·입금충당·잔액·상태(완납/일부입금/미입금)
- `customer_summary.csv` : 거래처별 청구·입금·미수·선수금

## 주의사항
- 입금일보다 **나중에 발행된 청구서**에도 충당합니다(선입금을 다음 청구에 쓰는 흔한 방식). 회사 규칙이 다르면 결과를 확인하세요.
- 청구번호를 적어 입금한 건(지정 입금)은 이 방식이 아니라 005번 대사로 먼저 맞추세요.
- 반품·할인(마이너스 청구)은 다루지 않습니다. 먼저 원래 청구서 금액에서 빼 두세요.
- 거래처 이름 표기가 다르면 다른 거래처로 봅니다(060번으로 표기 통일).
