# 179 마크다운 목차 자동 생성

## 무엇을 하나요?
마크다운(.md) 문서의 제목(`##`, `###`)을 읽어 **클릭하면 이동하는 목차**를 만듭니다. 문서에 `<!-- toc -->` 와 `<!-- tocstop -->` 표시가 있으면 그 사이를 새 목차로 바꿉니다(`--apply` 일 때만, `.bak` 사본을 남김).

## 어떤 업무에 쓰나요?
- 운영 매뉴얼·장애 대응 가이드·인수인계 문서에 목차 달기
- GitHub·사내 위키 README의 목차를 제목 바꿀 때마다 다시 맞추기
- 070번(md → docx)으로 바꾸기 전에 목차 정리

## 생각의 흐름
줄 맨 앞 `#` 개수로 단계를 알고, GitHub 방식으로 링크 주소(앵커)를 만듭니다: 소문자로, 공백은 `-`, 문장부호는 지우고, **같은 제목이 또 나오면 `-1`, `-2`** 를 붙입니다. 코드 블록(```) 안의 `#` 은 제목이 아니므로 건너뜁니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/ops_guide.md                 # 목차 미리보기
python main.py sample/ops_guide.md --apply         # 표시 사이에 실제로 넣기
python main.py README.md --min 2 --max 4           # ## ~ #### 까지
```

## 입력 예시
````
# 야간 배치 운영 가이드
<!-- toc -->
<!-- tocstop -->
## 2. 실행 순서
### 2.1 정산 배치
```bash
# 이 줄은 코드라 제목이 아닙니다
```
````

## 주의사항
- 앵커 규칙은 GitHub 기준입니다. 다른 위키(Confluence, Notion 등)는 규칙이 달라 링크가 안 맞을 수 있습니다.
- 밑줄(`===`, `---`)로 쓴 제목은 인식하지 않습니다. `#` 제목만 씁니다.
- 표시가 없으면 문서를 바꾸지 않고 화면에만 보여 줍니다.
