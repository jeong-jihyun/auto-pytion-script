# 180 외화 채권·채무 기말 환산손익

## 무엇을 하나요?
외화예금·외상매출금·외상매입금 같은 **외화 잔액을 기말 환율로 다시 계산**해 장부금액과의 차이, 즉 **외화환산이익·손실**을 구합니다. 계정·통화별 합계와 이익·손실·순액을 보여 주고, 건별 결과를 CSV로 저장합니다.

## 어떤 업무에 쓰나요?
- 월말·분기말 결산 때 외화환산손익 분개 금액 준비
- 환율 급등락 때 외화 채권·채무 손익 영향 미리 보기(환율 파일만 바꿔 다시 실행)
- 062번(환율 변환)이 "금액 바꾸기"라면, 이 스크립트는 "장부 대비 손익"을 냅니다

## 생각의 흐름
기말평가액 = 외화금액 × 기말환율. 받을 돈(**자산**)은 환율이 오르면 이익이라 `기말평가액 − 장부금액`, 갚을 돈(**부채**)은 환율이 오르면 손실이라 `장부금액 − 기말평가액` 이 손익입니다. JPY처럼 100엔 단위로 고시되는 통화는 환율 파일의 `단위` 열(100)로 나눕니다. 금액은 `Decimal` 로 계산하고 원 미만은 반올림합니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/fx_balances.csv --rates sample/rates.csv
python main.py 외화잔액_2026-11.csv --rates 기말환율_2026-11-30.csv -o out/환산_2026-11.csv
```

## 입력 예시
`fx_balances.csv` (가짜 거래처입니다)
```
계정,거래처,구분,통화,외화금액,장부금액
외화예금,가나은행,자산,USD,"50,000.00","67,250,000"
외상매입금,Euro Parts GmbH,부채,EUR,"8,000.00","12,040,000"
```
`rates.csv` (예시 환율입니다. 실제는 회사가 정한 기준환율을 쓰세요)
```
통화,환율,단위
USD,1402.50,1
JPY,935.20,100
```

## 출력 예시
```
[계정·통화별 환산손익]
  외상매입금 (EUR): -106,400원
  외상매출금 (JPY): +280,000원
  외화예금 (USD): +2,875,000원
외화환산이익 3,677,750원 / 외화환산손실 275,150원 / 순액 +3,402,600원
  [확인] 7행: 통화 CNY 의 기말 환율이 없음 → 건너뜀
```

## 주의사항
- 장부금액은 **직전 평가 후 금액**이어야 합니다. 이미 환산한 금액에 또 더하지 않게 주의하세요.
- 환율 파일에 없는 통화·구분이 잘못된 줄은 건너뛰고 `[확인]` 으로 알려 줍니다.
- 결과는 분개 참고용입니다. 어떤 계정을 평가할지, 어느 환율을 쓸지는 회사 회계 규정과 담당자 확인을 따르세요.
