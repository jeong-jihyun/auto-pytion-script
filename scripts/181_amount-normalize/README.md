# 181 금액 글자를 숫자로 통일

## 무엇을 하나요?
CSV의 금액 열에 `1,234원`, `₩ 12000`, `(5,000)`, `△3,000`, `1,000-`, `3.5만`, `1억 2,000만` 처럼 제각각 적힌 값을 **계산할 수 있는 숫자**(`1234000`, `-5000`, `120000000`)로 바꿉니다. 바꾸지 못한 칸은 지우지 않고 `problems.csv` 에 행 번호와 함께 남깁니다.

## 어떤 업무에 쓰나요?
- 여러 부서에서 받은 경비·매출 표를 합치기 전에 금액 형식 맞추기
- 회계 출력물(괄호·△ 음수)을 다른 시스템에 올리기 전 정리
- 엑셀에서 "숫자로 저장된 텍스트" 때문에 합계가 안 맞을 때

## 생각의 흐름
1. 통화 기호·`원`·쉼표·공백을 지웁니다.
2. 음수 표시(앞 `-`, 괄호, `△`/`▲`, 뒤 `-`)가 하나라도 있으면 음수로 봅니다.
3. `억`·`만`·`천` 이 있으면 덩어리마다 곱해서 더합니다.
4. 그래도 숫자가 안 되면 **0으로 바꾸지 않고** 원래 글자를 둔 채 문제 목록에 적습니다. 조용히 0이 되면 합계가 틀려도 모르기 때문입니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/expenses.csv --columns 금액,수수료
python main.py 매출.csv --columns 공급가,세액 --decimals 2 --output output/매출_정리.csv
```

## 입력 예시 (`sample/expenses.csv`)
```
일자,거래처,금액,수수료
2026-11-03,마바유통,"(5,000)",-
2026-11-04,카타전자,3.5만,1천
2026-11-05,파하건설,"1억 2,000만",
2026-11-05,가나상사,미정,0
```

## 출력 예시
```
읽은 행: 8, 바뀐 칸: 9, 못 바꾼 칸: 2
  - 4행 [수수료] '-' → 숫자가 없습니다
  - 9행 [금액] '미정' → 숫자로 바꿀 수 없습니다
```
`output/normalized.csv`
```
2026-11-03,마바유통,-5000,-
2026-11-04,카타전자,35000,1000
2026-11-05,파하건설,120000000,
```

## 주의사항
- 원본 파일은 바꾸지 않습니다. 결과는 `output/` 에 새로 저장합니다.
- 빈 칸은 빈 칸 그대로 둡니다(0으로 채우지 않음).
- 통화 기호는 지우기만 하고 환산하지 않습니다. 원화·외화가 섞여 있으면 062번(환율 변환)을 함께 쓰세요.
- `1.2.3` 처럼 점이 여러 개인 값, 유럽식 `1.234,56` 표기는 문제 목록으로 갑니다.
