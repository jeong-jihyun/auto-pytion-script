# 182 git 커밋 기록으로 릴리스 노트 만들기

## 무엇을 하나요?
`git log` 로 뽑은 커밋 목록을 읽어 **새 기능 / 버그 수정 / 성능 개선 / 구조 개선 / 문서 / 테스트 / 빌드·배포 / 기타** 로 묶은 릴리스 노트(마크다운)를 만듭니다. `feat!:` 나 `BREAKING` 이 있는 커밋은 맨 위 **호환성 깨짐** 칸에 한 번 더 적습니다.

## 어떤 업무에 쓰나요?
- 운영 반영(배포) 전 변경 내역서·반영 요청서 초안 만들기
- 고객사·현업에 "이번 버전에서 바뀐 점" 공지 초안 만들기
- 주간 개발 보고에 이번 주 커밋 요약 붙이기

## 생각의 흐름
1. git 이 없는 PC에서도 쓰도록, 커밋 목록은 **텍스트 파일**로 받습니다.
2. 커밋 제목 앞머리로 나눕니다: 영어 관례(`feat:`, `fix:`, `docs:` …)와 한국어 말머리(`[기능]`, `[버그]`, `[문서]` …) 둘 다 압니다.
3. 둘 다 아니면 억지로 짐작하지 않고 **기타**에 둡니다.
4. Merge 커밋은 내용이 겹쳐서 기본으로 뺍니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 입력 파일 만드는 법 (저장소 폴더에서)
```bash
git log --pretty=format:"%h|%ad|%an|%s" --date=short v1.2.0..HEAD > gitlog.txt
```
`v1.2.0..HEAD` 는 "지난 태그 이후"라는 뜻입니다. 기간으로 하려면 `--since=2026-11-01` 을 쓰세요.

## 실행 예시
```bash
python main.py sample/gitlog.txt --version v1.3.0
python main.py sample/gitlog.txt --version v1.3.0 --with-author
python main.py gitlog.txt --since 2026-11-09 --until 2026-11-12 --output output/주간변경.md
```

## 입력 예시 (`sample/gitlog.txt`, 사람 이름은 가짜)
```
a1b2c3d|2026-11-12|김개발|feat(정산): 일별 정산 파일 자동 생성 추가
f6a7b8c|2026-11-10|이운영|feat!: 주문 API 응답에서 구버전 필드 삭제
b8c9d0e|2026-11-09|김개발|[버그] 대사 화면 합계 0원 표시 문제
```

## 출력 예시 (`output/RELEASE_NOTES.md`)
```
# 릴리스 노트 - v1.3.0
기간: 2026-11-08 ~ 2026-11-12 · 커밋 9개

## ⚠ 호환성 깨짐 (꼭 확인)
- 주문 API 응답에서 구버전 필드 삭제 (`f6a7b8c`, 이운영)

## 새 기능 (2)
- **정산**: 일별 정산 파일 자동 생성 추가 (`a1b2c3d`, 김개발)
...
## 기타 (1)
- 화면 문구 다듬기 (`d0e1f2a`, 이운영)
```

## 주의사항
- 커밋 제목에 `|` 가 들어 있어도 괜찮습니다(앞의 세 칸만 나눕니다).
- 형식이 맞지 않는 줄은 건너뛰고 줄 번호를 알려 줍니다.
- 결과는 **초안**입니다. 고객에게 보내기 전에 사람이 읽고 다듬으세요(내부 용어·티켓 번호 등).
