# 184 직원 명단으로 조직도 트리 + 명단 검사

## 무엇을 하나요?
직원 명단 CSV의 **사번·상사사번** 두 칸으로 조직도 트리를 그립니다. 동시에 명단의 잘못된 곳(사번 중복, 없는 상사, 자기 자신이 상사, 순환 참조)과 관리 폭·조직 깊이가 기준을 넘는 곳을 알려 줍니다.

## 어떤 업무에 쓰나요?
- 조직 개편안·인사 발령 전 명단이 맞는지 확인
- 결재선·권한 시스템(ERP, 그룹웨어)에 조직을 올리기 전 데이터 점검
- 회의 자료·인수인계 문서에 넣을 조직도 초안

## 생각의 흐름
1. 상사 사번이 빈 사람이 맨 위입니다. 그 사람부터 "나를 상사로 둔 사람"을 차례로 붙여 내려갑니다.
2. 상사 사번이 명단에 없으면(퇴사자·오타) 그 사람을 맨 위에 따로 보여 주고 확인할 점에 적습니다.
3. A→B→A 처럼 돌고 도는 경우는 맨 위에서 내려가도 만날 수 없습니다. 그래서 **트리에 한 번도 안 나온 사람 = 순환**으로 찾습니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/employees.csv
python main.py sample/employees.csv --max-span 1 --max-depth 3     # 기준을 낮춰 알림 확인
python main.py 인사명단.csv --id-col 사원번호 --boss-col 상위자사번 --label 성명,직위
```

## 입력 예시 (`sample/employees.csv`, 가짜 명단)
```
사번,이름,직급,부서,상사사번
E001,김대표,대표,경영,
E010,이본부,본부장,IT본부,E001
E030,서파견,사원,운영팀,E099
E040,오순환,과장,기획팀,E041
E041,유순환,과장,기획팀,E040
```

## 출력 예시
```
김대표 / 대표 / 경영 (E001)  [직속 2명]
├─ 이본부 / 본부장 / IT본부 (E010)  [직속 2명]
│  ├─ 박팀장 / 팀장 / 개발팀 (E011)  [직속 2명]
│  │  ├─ 정선임 / 선임 / 개발팀 (E013)
│  │  └─ 한주임 / 주임 / 개발팀 (E014)
...
서파견 / 사원 / 운영팀 (E030)
----------------------------------------
인원 13명, 최상위 2명, 최대 4단계
확인할 점:
  - 15행: 사번 E013 가 중복됨(첫 번째 것만 사용)
  - 사번 E030: 상사 사번 E099 가 명단에 없음 → 맨 위로 따로 표시
  - 순환 참조로 트리에 넣을 수 없는 사번: E040, E041
```
같은 내용이 `output/org_chart.md` 에도 저장됩니다.

## 주의사항
- 실제 인사 명단은 개인정보입니다. 결과 파일을 공유할 때는 필요한 열만 `--label` 로 고르세요.
- 겸직(상사가 두 명)은 표현하지 못합니다. 주 소속 상사 하나만 적어 주세요.
- 관리 폭·깊이 기준(8명, 5단계)은 예시 값입니다. 회사 기준에 맞게 바꾸세요.
