# 185 상한가·하한가 계산 (호가단위 반영)

## 무엇을 하나요?
종목별 **기준가격**으로 다음 거래일의 **상한가·하한가**를 계산합니다. 가격제한폭(기본 ±30%)을 구한 뒤 호가단위에 맞게 자릅니다. 기준가격이 호가단위에 안 맞는 값이면 "입력 확인"으로 알려 줍니다.

## 어떤 업무에 쓰나요?
- 주문·리스크 시스템 테스트 데이터(상·하한가 경계값) 만들기
- 가격 제한 로직을 고친 뒤 결과를 대조하는 검산표 만들기
- 100번(호가단위 사전 검사)과 함께 주문 가격 범위 점검

## 생각의 흐름
1. 제한폭 = 기준가격 × 30% 를 기준가격 구간의 호가단위로 **버림**
2. 상한가 = 기준가격 + 제한폭 → 상한가 구간 호가단위로 **내림**
3. 하한가 = 기준가격 − 제한폭 → 하한가 구간 호가단위로 **올림**

내림/올림 방향은 "제한폭 밖으로 나가지 않게" 하려는 것입니다. 돈 계산이라 소수(float) 대신 정수로 계산합니다.

## 기본 호가단위표 (2023-01 개편, 유가증권·코스닥 공통)
| 가격 | 호가단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 2,000 ~ 5,000원 미만 | 5원 |
| 5,000 ~ 20,000원 미만 | 10원 |
| 20,000 ~ 50,000원 미만 | 50원 |
| 50,000 ~ 200,000원 미만 | 100원 |
| 200,000 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

제도가 바뀌면 `--tick-file` 로 새 표를 주세요(열: `미만,호가단위`, 마지막 줄의 `미만` 은 빈칸).

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/base_prices.csv
python main.py sample/base_prices.csv --rate 0.15            # 제한폭이 다른 상품 연습
python main.py 기준가.csv --price-col 전일종가 --tick-file 내호가표.csv
```

## 입력 예시 (`sample/base_prices.csv`, 가짜 종목)
```
종목코드,종목명,기준가격
A000001,가상전자,71500
A000004,가상화학,15400
A000007,가상통신,12345
```

## 출력 예시
```
종목                기준가격         상한가         하한가  비고
가상전자             71500       92900       50100
가상화학             15400       20000       10780
가상지주            385000      500000      269500
가상통신             12345       16040        8650  기준가격이 호가단위에 안 맞음(입력 확인)
가상건설                미정                          기준가격 '미정' 이(가) 양의 정수가 아님
```
`output/price_limits.csv` 에 호가단위·제한폭까지 함께 저장됩니다.

## 주의사항
- **학습·점검용 계산기입니다.** 실제 주문에 쓰기 전에 거래소가 공시한 상·하한가와 꼭 대조하세요. 기준가격 산정(권리락·액면분할·신규상장 등)과 ETF·ELW·코넥스 등 상품별 규칙은 반영하지 않았습니다.
- 확인한 것: 위 샘플 값은 이 스크립트의 계산 순서대로 손으로 다시 계산해 맞는 것을 확인했습니다. 거래소 실제 공시값과의 대조는 하지 못했습니다.
