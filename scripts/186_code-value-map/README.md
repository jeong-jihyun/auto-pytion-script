# 186 코드값 매핑 변환 (시스템 이관용)

## 무엇을 하나요?
CSV 데이터의 코드값(예: 거래구분 `01`, 계좌유형 `G`)을 **매핑표**대로 새 시스템 코드(`BUY`, `GENERAL`)로 바꿉니다. 매핑표에 없는 값은 목록(`unmapped.csv`)으로 뽑아 줘서, 이관 리허설 때 빠진 코드를 바로 찾을 수 있습니다.

## 어떤 업무에 쓰나요?
- ERP·차세대 시스템 이관 때 공통코드 변환
- 대외기관·타사 연계 파일의 코드 체계 맞추기
- 이관 리허설에서 "매핑 안 된 코드가 몇 종류, 몇 건인지" 보고

## 생각의 흐름
1. 매핑표 한 파일에 여러 열의 매핑을 같이 적습니다: `열이름,원본코드,대상코드`
2. 매핑표부터 검사합니다. 같은 열·같은 원본코드가 서로 다른 대상코드로 두 번 있으면 멈춥니다.
3. 매핑 없는 값 처리를 고릅니다.
   - `keep`(기본): 원래 값 그대로 두고 목록에 적기
   - `default`: `--default` 값으로 채우기
   - `fail`: 하나라도 있으면 결과를 **저장하지 않고** 멈추기(종료 코드 1)
4. 공백·대소문자 때문에 안 맞는 일이 많아 앞뒤 공백은 항상 무시하고, `--ignore-case` 로 대소문자도 무시할 수 있습니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/legacy_orders.csv sample/code_map.csv --ignore-case --keep-original
python main.py sample/legacy_orders.csv sample/code_map.csv --on-missing fail       # 리허설용
python main.py data.csv map.csv --on-missing default --default UNKNOWN
```

## 입력 예시
`sample/code_map.csv` (설명 열은 있어도 되고 없어도 됩니다)
```
열이름,원본코드,대상코드,설명
거래구분,01,BUY,매수
거래구분,02,SELL,매도
계좌유형,G,GENERAL,일반
```
`sample/legacy_orders.csv` (가짜 주문)
```
주문번호,거래구분,계좌유형,통화,금액
O-1001,01,G,krw,1500000
O-1004,03,G,KRW,50000
```

## 출력 예시
```
읽은 행: 6
  [거래구분] 바꾼 칸 4개, 매핑 표 2개
  [계좌유형] 바꾼 칸 5개, 매핑 표 2개
  [통화] 바꾼 칸 6개, 매핑 표 2개
매핑 없는 값 2종류:
  - [거래구분] '03' 1건 (처음 5행)
  - [계좌유형] 'X' 1건 (처음 6행)
```
`output/mapped.csv` (`--keep-original` 사용 시)
```
주문번호,거래구분,거래구분_원본,계좌유형,계좌유형_원본,통화,통화_원본,금액
O-1001,BUY,01,GENERAL,G,KRW,krw,1500000
O-1004,03,03,GENERAL,G,KRW,KRW,50000
```

## 주의사항
- 빈 칸은 매핑하지 않고 빈 칸으로 둡니다.
- 원본코드 `01` 과 `1` 은 다른 값입니다. 엑셀로 열었다 저장하면 앞의 0이 사라질 수 있으니 CSV를 메모장 등으로 확인하세요.
- 원본 파일은 바꾸지 않습니다.
