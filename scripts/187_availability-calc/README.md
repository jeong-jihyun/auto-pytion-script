# 187 장애 이력으로 월 가용률 계산

## 무엇을 하나요?
장애 이력 CSV로 서비스별 **한 달 가용률(%)** 을 계산하고 SLA 목표(기본 99.9%)와 비교합니다. 한 달에 허용되는 장애 시간과 **남은 여유(분)** 도 같이 보여 줍니다.

## 어떤 업무에 쓰나요?
- 월간 운영 보고서의 가용률·SLA 달성 여부
- 고객사 SLA 보고, 위약금 산정 전 검산
- 이번 달 남은 장애 여유를 보고 배포·점검 일정 정하기

## 생각의 흐름
- 가용률 = (전체 시간 − 장애 시간) ÷ 전체 시간 × 100
- 그냥 더하면 틀리는 두 가지를 먼저 처리합니다.
  1. **겹치는 장애**(같은 시간대 두 건)는 한 구간으로 합칩니다 → 두 번 세지 않음
  2. **달 경계를 넘은 장애**는 이번 달 몫만 셉니다
- 계획 점검(사전 공지, `계획점검=Y`)은 기본으로 빼고 따로 표시합니다. 넣으려면 `--include-planned`.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/incidents.csv --month 2026-10
python main.py sample/incidents.csv --month 2026-10 --services 주문API,조회API,정산배치,고객센터
python main.py sample/incidents.csv --month 2026-10 --include-planned --target 99.95
```
`--services` 로 이름을 주면 장애가 한 번도 없던 서비스도 100%로 표에 나옵니다.

## 입력 예시 (`sample/incidents.csv`, 가짜 장애)
```
서비스,시작,종료,계획점검,내용
주문API,2026-10-03 09:10,2026-10-03 09:40,N,DB 커넥션 고갈
주문API,2026-10-03 09:30,2026-10-03 09:55,N,같은 시간 LB 오류(겹침)
주문API,2026-10-18 02:00,2026-10-18 04:00,Y,정기 점검
조회API,2026-10-31 23:30,2026-11-01 00:45,N,월말 배치 영향(달 경계)
```
날짜시간은 `2026-10-03 09:10`, `2026-10-03 09:10:00`, `2026/10/03 09:10` 을 읽습니다.

## 출력 예시
```
2026-10 전체 44,640분, 목표 99.9% → 허용 장애 44.6분
  고객센터       가용률 100.000%  장애 0분 (계획점검 제외 0분)  여유 44.6분  → 달성
  정산배치       가용률 99.933%  장애 30.0분 (계획점검 제외 0분)  여유 14.6분  → 달성
  조회API      가용률 99.888%  장애 50.0분 (계획점검 제외 0분)  여유 -5.4분  → 미달
  주문API      가용률 99.899%  장애 45.0분 (계획점검 제외 120.0분)  여유 -0.4분  → 미달
[건너뜀] 8행: 종료가 시작보다 빠르거나 같음
```
주문API는 09:10~09:40 과 09:30~09:55 가 겹쳐서 55분이 아니라 **45분**으로 셉니다.

## 주의사항
- 전체 시간은 그 달의 24시간 × 일수입니다. "영업시간만 SLA"인 계약이면 063번(SLA 업무시간 계산)을 참고하세요.
- 계약마다 장애 인정 기준(부분 장애, 5분 미만 제외 등)이 다릅니다. 이 스크립트는 기록된 시간을 그대로 셉니다.
- 시간대(타임존)는 따로 바꾸지 않습니다. 모든 기록을 같은 시간대로 적어 주세요.
