# 188 WBS 가중 공정률 계산

## 무엇을 하나요?
WBS(작업분류) CSV에서 맨 아래 작업의 계획%·실적%와 가중치로 **상위 단계와 전체 프로젝트 공정률**(계획 대비 실적)을 계산합니다. 계획보다 기준(기본 5%p) 이상 뒤처진 작업은 **지연 작업**으로 뽑아 마크다운 보고서로 저장합니다.

## 어떤 업무에 쓰나요?
- SI·ERP 프로젝트 주간 보고의 공정률 표
- PMO 점검 전에 담당자별 지연 작업 확인
- 엑셀 공정표의 수식이 깨졌을 때 검산

## 생각의 흐름
1. 진척은 **맨 아래 작업(리프)에만** 적습니다.
2. WBS 코드의 점(.)으로 부모를 찾습니다(`1.2.3` → `1.2` → `1`).
3. 상위 진척 = Σ(하위 가중치 × 하위 진척) ÷ Σ(하위 가중치). 상위 항목에 손으로 적은 진척 값은 무시하고 다시 계산합니다.
4. 가중치는 "형제들 사이의 비중"입니다. 합이 100이 아니어도 비율로 계산합니다.

## 설치
파이썬 3.8 이상. 추가 설치 없음.

## 실행 예시
```bash
python main.py sample/wbs.csv
python main.py sample/wbs.csv --late-gap 10 --output output/주간공정.md
```

## 입력 예시 (`sample/wbs.csv`, 가짜 프로젝트)
```
WBS,작업명,가중치,계획%,실적%,담당
1,분석,20,,,PM
1.1,현행 업무 분석,50,100,100,김분석
1.2,요구사항 정의,50,100,90,김분석
2,설계,30,,,PM
2.1,화면 설계,40,100,80,이설계
...
4,테스트,10,0,0,QA
```

## 출력 예시
```
- 전체 계획 공정률: **59.6%**
- 전체 실적 공정률: **51.1%**
- 차이: **-8.5%p** (뒤처짐)

| WBS | 작업명 | 가중치 | 계획% | 실적% | 차이 | 담당 |
| 1 | **분석** | 20 | 100.0 | 95.0 | -5.0 | PM |
| 2 | **설계** | 30 | 88.0 | 77.0 | -11.0 | PM |
...
## 지연 작업 (계획보다 5%p 이상 뒤처짐)
- 2.1 화면 설계 (이설계): 계획 100% / 실적 80%
- 3.1 정산 모듈 (최개발): 계획 40% / 실적 25%
```
검산: 계획 = (20×100 + 30×88 + 40×33 + 10×0) ÷ 100 = 59.6% 로 맞습니다.

## 주의사항
- 리프 작업의 계획%/실적%가 비면 0으로 계산하고 "확인할 점"에 적습니다.
- WBS 코드가 두 번 나오면 멈춥니다.
- 일정 막대 그림이 필요하면 139번(간트 차트)을 함께 쓰세요.
